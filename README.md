## 产品摘要（30 秒读完）

**是什么**：一个能被**完整验证**的 agent 内核。七段认知循环可跑、预算可对账、
记忆去重由数据库保证，而且「它变好了没有」这句话有**外部依据**（外部打分器 +
口径闸 + 撤回态）。零第三方运行依赖（`dependencies = []`，由 AST 审计与契约钉死）。

**不是什么**：**不是 AGI**，不声称「无限接近 AGI」，也不声称「内核会自己变强」。
种库、动作空间、判据、目标类型表，全部是人写的。见文末「边界」。

**30 秒验证**（零模型、零网络、零密钥，全部本机实测）：

```bash
./quickstart.sh                      # 契约 + 锚层 + 端到端自检，四步
bash demo/run_demo.sh                # 三臂参照点：1.0000 / 0.0000 / 0.6194（逐位可复现）
./run_tests.sh                       # 七步全量门（含依赖审计：白名单外一个 import 都不许有）
python3 run.py --goals               # L5 入口：它从**自己的账本**里决定该做什么
```

**别人 clone 之后能不能自证** —— 这是「交付物」与「我机器上绿了」的分界线：

**与 Inspect AI（评测 harness）的差异** —— 不比能力规模，比的是**测量有效性**：

| 维度 | Inspect AI（公开定位） | V1 |
|---|---|---|
| 角色 | 跑评测、算分数 | agent 内核 + **测量有效性层** |
| 判据来源 | 用户提供 scorer | 判据只从题面派生（`mw/verify.py`）+ 外部真值锚层 |
| 「绿灯可信吗」 | 不内置回答 | **382 条撤回态**：每条断言配一个「把它改坏，这条必须红」的撤回动作。口径分三层：**382/382 锚点在源码里恰好出现一次**（静态）、受改动影响的 16 条**逐条动态复跑全绿**、**其余 306 条动态未测**（单条 1~4 分钟，全量 6~10 小时，两次尝试被沙箱执行能力上限终止 —— 未测就写未测） |
| 噪声处理 | 不内置 | 噪声下限 + 安慰剂臂（等长、非空、非原文）+ T=0 跨请求不确定性实测 |
| 三臂对照 | 无内置 | oracle / null / partial 参照点 + 等长中性扰动 |
| 依赖 | pip 生态 | 零第三方运行依赖 |

**边界**：V1 **不是 AGI**。它声称的只有「可被完整验证」这一件事，
且每个绿灯都能被撤回证明不是恒真。

## 二、自省：把「改不动」拆成三步之后

`t01`（`parse_duration`，起点 5/6）上的连续五轮，每轮只动一个变量：

| 轮 | 动的是什么 | 读数 | 判决 |
|---|---|---|---|
| V245 | 反馈保真度（加执行轨迹 / 强制根因） | 三臂 **0/16** | 加信息无效 |
| V246 | 自验回路（最多 3 轮） | 7B **0/16**，自锁 14/16 | 确定性提议者 ⇒ 回路退化成单轮 |
| V247 | 动作换成「先自述语义，再回喂改码」 | 问答 **32/32 说对**「分钟数是 `parts[0]`」，代码 **31/32 照抄** | **说与做零接合** |
| **V248** | **动作空间压到一行**：只输出 `LINE:` / `EXPR:`，替换由装置执行 | **10/16** 达 6/6（对照臂 A/N 均 **0/16**） | **首次转正** |
| V249 | 接成产品开关 `--goals-swap-edit {off,line}`，默认 `off` | 接口与锚点都齐了；**一次模型没跑** | 接档 ≠ 有效 |

**读得出来的结论**：缺口不在「看见」（4/4），不在「说」（32/32 说对），
而在**动作空间只有一个出口**叫「重写整个函数」——同一个「尽量少改」的倾向，
在「重写 26 行」里执行成照抄，在「只改一行」里执行成正确修复。

**必须一起说的三条限定**（少一条就是包装）：

1. **执行是装置做的**，模型只输出「改哪行、改成什么」⇒ ⛔ 不能说「模型学会了自己改代码」。
2. 只适用**最小修复 = 一行**的 bug；需要改两行的未测。
3. 10/16 里落地成**同一个 sha**，有效样本量 ≤ 4；单题、单起点、7B。

## 三、怎么跑

```bash
git clone <repo> && cd PyautoL-V1
./run_tests.sh          # 不需要装任何东西；本机 Python ≥3.11
```

| 入口 | 用途 | 需要模型 |
|---|---|---|
| `./quickstart.sh` | 四步上手：契约 → 锚层 → 自检 → 读数 | 否 |
| `bash demo/run_demo.sh` | 三臂参照点，验证尺子有分辨力 | 否 |
| `python3 run.py --selftest` | 离线端到端（七段循环全跑一遍） | 否 |
| `python3 run.py --goals` | **自主目标**：从账本提议该做什么 | 否 |
| `python3 run.py --goals --goals-act 1 --offline` | 真执行一条目标并判定 | 否 |
| `python3 run.py --verify-impl 候选.py` | 检视工具：报 `VARIES/CONST/STRUCT/FAULT` | 否 |
| `python3 run.py --bench --suite bench/tasks/coding_small.jsonl` | 外部锚层模式：校准 → 跑 → 过口径闸 | **是** |
| `python3 -m mw.loop --rounds N --noise-floor X` | 常驻循环 + 能力曲线 | 是 |

真模型只需三个环境变量：`V1_LLM_API_KEY`、`V1_LLM_MODEL`、`V1_LLM_BASE_URL`
（本机 Ollama 见 `agents.example.json`）。⚠️ **少一个 key 会静默退化成 oracle 桩** ——
跑完先看血缘行，别信分数。

⚠️ 跨轮比较有前提：`harness_sha` 变了，历史锚点就作废。V249 为接一个默认关的开关，
`harness_sha` 从 `3b33bcb8` 变成 `a05e15df6cd1ec84` ⇒ **该点之前的跨轮读数不可直接对比**（纪律 237）。

## 四、证据怎么复核

每条结论落在 `bench/evidence/<轮名>/`，最小集合：

```
PREREG_*.md     跑之前押什么、判据是什么、分母是多少、UNKNOWN 怎么判
*.py            装置（能重跑，不是截图）
READINGS*       原始读数（未经整理的输出，含失败与自踩）
RESULTS_*.md    结论 + 自踩 + 边界
```

复核顺序：先读 `PREREG` 看它当时押了什么 → 跑装置拿读数 → 对比 `RESULTS`。

⛔ 三类东西**不算证据**：同一份数据的二次整理、没有预注册的事后解释、
以及「读数更干净」但不改变任何判断的改动。

## 六、边界（先读再评估）

1. **不是 AGI**，不声称「无限接近」。这是一个几千行的内核，不是通用智能。
2. **CI 只覆盖离线部分**。所有分数证据都需要本机模型，CI 不跑；CI 自己也曾连红 15 次
   （`run 234→248`），所以「绿」必须按 run 号查，不按徽章猜。
3. **L3 只完成一半**：能看、能量、判不过、默认路径下改不动（92.5%）。
   V248 的 10/16 是**装置执行**的结果，不是模型自省闭环。
4. **L4 的 84% 只在 26 个实现 / 4 道题上量过**，且累积只在资源紧张（`B<400`）时有牙。
5. **L5 的自主是「测量自主」**：它自己决定去测什么、判自己测成没有；
   它不是自己决定「要变成什么」。`RAISE` 类目标**提得出、做不到**。
6. **撤回态里有 306 条动态未测**。静态 382/382 全绿只证明「锚点在源码里唯一」，
   不证明「改坏它一定红」——两者是不同的读数。
7. **动作空间、种库、判据、目标类型表全部人写**。⛔ 不许把 V248 的读数说成
   「内核会自己变强」。
