## 3. ⭐ 尺子的缺陷：题面欠定，8 题里 2 题不可归因

### 3.1 是什么

第一版题面写的是「写一个函数 `append_dedup`，**参数见下面每一条规则里提到的名字**」。
但 at03/at05 的规则里 `path`/`root` **先出现**，而测试按 `(rows, path)` 调用：

| 题 | 规则里的首现顺序 | 测试的调用顺序 | 模型写的 |
|---|---|---|---|
| at03 | `path`(规则1) → `rows`(规则2) | `(rows, path)` | `def append_dedup(path, rows)` ⇒ `TypeError: ... not list` |
| at05 | `root`(规则1) → `rows`(规则2) | `(rows, root)` | `def save_nested(root, rows)` ⇒ 同上 |

⇒ 这 2 题、**32/128 格**的 0 分**不是能力读数**，是题面欠定。
模型「照题面顺序写」是**正确行为**，被尺子判成错。

### 3.2 怎么修的

1. `sig_of(sp)` 从 **oracle** 抽签名（参数名 + 顺序），作为唯一真相来源；
2. 题面统一改成「函数签名**必须**是 `def f(a, b)`（参数名与顺序照此写，不要改）」；
3. 新增 **S9**（每条题面必须含签名）+ **S10 反证**（把签名拿掉、只按「规则首现顺序」猜，
   必须至少错 1 条 —— 若 0 条则 S9 是装饰、该删）。

S10 独立跑出来的结果，与上表的实测**完全吻合**：

```
[S10] 反证「按规则首现顺序猜参数」：2 条会猜错 ✅
      at03: 猜=path,rows 实际=rows,path
      at05: 猜=root,rows 实际=rows,root
```

第十八件量具加 **A8**（冻结题集里每条题面必须含签名）。
**A8 不是恒真**：拿 HEAD 版旧题集跑同一判据 ⇒ **8/8 报错**（见 `analyze.txt` 末尾）。

### 3.3 修完还剩下什么

at05 **0 → 1.0**（真被修好了）。
at03 **仍然 0**，但原因换了：不再是 `TypeError`（参数序），而是
`io.UnsupportedOperation: not readable` —— `open(path, 'a')` 之后还想 `for line in f`。
⇒ 这道题有**两个** bug，尺子只挡住了第一个。**修完尺子才看得见第二个**，这才是修的收益。

## 4. ⛔ 预注册被自己的读数否证（照登）

`PREREG.md` 第四节写定：全 0 时最可能的真因是「a 有 / b 无」——
模型交的是**不写文件的纯函数**（`pure` 形态，v1~v3 的满分答案）。**两轮都是错的**：

| 轮 | 唯一答案 | 有 `def` | 有写调用 | `pure` 形态 |
|---|---|---|---|---|
| T1 | 9 | 9 | **9** | **0** |
| T1b | 10 | 10 | **10** | **0** |

⇒ 模型**从来没有**交「只算不写」的代码。它交的代码都真的写文件，**只是写错**。
`§70` 的 `pure` 判据（尺子存在的理由）在这轮真实读数里**一次也没咬合** ——
它的价值只剩「形态自证」（同一份实现在 v1~v3 满分、在这里 0.0469），
**不能**当成「真实失败的主因」。

`kernel_closeout` 台账两轮都是 `overrode_rejected=3 / same_as_rejected=0`：

| 轮 | 收尾触发 | 来源 | 改交付 | 与被闸打回那版同 |

## 6. ⭐ 噪声下限不是常数（第二轮实测）

| 轮 | 极差 | 不稳定题 |
|---|---|---|
| T1 | **0.1250** | `at08`（1.0 / 1.0 / 0.0） |
| T1b | **0.0000** | 无 |

同一晚、同一内核、同一模型、同一温度、逐位相同的 `limits` ⇒ **只有题面不同**。
⇒ **「极差 = 0」不是「链路确定」的证明，只是「本次这套（题面, 模型, 内核）组合在本时段没抖」。**
这是 §63（`T=0` 不是逐字确定）的第二次独立观测，并且比 §63 更强：
**连"噪声下限有多大"本身都不是常数**（同一晚 0.1250 → 0.0000）。

⇒ 任何「Δ ≤ 逐题极差 ⇒ UNKNOWN」的判据都得写成「**本 run 的**极差」，
而单 run 的极差 = 0 **不能**被读成「任何 Δ 都可分辨」。

```
  at05  +1.0000/8 = +0.1250   ← 尺子欠定被修掉（题面加了签名）

  ────────────────────────────
  合计            = +0.1667   ✅ 逐位对得上
```

⇒ **+0.1250 是测量误差被消除，+0.0417 是采样噪声。能力项 0.0000。**

⛔ 任何人拿「0.3802 → 0.5469」说「变强了」，都是在把「修表」当成「跑得更快」。

## 8. 本轮做了什么 / 没做什么

**做了**：
1. T1、T1b 两轮真模型单臂（同一晚，间隔 ~30 分钟），全部 `attempted=24 recorded=24`；
2. 发现并修掉尺子的一处欠定（题面签名），修法带 S9/S10/A8 三道闸，其中 S10 与 A8 都有**反证**；
3. 把 at04 的「缺 import」跨族复现与三重叠加逐条对位；
4. 把「+0.1667 的分解」算到逐位对得上。

**没做**：
1. ⛔ **没改内核**（`mw/` 一个字节没改）⇒ 无断段，175 条撤回态不用重跑；
2. ⛔ **没改 `verify_static` 默认值**（§67.9 M1 仍未做，它也仍未获授权）；
3. ⛔ **没做 A/B**，「收尾只记不拦」也没有动（§57 的设计，改它要单独预注册）；
4. ⛔ **没说「模型变强」**，本轮 Δ 全部分解为测量误差 + 采样噪声。
