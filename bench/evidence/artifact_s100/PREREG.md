# §70 预注册：S1 前置 —— 造一把「产物型」尺子（`tasks_v4`）

> 写于跑任何读数**之前**。落盘理由：§66 的自踩是「零咬合只能事后发现」，
> 因为当时没预注册两个分母。本轮预先把判据、分母、判负条件全部写死。

## 一、要证明的一句话

`tasks_v4` 测的是**另一件事**，不是 v1~v3 的加强版。

判据不是「题目变难了」，而是：**同一份在 v1~v3 上能拿满分的实现，在 v4 上拿不到分。**
具体形式：`pure` 变体（返回值完全正确、但什么都不写出去）。

## 二、两个分母（§66 自踩的修法）

| 分母 | 值 | 说明 |
|---|---|---|
| 机会数 | `8 题 × 16 格 = 128` | 每一格都是一条独立断言 |
| 判负的分母 | `pure 均分`（8 题平均） | 判据 `< 0.10` |

## 三、判负条件（满足任一条 ⇒ 本轮结论作废，不许写「尺子造好了」）

| # | 判负 |
|---|---|
| N1 | `oracle` 有任何一题 < 1.0（题目不可解） |
| N2 | `pure` 均分 ≥ 0.10（形态没变，白造） |
| N3 | 任一题 `partial` 不在 `(0, 16)` 开区间（断言不区分中段） |
| N4 | 倒序跑 test 分数变（断言互相依赖 ⇒ 「128 格」是假的） |
| N5 | 冻结文件 ≠ 生成器重生成（尺子已漂） |
| N6 | 改坏一条期望值后分数不掉（断言恒真） |

## 四、明确**不**声称的东西

1. ⛔ 不声称「内核会用工具」。判分只看 `answer`，看不到轨迹
   （`mw/bench.py:301` 的协议就是 `{task, answer}`）。
2. ⛔ 不声称这把尺子比 v3「更外部」。它的期望值来自
   **CPython stdlib 的序列化行为 + 我规定的产物格式**，比 v3（CPython 自己的实现）
   **弱一层**。
3. ⛔ 不声称分数可比。新 `suite_sha` ⇒ 与 v1/v2/v3 的读数**一律不可并列**。
4. ⛔ 本轮不跑真模型。这是**造尺子**轮，不是**量能力**轮。
