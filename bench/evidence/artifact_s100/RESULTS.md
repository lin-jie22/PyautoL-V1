## 核心读数

| 读数 | 值 | 含义 |
|---|---|---|
| 题数 × 格数 | 8 × 16 = **128** | 每题 16 条独立断言 |
| `oracle` 均分 | **1.0000** | 题目全部可解 |
| **`pure` 均分** | **0.0469** | ⭐ 返回值完全正确、但不落盘的实现拿不到 10% |
| `partial` 分布 | 7,8,14,10,5,1,14,5 | 全部严格居中（`0 < p < 16`） |
| `null` | 0/16 × 8 | 空答案零分 |
| 倒序跑 test | 分数不变（3 题抽样） | 断言之间不共享状态 |
| 改坏一格期望值 | 1.0000 → 0.9375 | 断言不是恒真 |
| 冻结 == 重生成 | 逐字节相同 | 尺子没漂 |

## 三处自踩（详见 DESIGN §70.4）

1. **at04 全 0/16**：`(rows, bad)` 二元组的 `bad` 被当参数展开 ⇒ `write_or_fail(rows, True, path)`。
2. **at08 期望值没转义** ⇒ `partial` 16/16、`oracle` 5/16（**错误答案拿了满分**）。是 S3 抓的，不是 S1。
3. **量具第一版 `pure` 恒 None** ⇒ A4 静默失效，而"失效"与"通过"在输出上同形。
