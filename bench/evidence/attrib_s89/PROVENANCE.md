## 2. 判分口径（不许另起一套）

探针若另写一套判分，这里先红。

## 3. 落盘答案的两处偏离

| | 根因 | 题面要求 |
|---|---|---|
| **B1** | `re.sub(r' +', '-', row)` | 「连续 **2 个以上**的空白字符换成「-」，**不足 2 个的空白原样保留**」 |
| | · 下限是 1 不是 2 ⇒ 单个空格也被换成 `-` | |
| | · `' '` 不认 `\t` ⇒ 制表符完全不参与 | 题面写的是「空白字符」，`sg07` 的测试里就有 `delta\tepsilon` |
| **B2** | 去重用**全局** `seen` 集合 | 「去掉**紧挨着**的重复行……**不相邻**的重复行必须保留」 |

⭐ **答案自己的注释是对的，代码不对**：注释写「每行里连续 2 个以上的空白字符都换成一个「-」」，
下一行代码写 `' +'`。复述规范与实现规范是两件事。

## 5. 结论：**最显眼的 bug ≠ 最值钱的 bug**

题面把 B2 那条规则加粗写了两遍（「紧挨着」/「不相邻的必须保留」），
答卷也明明白白违反了它 —— 目测几乎必然把 B2 判成主因。

**实测：只修 B2 一格都拿不到。**

为什么：B1 先把不同的行压成了相同的行。`['Alpha Beta', 'ALPHA BETA']`
经 `strip` + `' +'→'-'` 变成 `Alpha-Beta` / `ALPHA-BETA`，`lower()` 后相同，
全局去重才有东西可删。B1 修好后这些行重新变得不同，B2 的伤害范围立刻收缩。
⇒ 两条根因在 `[1][6][13]` 上**耦合**：逐项相加（0 + 6 = 6）≠ 一起修（+9）。

这把一条纪律从口号变成读数：**单项收益不可加，不许把消融表的单列当分量求和。**

## 6. 边界（不许越）

- **n=1 题、n=1 个答案**。这是一份**案例**，不是分布。⛔ 不许据此说
  「模型总是先修错地方」，也不许外推成任何「定律」。
- `fix_B1` / `fix_B2` 的替换串由 `bench/attrib/sg07.json` 提供，**逐字节匹配**。
  答案文本一变（换模型、换采样）这张表立刻失效 —— 自检 C4 专门钉这一点：
  目标不存在必须抛，静默跳过会让「0 收益」变成伪造读数。
- 只回答「哪些断言红了、红在哪」，不回答「模型为什么犯这个错」。
  后者需要看完整推理链，本证据里没有（`thinking=disabled` 那轮**没**采思维链）。
- `sg07` 的 5/14 仍只是**这一个模型在一次采样**下的读数。`repeat=1`，噪声未估。
