## 0. 本轮要动的东西（来自 §65.9 的预注册，未实施）

```python
# 现状（mw/core.py:1161）
if repeats and repeats == len(cands):
```

§65 量到的事实（309 份任务日志 / 2108 步 / 81 次重复候选）：

- 全等 **48 步**，宽度**全是 1**；
- 混合 **33 步**，宽度**全是 2**；
- 混合掉进 `else` 支 ⇒ `consecutive_failures += 1`（把"重复"记成"做错"）。

⇒ 修法方向：**把"这一步没执行任何候选"的两种原因分开记，并让"有重复、且剩下的都只是被拦"这一情形也算停滞**。

## 1. 对 §65.9 候选判据的**收窄**（写在最前面，因为它是一条偏离）

§65.9 预注册的公式是：

```python
if (repeats + blocked_now) == len(cands) and (repeats or blocked_now):
```

本轮**不照抄**，改成一个更窄的条件：

```python
if repeats and (repeats + blocked_now) == len(cands):
```

差分只在一种情形：`repeats == 0` 且**全部候选被拦**。旧判据把它记成 `stalled += 1`，
新判据保持 `consecutive_failures += 1`。三条理由：

1. **语义**：`repeats == 0` 的全拦是"这些动作都不许做"，一个"重复"都没有；
   把它记成停滞，等于把「全部候选被拦」这条**真信号**吞掉。
2. **可归因**：`stalled` 触发的出口是 `_close_out(reason="stalled")`；
   而全拦的出口是熔断（`cascade`）。把一种并进另一种，之后读数再也分不开
   "模型在原地打转"与"模型一直提不该做的事"—— 它们的修法完全不同。
3. **风险面**：`repeats == 0` 的全拦在最近两轮的两臂里**真实出现过**
   （§64.2 的 `sg10` 第 1 轮就是 `1 重复 + 1 撞墙`，但 §65.1 的 `B` 臂同形）。
   不缩窄，等于在一个**没量过的格子**上同时改两件事。

⚠️ 这条偏离**必须在 DESIGN 里单独列一条**，不许混进结果里当"设计选择"。
