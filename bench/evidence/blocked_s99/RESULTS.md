# 第九十九轮 §66 结果：开关一次也没开火 —— 因为它押的那条腿不是「被拦」

日期：2026-10-27　起点 `abc15d5`　读法：`bench/evidence/blocked_s99/`（两臂全量冻结）

## 0. 一句话

§65.9 预注册的判据改动（把 `blocked_now` 计入分母）做完了，机制层十五条反证全绿，
但放到真模型两臂上，**它一次也没开火**（停滞行 `0 / 0`）：

> §65 说「41% 的重复发生在混合轮，而混合轮够不到停滞」——这句是对的。
> 但**混合轮的那条「另一条腿」几乎从来不是「被拦」**，所以把「被拦」加进分母，
> 加的是一个恒为 0 的数。

| 量 | `SB=0`（对照） | `SB=1`（开闸） | Δ |
|---|---|---|---|
| `mean` | **0.7286** | **0.7095** | **−0.0191** |
| 单臂极差 | 0.0214 | **0.1072** | — |
| 停滞行 | **0** | **0** | 0 |
| 全拦行 | 1 | 0 | −1 |
| 重复跳过 | 3 | 4 | +1 |
| `elapsed_s` | 1336.8 | 1257.1 | −5.96% |

裁决：`|Δ| = 0.0191 < max(极差) = 0.1072` ⇒ **`UNKNOWN`**。
⛔ 不许把 `−0.0191` 读成「开闸有害」：`−13 格`全部来自 `sg10` 一轮缺 `import re`（§63.6 的老毛病）。

## 1. 决定性的那个数：混合轮的「另一条腿」去哪了

本轮两臂共 **7 次**混合轮（`SB=0` 三次、`SB=1` 四次），形状**完全一致**：
`[2] 通道=深 候选=2`、`重复=1`（都是 `finish` 被判重复）。

| 那一步的另一条腿 | 本轮 7 次 | 全库 309 份日志（33 次混合） |
|---|---|---|
| **被执行**（`↳ … ok=True`） | **6** | **21** |
| 预算/墙钟掐掉（`⏳ 预算耗尽`） | 1 | 7 |
| **被拦**（`✋` / `⊘`） | **0** | **5（15.2%）** |

⇒ `blocked_now` 在本轮 **7 次机会里恒为 0**，判据 `repeats + blocked_now == len(cands)`
（`1 + 0 != 2`）**永远不成立**。开闸与关闸的判据路径逐位相同 ⇒ 两臂行为必然同形。

⭐ 这张表的复跑方式（脚本已提为正式量具，挂在 7i）：

```bash
python3 bench/audit_legs.py bench/evidence/blocked_s99/run_a.log \
                            bench/evidence/blocked_s99/run_b.log
python3 bench/audit_legs.py --self-check     # A1~A5，其中 A4 钉住下面那条自踩
```

⭐ 这条也**反向修正了 §65 的一个隐含假设**：混合轮不是「一次失败 + 一次被拦」，
而是「一次重复 + 一次**真的在干活**」。那一步**本来就不该算停滞** ——
判据没记它是**对的**，不是「够不到」。

## 2. 判据的理论咬合上界：15.2%

全库 33 次混合里只有 5 次是「另一条腿被拦」。⇒ 即使把开关默认打开，
它在历史上**最多**能改变 5/33 次的归属；而 v2 这把尺子本轮是 0/7。

⛔ 更重要的：那 5 次咬合之后**行为会不会更好，本轮没测**（一次没咬到）。
把「咬合上界 15.2%」与「咬合后有效」混为一谈，就是把机制当收益。

## 3. 分数账：−8 格，全在两题上

`420 格`里 `+2（sg01）+ 3（sg02）− 13（sg10）= −8 格`，`−8/420 = −0.01905` ✅ 与 `Δmean` 逐位对上。

| 题 | `SB=0`（r1,r2,r3） | `SB=1`（r1,r2,r3） | 格差 |
|---|---|---|---|
| `sg01` | 12/14 ×3 | **14/14**, 12/14, 12/14 | **+2** |
| `sg02` | 7/14, 10/14, 10/14 | 10/14 ×3 | **+3** |
| `sg10` | 14/14 ×3 | 14/14, 14/14, **1/14** | **−13** |
| 其余 7 题 | — | — | 0 |

`sg10` 那轮 `1/14` 是**同一个老缺陷第三次出现**：交付物缺 `import re` ⇒ 13 条断言同一个 `NameError`。
`SB=1` 臂的极差 `0.1072` 就是这一格撑起来的（`0.9286 × 3 / 420`）。

⇒ **本轮的 `UNKNOWN` 不是「效应太小」，是「噪声被一格老缺陷放大到 5 倍」**。
这也是 §63.6 的推论：`T=0` 下同一题可以给出两种答案，n=3 的极差只是**下界**。

## 5. 与 §65.9 预注册的偏离（单独列，不混进结果）

§65.9 草稿：`if (repeats + blocked_now) == len(cands) and (repeats or blocked_now):`
落地用的：`if repeats and (repeats + blocked_now) == len(cands):`

差分只在「`repeats == 0` 且全被拦」：旧判据记 `stalled`，新判据保持熔断。
三条理由见 `PREREG.md` §1；新增的 P12/P13 两向反证就是为这条守门
（照抄草稿时 P12 会红 ⇒ 这条偏离被钉在量具里，不只写在文档里）。

## 6. 三个自踩（照登，一个方向对结论有利）

1. **解析器把 6 次「被执行」误归「预算掐掉」**。
   `line.lstrip().split(" ", 1)[-1].startswith("↳")` —— `split(" ", 1)` 的右半**保留前导空格**
   ⇒ `startswith` 恒 False ⇒ `exec` 恒 0 ⇒ 全部混合轮都被读成「预算掐掉」。
   ⚠️ 那个方向**正好支持本轮结论**（「修法永不开火」）⇒ 属 §62 的「混口径往往对结论有利 = 自我打脸」。
   修法：改判 `"↳ " in line`。修后读数从 `{预算掐掉:2, 未知:1}` 变成 `{被执行:3}`。
2. **预注册漏了「真模型咬合次数」这条预测**。PREREG §3 的 P1~P5 全是桩上的，
   P6/P7 只押了 Δ 与墙钟 —— **没有一条押「它会咬合几次」**。
   结果本轮最重要的读数（`0/7`）是**事后**才发现的，不是被预测检验的。
   ⇒ 这类实验以后必须预注册「机会数 / 咬合数」两个分母。
3. **`probe_mutate_driver` 的 P5 硬锚 `len(fields)==19` 撞红**（新字段 ⇒ 20）。
   复核确认 `clean_env` 走 `fields_of_limits()` 动态取字段 ⇒ 硬锚干了它该干的事（逼我确认，不是让我猜）。

## 8. 保留还是回退

**保留**（默认 `0`），但登记为**死旋钮**：

1. 默认 `0` ⇒ 与旧版逐位相同（P10/P11 两向钉住），零风险。
2. 它自带两个可观测计数器（`blocked_skipped` 进 `stats`，零值也在），
   下一个想改这条判据的人**必须**先看这两个数 —— 这比删掉它更省事。
3. 回退要再断一次段（撤 AZ95 ⇒ 撤回态 175 → 172，再跑一遍全量），成本高于收益。

⛔ 三条不许忘：

1. **它一次也没咬合**（本轮 `0/7`，全库上界 `15.2%`）。⛔ 不许写成「判据改进有效」。
2. **咬合之后有没有用，本轮没测**。
3. **不许再为它调参**（`max_stall`、`blocked_now` 的口径都不许再动）——
   这把尺子上它没有机会，调参只会把「没机会」调成「看起来有机会」。
