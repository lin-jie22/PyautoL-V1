# 证据：三臂真跑第二次（§43.11）—— 第一次 `KEEP`

## 一、这一发在问什么

§43.9 的第一发把 `verify_static=2`（**同一触发集、盲报**）放在**安慰剂槽位**，
结果它比处理臂 `1`（报名字）高出 6 格，于是 `1` 被交叠闸判 `NO_EVIDENCE`。
这一发把 `2` 提到**处理臂**，并换上一个**历史上实测惰性**的安慰剂
（`working_memory_items 24 → 32`，第五～七十六轮的惰性对照）。这是第一次
**合规**的裁决：处理臂与安慰剂臂都对得上门，且安慰剂不承载任何语义。

## 四、裁决：`KEEP`，且不靠噪声口径撑着

```
base   0.5574
cand   0.6905   Δ = +0.1331
安慰剂 0.5595   Δ = +0.0022
噪声   0.0476
交叠   cand 0.6905~0.6905 ｜ 对照(base∪安慰剂) 0.5238~0.5714 ⇒ 分开↑
量级   最小效应量 0.0357（3 格 / 84 格）
⇒ KEEP  扣掉安慰剂 +0.0022 后净增益 +0.1309 > 噪声 0.0476
```

**四种噪声下重判（纯函数，`mutation_verdict` 原样调用）**：

| 噪声 | 裁决 |
|---|---|
| 0.0476（台账实测） | **KEEP** |
| 0.0000（置 0） | **KEEP** |
| 0.1309（放到与增益同量级） | NO_EVIDENCE |
| 0.5000 | NO_EVIDENCE |

⇒ **`KEEP` 不由噪声下限决定**：置 0 仍是 `KEEP`，因为交叠闸独立成立
（cand 的 10 次全部严格高于对照组的 16 次全部）。这与第七十六轮
「噪声置 0 仍 `NO_EVIDENCE`」是同一条闸的两次相反结果 —— 闸不是恒绿也不是恒红。

## 五、两处**必须先说清**的口径问题（不隐去）

1. **`base` 池的 0.0476 全部来自两个一次性点**：0.5238（整个实验的最第一次运行）
   与 0.5714（`sg05` 偶然拿到 1 格）。去掉这两点，base 9 次全是 0.5595，噪声为 0。
   ⛔ 这个方向是**保守**的（噪声越大越难 `KEEP`），但不能反过来读成
   「base 的抖动就是 0.0476」。
2. **0.6905 不是「超过 §43.3 预判的 0.6786」**：

   | | 基线 | 增益 | 结果 |
   |---|---|---|---|
   | §43.3 预判 | 44 格 | +13 | 57 格 = 0.6786 |
   | 实测 | **47 格** | **+11** | 58 格 = **0.6905** |

   差 3 格恰好是 `sg02` 的预热抖动（7→10）。**基线取法不同，不是判据比预判更强。**

### 关于 `default2_contract_run.log`（§43.12 的那一发）

它回答的是「`KEEP` 之后若要落默认值，契约层要付多少」——答案是 **0 条断言**。
⛔ 但它**不能**用来声称「撤回态也验过了」：同一次尝试里 `bench/withdraw_check.py`
启动时把手改的默认值当成**残留变异**还原成了 `0`（日志首行
`↩️ 启动先还原 1 个残留变异文件：['mw/config.py']`）⇒ 那次基线是**默认值 0** 下跑的。
`promote` 必须是一次真实提交 + 一次 159 条全量撤回重跑，本轮没做。

池子**不对称**：base 11 / cand 10 / placebo 5。
base 与 cand 的池子跨了两次驱动器调用（§43.9 与本节），
按 `(臂, sig)` 分池后各自 ≥ `MIN_RUNS=5`，且 `sig` 逐条相同 ⇒ 合并合规。
⚠️ 这也意味着 **cand 的 10 次 = 同一配置跑了两轮**，结论更强（轮间 0.0000）。

## 七、边界

1. 单模型（qwen2.5:7b 本地）、T=0、6 题 × 14 用例 = 84 格。
2. **效应只有一题**（`sg01`）。这不是「普遍变好」，是「那一条判据正好看见那一处错」。
3. `sg05` 恒 0 ⇒ 与 §43.3 的预判一致（类型错，静态判据看不见）。
4. ⛔ **`KEEP` ≠ 「内核会自己变强」**：它是「一个候选在**这一套 6 题**上分开了」。
   内核对判决的**接受**（改默认值）还没发生 —— 那是 §43.12 的待拍板项。
