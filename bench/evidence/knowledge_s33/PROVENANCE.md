# §17-7e 证据档案 —— 题面**显式指向记忆**（第三十三轮，2026-10-19）

> 一句话：题面只把 `按本项目定下的` 换成 `按记忆里记着的项目`（每题恰好一处、+2 字），
> 三臂里的 **H 臂第一次不是 0**：`g7d2` 从 **0.20 → 1.00**（3/3 repeat 逐位相同），
> 而 P 臂（**逐字等长**的骨架安慰剂）与 E 臂（空库）**全部 0.20**。
> ⇒ 这 0.80 的位移**有内容来源**，不是长度、不是位置、不是"多了一堆字"。
> 但 **4 题里只有 1 题动了** —— 这是"通道可用"的存在性证明，不是"通道好用"。

⛔ 本轮 H 臂 facts 是**手写惯例**（不是蒸馏产物）⇒ 这是**通道容量**测试。
读数**不许**写成"系统学会了"。

## 0. 本轮要回答的问题（事前登记见 DESIGN §17-7 ★7e）

7d 已把"送到没送到"排除（惯例逐字在 state 里），但 7d 的题面**没有一个字指向记忆** ——
模型完全可以把"按本项目定下的惯例处理"读成"按你的常识"。
7e 只改这一件事：题面**显式指向记忆**，其余一个字节不动。

## 4. 机制（交付代码原文，来自跑后库 `episodes(kind='finish')`）

三臂三次的 `dedupe_keep` 原文（`final_{arm}_r{1,2,3}.db` 可复算）：

| 臂 | 交付 | 判定 |
|---|---|---|
| H ×3 | `x_normalized = x.strip().lower()`，按归一化键保留**首次**那条原文 | 1.00 |
| P ×3 | `seen=set(); [x for x in xs if not (x in seen or seen_add(x))]` | 0.20 |
| E ×3 | 与 P 逐字相同 | 0.20 |

⇒ **P 臂与 E 臂逐字相同**，而 H 臂三次也逐字相同 ⇒ 位移来自**内容**，
与"上下文里有一堆形状对的东西"（7c 的存在性效应）无关。

另外三条（H 与 E 的交付**逐字相同**，都是模型默认写法）：

| 题 | 交付（H 与 E 相同） | 记忆里的惯例 |
|---|---|---|
| `g7d3` | `return "{:,.2f}".format(x)` | 空格千分位 + 圆括号负数 |
| `g7e1` | `('true','yes','1') → True` | `true/on` 一律算**假** |
| `g7e2` | `s[:n] + '...'`（保留头部） | 保留**尾部** + `…` |

## 5. 归因边界（必须与结论一起读）

- **只有 1/4 题动了**。Δ_H=+0.20 全部来自 `g7d2`；其余三题 H 与 P、E 三臂同为 0.20。
- 与 7d 的 D1′（把惯例写进**题面**，诊断臂，不进判据）并排读：

  | 题 | D1′ 指令位 (7d) | 7e 记忆位 | 本轮读法 |
  |---|---|---|---|
  | `g7d2_dedupe_keep` | 0.00（`yield` 写崩） | **1.00** | 记忆位反而做对了 ⇒ "写崩"是位置相关的偶然，不是能力墙 |
  | `g7e2_truncate_tail` | 1.00 | 0.20 | **能力够、但不采用** ⇒ 干净的"记忆不当约束"样本 |
  | `g7e1_parse_flag` | 0.60 | 0.20 | 部分能力 + 不采用，混在一起，**不归因** |
  | `g7d3_fmt_amount` | 0.00（非法格式串） | 0.20 | 两处都过不去，**不归因** |

  ⛔ D1′ 是另一个题面 ⇒ 不是同一把尺子；**只用于定位断点，不参与任何 Δ**。
- ⛔ 不许把 `+0.20` 读成"记忆通道有效"：它只是"**指向记忆时**，通道能把 1 条惯例
  送进决策并改变行为"的**存在性**证明。
- ⛔ 7d 与 7e 的读数**不可比**（题面被改过）。本轮不做跨轮 Δ。

## 6. 复算方法

```bash
# 判读（R1 → R7 → R-noise → R3a/b/c）
python3 bench/probe_g7d.py --evidence bench/evidence/knowledge_s33 \
        --heldout bench/heldout/g7e_hint_heldout.jsonl

# state 层送达（零模型调用）
python3 bench/probe_g7d_state.py --seed bench/evidence/knowledge_s33/seed_H.db \
        --heldout bench/heldout/g7e_hint_heldout.jsonl

# 题面派生（反向校验）
python3 bench/build_g7e_hint.py --base bench/heldout/g7e_heldout.jsonl \
        --out /tmp/again.jsonl     # sha 应为 696d812d4d25a876…

# 交付代码原文
sqlite3 bench/evidence/knowledge_s33/final_H_r1.db \
  "SELECT content FROM episodes WHERE kind='finish' AND content LIKE '%dedupe_keep%'"
```
