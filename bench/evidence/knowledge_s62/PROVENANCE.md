## 二、AZ47：核对器（`bench/check_counts.py` + `run_tests.sh` 步骤 3b）

**为什么不做成契约断言**：被核对对象里就含"契约这次跑出多少条"，断言自己也在那个数里
⇒ N 与 N+1 自指。AZ44 上一版 `and "535" in _az44_head` 就是这个结构的实证
（加一条断言就红 ⇒ 只能改判据去迎合实现）。⇒ 数值核对下移到**被测集合之外**。

**扫描范围**：只扫活文档 `README.md` / `demo/README.md`。
⛔ 不扫 `DESIGN.md` 与 `bench/evidence/**/PROVENANCE.md` —— 它们是**历史台账**，
每个数字记的是**当时**的实测值；按今天的真值去改历史 = 伪造记录。

**量具两版（第一版在 README 上误伤 5 处）**：

| 误伤 | 句子 | 结构理由 | 修法 |
|---|---|---|---|
| `6 条断言` | "（6 条断言里稳定挂 2 条）" | 某道题内部 | 撤掉泛规则 `(\d+)\s*条断言`，改为"契约"须在 ≤6 字内 |
| `17 条断言` | "15 条入口覆盖 17 条断言" | AS 组内部覆盖率 | 同上 |
| `6 条断言` | "（4 题 × 6 条断言）" | 题集结构 | 同上 |
| `448 条契约` | "⛔ 三个禁止的读法：… `448 条契约` = 能力更强" | **引用**历史值 | 反引号/数字前不认：`(?<![\d`])` |
| `95 条撤回态` | "（95 条撤回态：AS / AE / AT …）" | 某几组的**子集清单** | 冒号前不认：`(?!\s*：)` |

⇒ 五条"不认"全部是**结构**理由（引用 / 子集 / 题内），不是"这行懒得改"。
放回泛规则等于让工具去改历史台账。

## 三、AZ48：D-a 的回归锚（契约 535 → 536）

根因是结构性的：`_data_path` 原本是 `main()` 里的**闭包** ⇒ 测不了（这正是它当初没锚的原因）。
⇒ 提到模块级 `run.data_path(rel, root=None)`，生产路径一步不变。

四条件（①②③ 里**只有①有判别性**）：

| 条件 | 形态 | 说明 |
|---|---|---|
| ① 当前目录优先 | 两处都有 | ★ 兜底优先的实现会读到包目录那份 ⇒ 红 |
| ② 包目录兜底 | 只有包目录有 | 修之前的行为不许丢 |
| ③ 都没有 ⇒ 返回包目录下那个不存在的路径 | 都没有 | 不造假文件、不把报错指向当前目录 |
| ④ 显式 `--suite` / `--scorer` 不进兜底 | 静态（`_code_only` 去注释后比对） | 悄悄换路径 = 比报错更坏的假成功 |

**牙（反证 `neg_az48_contract.log`）**：把优先序倒过来 ⇒ `PASS=535 FAIL=1`，
红的**只有** AZ48。还原后 536/0。
