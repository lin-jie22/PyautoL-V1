## 1. 一句话

**「改完自己跑一遍、把新失败喂回去」这个回路，在 7B 上 16 条里 14 条只跑了一轮就自锁。**
最终 6/6 = **0/16**（首轮也是 0/16）。

## 2. 装置

首轮提示与 v245 的 B 臂**逐字节相同**（`2307 bytes` / `sha=1bdea4fc92d67817`，
装置在启动时 `assert` 了这一条）。差别只有回路本身：

```
轮 0：给人看的那份（起点 + why + actuals + 轨迹）
轮 1..2：喂**它自己上一轮的产出**，失败断言与轨迹**重算**
```

「照抄即停」：若新一轮代码与上一轮**逐字节同**，则下一轮 prompt 也会相同
⇒ 确定性装置上必然同产出（§305 的「同 prompt ⇒ 同码」，3/3 逐字节），
所以到此为止并记 `stalled=True`，不空烧调用。

## 5. 为什么回路不转：自锁是定律，不是 bug

14/16 的路径完全相同：

```
轮 0 产出 == 起点（照抄）
⇒ 轮 1 的输入与轮 0 完全一样（同一份代码、同一失败、同一轨迹）
⇒ 轮 1 产出 == 轮 0（§305 定律）
```

⇒ **一个不改变输入的回路不是回路。** 自修闭环要真转，前提是提议者**真的改了**；
7B 在 5/16 的情况下才改（v245 的 B 臂同数），而改对的条件概率是 **0/4**（v245 §5.3）。
回路的价值因此是两项乘积：

> 命中率 = P(真改) × P(改对 | 真改) = (5/16) × 0 = **0**

加轮数不改变第二项。这就是为什么「多跑几轮」在本装置上是**零**而不是「少」。

## 7. 结论

- ⛔ **「多轮自验」不是 7B 上这个缺口的解**：0/16，且 14/16 在结构上就没有第二轮。
- ⭐ 结构性结论：**确定性提议者 ⇒ 自验回路退化为单轮**。
  这条比分数重要：它说明「loop 次数」这类设计在本装置上不是可调参数，
  除非先让提议者**必然产生差异**（这才是「探索」该解决的问题）。
