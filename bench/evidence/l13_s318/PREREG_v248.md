## 0. 为什么是这一轮

v247 把四条轴全否掉了：换措辞（0/48）、加反馈（0/16×3）、加回路（0/16，自锁 14/16）、
换动作（自述回喂，0/16，照抄率反升）。缺口写成「**说与做零接合**」。

但 v247 之后新增了一条**装置层面**的读数，它把缺口改写得更具体：

> **第 16 行与第 23 行逐字节相同**（`minutes = int(parts[1].split('m')[0])`），
> 而第 16 行是错的、第 23 行是**对的**。
> v247 的 7 条非照抄产出，全部落在 19~24 行 —— 也就是说，它改的是**正确的那一处**。

配套的两条实测（§9 有读数）：

| 动作 | verify |
|---|---|
| 起点 | 5/6 |
| 只把**第 16 行**换成 `minutes = int(parts[0])` | **6/6** |
| 只把**第 23 行**换成同一句 | **4/6**（把对的改坏） |
| 第 16 行换成 `minutes = int(parts[0]) * 60` | 5/6（与第 17 行重复乘 60） |

⇒ 这是一个**单行、单表达式**的最小修复；而且「改哪一行」和「改成什么」**各自都能单独判对错**。

## 1. 外部依据（本轮查到的四条，按对本装置的直接程度排序）

| 来源 | 读数 | 对本轮的作用 |
|---|---|---|
| **arXiv 2606.00476**《Doing What They Say, Not What They Reason》 | 把忠实性拆成「推理→结论」与「结论→行动」两步。**显式 `DECISION:` 标签下，结论→行动不一致率 0.7%（Haiku）/ 1.4%（DeepSeek）**；从自由文本解析同一件事则是 22–26%，作者判定后者是**测量伪影**。另：动作空间是 fold/call/raise 三选一 | ⭐ 我们的动作空间是「重写 26 行 Python」，比三选一大了几个数量级。**显式标签路线我们从未测过** |

| **Over-editing / Edit Fidelity**（NUS，400 个注入 bug 的函数） | 50.2% 的最小修复只需改 **1 个 token**，91.8% ≤2 个 token；加一句保守编辑约束（*make only the necessary changes… preserve the original code*）使 Excess Levenshtein **0.195→0.131**，Pass@1 **+2.3pt** | 说明「只改必要处」这条约束在**更大模型上有效**，我们从未在 7B 上试过（v247 的指令是「只改那一处，不要整篇重写」，但它仍然整篇输出 ⇒ **措辞约束不住输出形态**） |

这就是本轮的唯一自变量。

## 2. 本轮唯一自变量：**输出形态**

⛔ 这一轮**不加任何新信息**。三条提示里的题面、代码、`why`、`failed_actuals`、`trace_failure` 完全相同，
v248 的 A 臂与 v247 的 A 臂**逐字节相同**（`2307B / 1bdea4fc92d67817`，preflight P1 已断言）。

⚠️ 必须先说清一件既存事实：**`trace_failure` 的输出里本来就有行号**
（`第 16 行 | minutes = int(parts[1].split('m')[0])   [⇒抛出=ValueError: …]`）。
所以「给它坐标」这件事 v247 已经做过了 —— 本轮**不是**「给坐标」，而是
**把「承诺」和「执行」压进同一个输出，并让装置代替它落地**。

## 3. 三臂

| 臂 | 输入 | 模型输出 | 装置动作 | 期望 bytes / sha |
|---|---|---|---|---|
| **A** | v247 A 臂逐字节 | 完整函数（```python 代码块） | 无，直接 verify | `2307` / `1bdea4fc92d67817` |
| **N** | A，但【当前代码】段换成**带行号**（`{n:3d}\| 原文`） | 完整函数 | 无 | `2437` / `8dc7c93d24b6d955` |
| **E** | 同 N 的输入，**输出要求段**整段替换 | **只两行**：`LINE: <n>` 与 `EXPR: <语句>` | `apply_edit(code, line, expr)` 单行替换 | `2615` / `60f2cc5e63c54255` |

- **A vs N** 分离「代码带不带行号」（一个变量）。
- **N vs E** 分离「输出形态：整函数 vs 两行标签」（一个变量，**本轮主臂**）。
- 构造校验（全部在 preflight 里断言，不是声称）：
  `N.replace(带行号代码, code, 1) == A`；`E.replace(TAIL_E, TAIL_A, 1) == N`。

### 3.1 E 臂的输出要求段（逐字节）

```
请顺着轨迹找到**第一处**让结果偏离题意的逻辑，只改那一处。
【输出格式】不要输出代码块，不要输出完整函数。**只输出两行**，严格如下（Line 用上面给的行号）：
LINE: <行号，纯数字>
EXPR: <把那一行整行替换成的 Python 语句；不要写行号，不要写缩进>
【硬约束】除这一行外**任何一行都不许改**——脚本只会按你给的 LINE 替换那一行，其余字节原样保留。你若想改别处，改了也不会生效。
```

最后一句是本轮的设计要害：**不是请求它别改，是让它改了也不生效**。
这正是「surgical diff patching」与「过度编辑」两条材料共同的做法 —— 把约束从措辞搬到执行层。

### 3.2 装置口径（`apply_edit`，fail-closed）

| 情况 | 判为 | 计入分母？ |
|---|---|---|
| `LINE` 解析不出 | `parse_fail` | ✅ 计入 16 |
| `EXPR` 为空 | `empty_expr` | ✅ 计入 16 |
| `LINE` 越界 | `oom` | ✅ 计入 16 |
| 替换后 `ast.parse` 失败 | `syntax_fail` | ✅ 计入 16 |
| 正常 | `ok`，交给 `verify` | ✅ |

- **缩进由装置补**：`新行 = 原行前导空白 + EXPR.lstrip()`。⛔ 不让模型负责缩进，否则「缩进写错」会被算成模型结论（纪律 108/111 的同型错误）。
- 判分只用 `mw.reflect.verify`（生产同一函数、同一份 6 条断言）。

## 4. 判据（唯一一行）

**主判据**：`E_6of6_over_16` ＝ E 臂经装置替换后 `verify == 6` 的条数。

| 值 | 判定 |
|---|---|
| **≤ 1** | **不成立** |
| 2 | **UNKNOWN**（压线，不选边） |

⛔ 不许改用「E 比 A 好」当主判据（v247 已立纪律：主判据不能改写成相对值）。

**押：不成立（≤1）。**

押注的两侧都写出来，免得只挑对的那半：

- **押不成立的依据**：v247 的 A 臂提示里已经**一条不缺**地给出了

  它仍然 0/16，且 7 条非照抄全改在**第 23 行（正确的那行）**。
  信息完整而行为不动 ⇒ 缩小输出不增加信息，凭什么会变。
- **押错的依据（这条必须写）**：v247 要它维持 26 行的全局一致，E 只要它维持**一行**。
  2606.00476 量到的 0.7% 正是在「三选一标签」这种小动作空间里。

## 6. 结局映射（读完 16 条之前不得改）

| 结局 | 立案 |
|---|---|
| **E ≥3**，且 `LINE=16` 占多数 | 缺口 = **动作空间 / 执行包装**。装置接得上 ⇒ 可接 `--goals-swap` 新档（**默认 off**）。⚠️ 必须同时写：**这是装置接通的，不是模型自己接通的** ⇒ ⛔ 不许说「自省补上了」 |
| **E ≤1**，`LINE=16` 占多数，`EXPR` 全非 `parts[0]` | **同一个输出内也说做不一**：承诺与落笔在同一段文字里就对不上 ⇒ 比 v247「跨生成断裂」更硬，瓶颈在「断言→token」这一跳 |

| **E = 2** | **UNKNOWN**，只报「压线非零」，不加样本凑结论（纪律 105） |

## 7. 成本与执行

- 7B、`T=1.0`、`max_tokens=900`、每臂 16、i 外层臂内层 **A→N→E**（同一 i 的三次生成时间相邻）。
- 生成次数 48（E 臂实际只吐两行，极短）。**零付费**，纯本地机时，预计 10~15 分钟。
- 速度闸沿用纪律 116：中位 **<15 tok/s 不启动**；单次 >300 s 停。
- ⛔ 逐条 `flush=True` 打印（纪律 216）。
- ⛔ **必须落 `cand` 全文**（A/N 的完整产出、E 的原文本 + 替换后的完整代码）——
  v245/v247 各踩过一次「只落 sha」（纪律 227）。

## 8. 边界（跑之前就写死，防止事后扩大解释）

1. **单题**（`t01`）、**单起点**（`90579ece`）、**单模型**（7B）。14B 未测。
2. **单 bug 类型**：值计算（`parts` 下标选错）。谓词/控制流型 bug 未测。
3. E 臂的坐标系依赖**输入带行号** ⇒ 「带行号」本身的效应由 N 臂隔离；若 N 与 A 差很多，
   本轮的 A vs E 对比就不能直接读，要报 A→N→E 三段。
4. ⛔ 不写「自省补上了」「闭环通了」「L3 完成」「内核会自己变强」。
5. ⛔ 若 E 成立，也不许把它写成「模型学会了自我修正」——装置执行的部分要单独计数。
