## 0. 为什么这一刀不是「跨题回灌」

上一轮登记的下一刀是「`z02`+`g7t4` 同失败类别累积实验（`--use-reward` 开/关）」。
本轮开局先复核它的前提，读到两件事，**前提倒了**：

1. **回灌的剂量是空的**。`mw/worldmodel.py` 的 `reward_guidance` 只把失败归到**类别**，
   再查 `_ERROR_CLASS_CHECK` 的**人写模板**。实测（`l18_s324/dose_v254.json`）：
   - 13 格里 `SyntaxError` ×2（`z02`/`g7t4`）、`ModuleNotFoundError` ×1（`m03`）
     **在模板表里没有键**，`_error_class()` 把它们归成 `其他`；
   - 而 `其他` 与 `AssertionError` 的检查句**逐字相同**
     （「用题目给出的示例输入，把当前实现手算一遍」）⇒ 11/13 格收到的**可执行文本完全一样**；
   - 74 个过门槛的有序对里，没有任何一对让目标格读到自己的病因。
   ⇒ 用这套剂量测「累积有没有牙」，等于拿一句与病因无关的话当自变量。

2. **更硬的墙在轮内**。V253 的日志（`run_a.log`）显示：13 格里
   **3 格（`z02` 3 次、`t04` 2 次、`g7t4` 2 次）已经被投喂过精确失败原文**：

   ```
   🧪 自检未过（第 1/2 次打回） ⇒ 退回重写：1/5 项未过：
      编译失败 line 4: unexpected character after line continuation character
      ⇒ return f'"{cell.replace(\"\", "\"\"")}"'
   ```

   三次都带**出错行原文**，模型三次（`z02`）都没改对，最后 `done_unverified` 交付。
   ⇒ 「跨题一句类别提示」比这个剂量**严格更弱**。先测更弱的剂量，结论无从解释。

**所以本轮改测可修性上界**：把 V253 交付的那份代码原样放回，
加上**打分器自己给出的那条失败断言**（一字不改），看模型能不能修。

⛔ 这是**上界**，不是可部署机制：真实部署没有打分器。
它的用途是**给累积通道定天花板** —— 若连判定原文都修不动，任何通道都不必谈。

## 2. 判据（跑前钉死，事后不许改）

- **P0 闸**：3 次真实生成的速度中位 **≥ 15 tok/s**；打分器能加载并对
  `oracle/partial/null` 三档复现 V253 的 1.0/中段/0.0。任一不过 ⇒ `NO_RUN`，不改门槛。
- **P1 剂量存在**：13/13 的 B 提示里**逐字节包含**该格的 `first_failing_assertion`；
  13/13 的 A 提示里**不含**（子串判「不含」需防相邻数字，纪律 233）。
- **P2 主判据（可修性）**：`Δ = #{格 : score_B > score_A}`。
  - `Δ = 0` ⇒ **「给定判定原文也修不动」**（负向 / 空结果，立案）；
  - `Δ ≥ 1` ⇒ 该格是**可修格**。
- **P3 归因（只在 Δ ≥ 1 时判）**：每个可修格必须满足
  「B 的分数增量 = 那条断言由 fail 转 pass」，用 `vec` 逐位对拍；
  增量若来自**别的断言**（B 顺手改坏/改好别处）⇒ 该格不算可修，记为 `offtarget`。
- **P4 内容 vs 措辞**（条件臂 C，只在 Δ ≥ 1 时跑）：
  C = 与 B **同模板等长**，但断言换成**另一格**的失败断言（内容无关、形态相同）。
  要求 `score_B > score_C` 才算「内容起作用」；若 `B ≈ C` ⇒ 结论降级为
  「多给一条断言这件事本身」而不是「给对了那条断言」。
- **P5 n**：每臂每格**一次生成**，按 `sha256` 报唯一数（T=0 下单次不可复现性见纪律 244）。
  `Δ ≥ 1` 时对**可修格**补跑一次 B，要求同 sha；不同 sha ⇒ 该格 n 记为 1 且标注不定。

**决策规则（事先写死）**：
- `Δ = 0` ⇒ 累积通道在本分母上**没有基底**，下一刀不再投在「回灌」上；
- `Δ ≥ 1` ⇒ 可修格构成累积实验的**真分母**（只有它们值得被通道救），
  并对这些格跑 §4 的 C 臂。

## 3. 闸未过时怎么办（纪律 234）

- 速度中位 < 15 ⇒ `NO_RUN`，不降门槛；等冷却 5 分钟复测一次，仍不过则整轮作废。
- 打分器对三档复现失败 ⇒ `NO_RUN`（尺子变了，跨轮不可比）。
- 单次生成 > 300 s ⇒ 该格记 `timeout`，**不进分母**，并在结果里单列。
- 任一格产物无法解析成代码（空/截断）⇒ 记 `empty`，不进分母，不补跑。

## 4. 已知边界（预注册时就写，防事后美化）

1. **这是开卷上界**：断言来自打分器，真实部署拿不到。结论只能说「上限在哪」。
2. **测的是模型，不是内核**：直连没有重规划/自检/工具，与 V253 的内核读数**不可直接比分数**，
   只能比**臂间差**。
3. **臂 A 与 B 的提示长度不同**（B 多一行）⇒ `Δ > 0` 先归因到「多了一行」，
   由 C 臂拆分；`Δ = 0` 不受此影响（多一行都没动）。
4. 13 格里 `z02`/`t04`/`g7t4` 在轮内已被投喂过同类原文且失败；
   若 B 臂对它们仍为 0，则该结果**与内核读数一致**，不构成新证据，只作校准。
