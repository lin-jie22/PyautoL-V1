这一问直接服务主线：V254 量到 **10/13 格自检 0 打回**（闸看不见），


## 2. 变量与测法

**自变量**：无。**因变量**：自造测试对本格答案的判决。

每格三次生成（T=0，各一次）：

| 产物 | 怎么来 | 用来判什么 |
|---|---|---|
| `sol.py` = V253 答案（`bare_code` 归一） | 既有产物，不再生成 | 被测对象 |
| `selfcheck.py` = 模型只凭**题面**写的自测 | **1 次生成/格** | 判决器 |
| `sol.py` ← `oracle` / `partial` | 题集自带 | **对照**：好测试必须放过 oracle |

判定：`python3 -c "import selfcheck; selfcheck.check()"`，`rc=0` = 通过，非 0 = 抓住。
超时 15s（超时按"抓住"计，但单列 `timeout`，见 §4-③）。

**给模型的提示（逐字固定，跑后不许改）**：

system：
```
你是测试工程师。只输出一个 python 代码块，不要任何解释。
```
user：
```
题面：
{spec}

请只根据上面的题面，写一份自测脚本，用来检验一份实现是否满足题面要求。

格式要求：
- 输出一个 Python 模块，定义 `def check():`；函数体里用 assert 检查题面明确规定的行为与边界。
- 被测实现已保存在同目录的 `sol.py` 中，直接 `from sol import <题面要求的名字>`。
- 不读文件、不联网、不用 time / random。
- 只输出代码，不要解释。
```

⛔ 提示里**不含**任何答案、不含「这份实现是错的」、不含该格的判定原文。

## 3. 预测（三值 + 方向，跑前押）

| # | 判据 | 押 |
|---|---|---|
| **M1（主）** | `valid` 格里被自测抓住的格数 `caught` | **`≤ 3`**（共享盲区：自测与代码同一个误读 ⇒ 测试照样通过） |
| **M2** | `valid` = 自测**放过 oracle** 的格数 | **`≥ 7`**（题面是 `spec-inline`，合格的自测应当能放过正确实现） |
| **M3（定性）** | 被抓住的格里，报错信息是否落在题面**明写**的那条行为上 | 逐条落原文，不做统计 |

**判据极性**（纪律 76）：我押的是「自测大面积无效」。
⇒ `caught ≥ 4` 时**我押错**（这条上策成立，自检可扩面）；`caught == 3` **压线自报**（纪律 91）。

## 4. 闸与例外（跑前写死）

1. **速度闸**：三次测速取中位，`< 15 tok/s` ⇒ `NO_RUN`，不读数、不降门槛（纪律 116/234）。
2. **尺子校准**：9 格 `oracle=1.0 / null=0.0 / partial<1.0` 任一不成立 ⇒ `NO_RUN`。
3. **`valid` 不足**：若 `valid < 5`，M1 只在 `valid` 上报，并**不给方向结论**——
   因为此时"抓住"少可能只是测试写坏了，不是盲区（两种解释不可分）。
4. **假抓必须单列**：测试**对 oracle 也失败**却"抓住"了答案的格，记为 `false_catch`，
   **不计入 M1**（那是测试自己错，不是发现了缺陷）。
5. **超时单列**：`timeout` 计入"抓住"但在表里标出来；若 `timeout ≥ 2`，
   M1 需同时报"扣除超时后的 caught"，因为死循环既可能是答案的缺陷（无限循环），
   也可能是测试自己写错。

## 5. ⛔ 边界（不许越界读）

1. ⛔ 不说「自省补上了」「系统会自己变强」：本轮只测**判决器**（能不能发现自己错），
   不测**修复**（发现了改不改得动——那是 V254 已量到的 1/13）。
2. ⛔ 不说「自测是有效验证手段」：`caught` 只说明"这份测试对这份答案报了错"，
   不说明报的是**对的那条**（M3 只做定性，样本小到不能外推）。
3. ⛔ 不把 `oracle` 的通过率当"测试质量"的充分证据：过 oracle 只排除"测试与题面矛盾"，
   不排除"测试只覆盖了显然情形"。
4. ⛔ 不把这 9 格的结论外推到 39 题：`caught` 只在 9 格上量，其余 26 格本来就是 1.0，
   没有"错"可抓 ⇒ 分母不是 39。
5. ⚠️ 若模型写的自测**要求题面没写的惯例**（如 `g7d` 那类），它在 `spec-inline` 题上
   就是**测试自己错**——这正是 `false_catch` 要单列的原因。
