# V185 预注册：arity 硬约束 + 回错带算子名 + 一次重选

> 接 §252.8 第 1 条与第 2 条。**跑前写死，跑后只许登记、不许改判据。**

## 零、本轮是什么（以及为什么把两条并成一轮）

§252.8 第 1 条要「arity 硬约束 + 回错带算子名 + 一次重选」，第 2 条要「检查顺序：
先 `reachable` 再 types 长度」。

**合并的理由（⛔ 不是为了跑得快）**：V184 的 A4 假阴就是分类顺序造成的 ——
`g7d2`（一元函数）选了 `TAIL`（二元算子），`validate()` 先判 `len(types)==n_args`
（1==1 通过，因为模型只填了 1 个类型），再撞上 `TAIL 需要第二个类型是 int` 那条特判，
于是返回的句子说的是**类型**，不是**参数个数**。要「回错可行动」，第一步就必须让分类器
**先比 arity**；否则回给模型的话本身指错了方向。

⇒ 两条共用同一段代码，分开做要写两遍分类器。**合并执行，合并登记**（本文件 §一~§三）。

⛔ 本轮**不动**：算子库（§252.8 第 3 条）、记忆注入（第 4 条）、模型、温度、题集、尺子。

## 一、装置改动

| 位置 | 改什么 | 不改什么 |
|---|---|---|
| `mw/critgen.diagnose()` | **新增**。返回 `{ok, code, msg, need, got}`；`code ∈ {KIND, ARITY, TYPES, SLOT, OK}`，优先级 **KIND → ARITY → TYPES → SLOT** | — |
| `mw/critgen.validate()` | **逐字不动**（`AZ145c` 仍钉原串）。它只回答「过/不过」，`diagnose()` 回答「为什么」 | 门槛不变 |
| `bench/.../arms_v185.py` | 新增 `typed_retry` 臂：首次 `diagnose().ok == False` 时，把**结构事实**回给模型，**只一次** | 首轮 prompt 逐字复用 V184 常量 |

回错措辞（写死，`retry_hint()`）：

```
你选的是 {kind}，它要 {need} 个位置参数；本题函数只有 {got} 个。
{其余 msg}
可用算子：<目录，与首轮同一份>
请重选算子或修正 types / 槽，只输出一个 JSON。
```

⛔ **不许点名该用哪个算子**（那是答案）。`AZ146d` 钉这条：回错串里除模型自己选的 `kind`
之外，不得出现 `OPS` 里任何其它算子 id。

## 二、预注册（三值；按纪律 40 只押结构，不押个数）

| # | 押什么 | 判法 | 押 |
|---|---|---|---|
| **P1** | 首次 attempt 的分类：`g7d2` 的 `code` 是 **ARITY**（`need=2, got=1`），不是 TYPES；其余 7 题首次 `code=OK` | `diagnose()` 第一轮输出 | ✅ |
| **P2** | 重选只发生在首次 `code≠OK` 的题上；`retry_used` 的题集 **= ** 首次非 OK 的题集（集合相等，不押个数） | 逐题比对 | ✅ |
| **P3** | 重选后 `code` 变 OK，且第二次选的算子 `arity == n_args` | 逐题比对 | ✅ |
| **P4** | **`pass_oracle` 不增加**（V184 `typed` 是 2/8）：改选解结构不解语义 | 两臂逐题 | ✅（负向押注）|
| **P5** | 其余 7 题的 `(kind, pass_oracle, bite_partial)` 与 `typed` 臂**逐题完全相同**（零干扰） | 逐题三元组 | ✅ |
| **P6** | 判别力**不上升**（V184 是 1/8） | 汇总 | ✅ |

**判定**：P4 若上升 ⇒ 「结构≠语义」这条论断被否，必须点名是哪个算子、为什么。
P3 若失败（模型坚持同一算子）⇒ 登记「回错格式不够」，下一刀改成**只给 arity 相符的算子子集**
（更强的结构约束），单独立轮。

## 三、分母（纪律 67：结构不可达的成员不许混进比率）

8 题，其中 `g7e1`（返回 `bool/None`）、`g7d3`（缺金额 decode）在现有 6 个算子下
**oracle 过不了**。本轮**不补算子** ⇒ 与 V184 同口径，报 **8 题**与**剔除两题 6 题**两个分母。

## 四、成本与血缘

- 模型 `qwen2.5:7b`（本机 ollama），`V1_LLM_TEMPERATURE=0`；⛔ 不拿 14b 当结论。
- 调用：8 题 × 首轮 = 8 次，重选 ≤ 8 次（实际预计 1 次）。
- 两臂**同进程**跑：`typed` 是 V184 的逐字重放（同 prompt 常量），用来在**本次后端状态**下
  做对照 —— ⛔ 不拿 V184 的历史读数当对照（那会把后端抖动读成臂差）。
