## §0 为什么是这一轮

用户定的顺序是 ① 诊断改变判断（V189）→ ② 对弱点自己出题（V190/V191）→ ③ 多 agent。
② 已经收口，结论是「免费信息不能加答案」。按顺序该谈 ③ 了。

但在谈 ③ 之前必须先答一个问题，否则 ③ 会重复同一个错：

> V184~V191 八轮新增的 33 个公开函数，**在那条真的跑得起来的链路上，有没有一个调用点？**

这不是「工程洁癖」。如果答案是 0，那么「系统对弱点自己出题」这件事**只发生在测量装置里**，
部署时的系统仍然不会出题 —— 那 ③ 就是在给一个不存在的能力加并发。

⚠️ 本轮**不是**新实验装置，是一次**计数**。它的价值全在「把一个印象变成个数」。

## §1 命题

**Q1**：从 `run.py` 出发的导入闭包里，有哪几个 `mw` 模块？
**Q2**：`mw/critgen.py` / `mw/metacrit.py` / `mw/probe.py` 在不在那个闭包里（静态 + 动态）？
**Q3**：全 `mw/` 的公开函数里，有多少个在部署闭包内**零引用**？
**Q4**：部署闭包里有没有「采判据」这一步（= 这三个模块本来该有的宿主）？

## §2 口径（写死，⛔ 跑后不许改）

1. **部署闭包**：从 `run.py` 出发，沿 `import X` / `from X import …` 递归；
   只跟 `mw.*` 与仓库内顶层模块；跳过 stdlib 与第三方。
   相对导入按所在包解析。
2. **装置闭包**（正例对照）：同法从 `tests/contract_test.py` 出发。
3. **「被引用」**：闭包内任一文件的 AST 里，`Attribute(value=Name(id=<别名>), attr=<fn>)`
   或 `from mw.X import fn` 之后 `Name(id=fn)` 被使用。
   ⛔ 只算 AST 引用，不算字符串、不算注释、不算 `getattr` 动态取用。
4. **动态证据**（独立于静态）：`import run` 之后 `sys.modules` 里有哪些 `mw.*`。
   静态管「有没有写」，动态管「加载时有没有真跑」。

⛔⛔ **一条必须自报的口径陷阱**：若某模块不在闭包里，那么「它的函数被引用数 = 0」
**是定义推出来的，不是读数**。所以 P3 必须同时给两个独立证据（静态闭包 + 动态 `sys.modules`），
不许只报一个然后说「0 次调用」。（纪律 10 同型：数值对得上 ≠ 解释对。）

## §3 预注册判据

| # | 判据 | 押 |
|---|---|---|
| **P1** | 三个模块（critgen / metacrit / probe）在**部署闭包**里 | **0/3 在** |
| **P2** | `import run` 后 `sys.modules` 含这三个模块 | **0/3 含** |
| **P3** | 三模块 33 个公开函数，从部署闭包**可达引用**数 | **0** |
| **P4** | 从**装置闭包**（`contract_test.py`）可达引用数 | **> 0**（这是检测器的正例） |
| **P5** | 全 `mw/` 公开函数中，部署闭包内**零引用**的个数 | **≥ 5**（押结构：存在一批，不押精确个数） |
| **P6** | `mw/verify.py` 是否存在「按 (算子, 签名) 采判据」的入口（参数表出现 `kind`/`types`/`ops` 之一） | **不存在** ⇒ 宿主不是「没接」，是「没有」 |

### §3.1 反证（纪律 60：撤回没转红先证检测器看得见）

- **R1**：把检测器指向 `tests/contract_test.py`，P4 必须 > 0。若报 0 ⇒ **检测器瞎，本轮全部读数作废**。
- **R2**：往 `run.py` 临时加一行 `from mw import critgen  # noqa`，P1 必须从 0/3 变 1/3。
  若不变 ⇒ 闭包算法漏了 `from X import Y` 形态。⛔ 改完立刻还原，并 `git diff` 自证无残留。
- **R3**：P6 是**描述性**判据（我在押「没有」）。它押错（= 有入口）比押对更有价值：
  那说明宿主存在、只是没接线，③ 的地基是实的。⛔ 不许因为押错就改口径。

## §4 不做什么

- ⛔ 不跑 LLM、不跑 bench、不改 `mw/` 任何实现（只加契约锚）。
- ⛔ 不因为「0 引用」就去接线。⛔ 不看一眼读数就下「这四轮白做」的结论 ——
  量具也有价值，问题只在于它是不是**被误当成部件**。
- ⛔ 不说「L3 是假的」。要说的是「L3 的证据全部来自装置，部署面为 0」。
