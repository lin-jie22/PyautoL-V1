# V195 预注册：③ 多 agent 的第一格 —— 中继断在哪一层

日期：2026-11-18　⛔ 本文件写于**任何读数产生之前**。

## 0. 接上什么

用户定的顺序不可调换：① 诊断改变判断（V189）→ ② 对弱点自己出题（V190/V191）→ **③ 多 agent**。
③ 的第一步照 V192 的规矩办：**先量插座位，不先造**。V194 又补了一条：**先量再接**。

这一轮量的是最朴素的一件事：**一个外部 agent 的输出，能不能走到另一个外部 agent 的输入？**

## 1. 一个问题

> 部署链路里，中继（A 的输出当 B 的 task）断在**哪一层**？

三层必须分开报，因为修法完全不同、代价也不同：

| 层 | 断了长什么样 | 修法 |
|---|---|---|
| **物理** | 没有把上游送进子进程的通道 | 造管道（便宜） |
| **策略** | 通道有，但执行点把入参**写死覆写**成题面原文 | 改策略（要面对已实测的代价） |
| **契约** | 入参到了，但能力只认题面原文，拿到别的话就拒答 | 换能力契约（最贵） |

⛔ 混着报就会得出"加条线就行"这种结论——而这正是本项目反复踩的那一类错。

## 2. 本轮**不跑模型**

读数全部来自四处，无一需要 LLM 答案：

1. **AST**（静态）：`args["task"]` 的构造点与覆写点全库枚举；
2. **真 `dispatch`**（两个 shell agent，零模型）：证明管道通不通；
3. **真入口 + 记录器**：import `external/code_agent.py`，把 `_chat` 换成记录器 ——
   测的是**边界之前**（拒答 / prompt 组装），⛔ 不是生成质量；
4. **历史账本**：`bench_out/runs.jsonl` 171 个 run 的 `kernel_external`。

⚠️ 因此本轮**不许**出任何「多 agent 有没有用」的结论。它只定位断点。

## 3. 判据（跑前锁定）

| 断点 | 判据 |
|---|---|
| ① 物理 | A→B 真 dispatch，B 的 stdout 里出现 A 的 stdout ⇒ **通**；不出现 ⇒ 断 |
| ② 策略 | AST：存在 `cand.args = answer_task(goal, ...)` 且位于 `if spec.produces_answer:` 内 ⇒ **无条件覆写** |
| ③ 契约 | 5 种 payload 喂真入口：拒答（`题面里没有『函数名必须是 X』`）或进模型；进模型时记录 prompt 是否含上游文本 |

## 4. 押（三值：成立 / 不成立 / UNKNOWN；⛔ 不许事后改措辞）

| # | 押 | 判定 |
|---|---|---|
| P1 | **值构造点唯一**：给 `agent:` 的 `args["task"]` 生产**值**的地方全库只有 1 处（`core.answer_task`）；其余是 schema 声明/读取 | 成立 / 不成立 |
| P2 | **物理通**（正例对照）：A→B 传递后 B 输出含 A 输出 ⇒ 管道没有断 | 成立 / 不成立 |
| P3 | **策略断**：覆写点存在且**无条件**（只看 `produces_answer`，不看题面/上游） | 成立 / 不成立 |
| P4 | **契约不是硬墙**：把上游文本拼在题面前/后，仍进模型，且 prompt 含上游文本 ⇒ 「只认原文」只在**改写丢了函数名**时成立 | 成立 / 不成立 |
| P5 | **历史残差为 0**：171 run 汇总 `calls − used_as_answer − err == 0`（没有一次非交付调用） | 成立 / 不成立 |
| P6 | **检测器有牙**：同一中继检测器在「B 的 task = goal」时必报 0 | 成立 / 不成立 |
| P7 | **装置自检**：`_chat` 记录器 `calls > 0`（否则「没进模型」是检测器哑火），且 `code_agent.__file__` 指向仓库真文件 | 成立 / 不成立 |

⭐ P2 与 P6 是**一对**：只报 P2 不报 P6，等于没证明检测器能分辨"中继"与"没中继"（假绿纪律 5）。
⭐ P5 是**采样**读数，P1/P3 是**结构**断言 —— 两类不许互相冒充（V192 自踩：用定义冒充读数）。

## 5. 判据作用域（⛔ 越界即作废）

- 结论只覆盖「**外部 agent 之间**的中继」。
- ⛔ 不外推到「多 agent 无用 / 有用」，也不外推到内核内部的多候选、多角度。
- ⛔ 不把"部署里注册 1 个 agent"读成"多 agent 不可能"——`agents.json` 支持 N 个，这是配置面。

## 6. 这轮**不**做的

- ⛔ 不改内核一行（`mw/*.py` 不动）；证据脚本只用临时 `agents.json`，不碰仓库那份。
- ⛔ 不跑 bench、不跑 LLM、不出新题新尺子。
- ⛔ 不因为"管道通"就下结论"接上就行"；接不接是下一轮的事，且要另立预注册（V194 的价）。

## 7. 成本上限

AST + 6 次子进程（每次 ≤ 20s 超时，全部本地）+ 读 171 行 jsonl ⇒ **< 2 分钟**。
任一步崩掉 ⇒ 如实报「这一臂没读数」，⛔ 不拿定义补。
