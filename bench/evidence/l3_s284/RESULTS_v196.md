⛔ 不是"草稿帮助了模型"，是**模型把草稿当答案交回来了**，分数自然与原来逐位相同。

## 3. 事后对照 S：草稿的净效是 **−0.011**

预注册只有 N/R/P，而 **N 是内核的答案、R/P 是外部能力的答案** ⇒ `R−N` 把「换流程」和「加草稿」
混在一起。事后补第 4 臂 **S（题面原文，同一外部能力，不带草稿）**，并把 R/P/N 在**同一批有 S 的格**上重算
（⚠️ 纪律 46：分母不同不比 —— 初版我拿 23 格的 R 去比 22 格的 S，已改，见 §7）：

| 配对 `denom=22` | 均分 |
|---|---|
| N′ | 0.3106 |
| **S**（不带草稿） | **0.3591** |
| R′（带本题草稿） | 0.3485 |
| P′（带别题草稿） | 0.3515 |

| 差分 | 值 | 读法 |
|---|---|---|
| **S − N′** | **+0.0485** | **换流程本身就值 +0.049**（外部能力比内核自己写得好） |
| **R′ − S** | **−0.0106** | **草稿的净效为负** |
| P′ − S | −0.0076 | 安慰剂也是负的（但没那么负） |

逐格 `R−S` 只有两格非零：`t01_parse_duration` **+0.1667**、`k03_unflatten` **−0.4000**。

⭐ `k03_unflatten` 是本轮最干净的一格证据：**不带草稿 S=0.8，带了旧答案 R=0.4**。
同一个能力、同一道题、同一份题面，只多了"它自己上一次的答案" ⇒ 掉了 0.4。
这**不是**"中继没用"，是**中继有害**：草稿把模型锚在旧答案上（它照抄了）。

⇒ 草稿没有被丢在路上（⛔ 不是装置哑火，纪律 88）。

## 5. 判决

1. **③ 的「自己交自己」形态：判死。** 净效 **−0.011**、安慰剂反而更高、41% 的格是照抄。
   ⇒ **不改 `answer_task` 的覆写策略**（V195 说那是唯一断点；现在知道改了也不值）。
2. **值钱的是换流程，不是中继**：`S − N′ = +0.049`。这笔账属于**外部能力本身**
   （V193/§113 那条线的延续），⛔ 不算在多 agent 头上。
3. **照抄是这条路的第一道坎**：V195 的 A3 证明"上游能进 prompt"，本轮证明"进去了也多半被原样交回"。
   ⇒ 与 DESIGN §46.5 那条老读数（「这个模型强的是照抄步骤」）同形，这次是在**答案**上而不是判据上量到的。

## 7. 自踩 / 口径

1. ⛔ **分母不同就比了**：初版 S 块用 `mean(R)@23` 减 `mean(S)@22`，得出 `+0.0003`
   （看起来"净效正好为零"——最容易被当成结论的那种漂亮数）。改成**同一批 22 格配对**后是 **−0.0106**。
   纪律 46/47 的原话是"分母不同不比"，我在同一个脚本里犯了一次。
2. **S 臂 1 格未交付**：`k04_to_ini` 的 agent 自报「全部实现都编译不过 ⇒ 不交付坏代码」⇒ 无答案、无分数。
   它是**真实的拒交付**，不是装置错；因此 S 的 `denom=22`，且该格在 §3 表里被整体剔除（两臂同时剔）。
3. **S 与 C 是事后补的臂**（预注册 §7 明写"不碰满分格/只量 3 臂"）。
   S 用于解释，C 用于装置自检；⛔ 它们**不参与** §0 的 6 条押。
4. **照抄率是下限**：口径是"交回的答案 strip 后与草稿逐字相等"。改了缩进/句末标点的复制不算抄
   ⇒ 真实照抄率 ≥ 41.3%。
5. `elapsed_s` 每格 23~50s，总 18m40s（46 次）+ 10m（23 次）+ 4 次自检 ⇒ 与预注册 §6 的 60 分钟上限相符。
