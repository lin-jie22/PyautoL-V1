## 2. B2 前置：这个「诊断」到底是什么

23 格 R 臂的 `why` 里，**22 格**含 `assert <fn>(` 调用，**共 52 条**测试原文：

```
通过 4/6；失败: assert parse_duration('1h30m') == 5400 ⇒ AssertionError | assert parse_duration('abc') is None ⇒ ...
```

这是 `bench/scorers/code_exec.py:131` 一行造成的：`fails.append(f"{str(t)[:70]} ⇒ {why}")`。
`t` 是 `task["tests"]` 里的**隐藏测试**，题面里没有。

⇒ 同一段文本有两个身份：
- 对 `mw/worldmodel.py` 的归类器：**噪音**（前 60 字是源码，诊断埋在中间）；
- 对做题的模型：**答案**（`输入 → 期望输出` 全在里面）。

§82 当年按「噪音」修（归类成类别级检查），修得对。但它**没有量过**按「答案」这一侧值多少。

## 6. 判决

1. **`why` 是答案，不是噪音。** 硬接进去 = 均分 0.3232 → 0.5174，且**表面上无症状**（`echo=0`）。
   ⇒ ⛔ 任何「让系统看到自己失败原因」的设计，只要原因来自**评分器**，就是给尺子上浮。
   ⇒ 这条闸必须**永久关闭**，不是「本轮先不接」。
2. **现状是对的，但不是因为有防线，是因为没通路。** 207 次闸 0 命中、5 条通道 0 条带原文。
   ⚠️ 地雷在 `episodes` 表（160 字原文已落盘），靠 `recall()` 不查 `episodes` 挡着。已加锚。
3. **③ 的中继线双向判死**：
   - V195：策略不许传（答案型 agent 入参被覆写成题面原文）；
   - V197：**即使许了也没东西可传** —— 默认配置下打回只给「编译错误」或 27 字盲报。
   ⇒ 不是「缺一个开关」，是**两头都空**。
4. **顺带**：交付闸对功能错误 0 判别力（空实现 23/23 过闸）。这不是本轮的题，但它解释了
   为什么 `verify_exec` 在 V61 之后一直默认 0 —— 开着也只有 1/23 题有示例可跑。
