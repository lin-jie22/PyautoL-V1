# V198 预注册：交付闸在**真实作答**上有没有判别力

写于任何新读数之前。装置：`arms_v198.py`（零模型、零内核改动、零新答案）。

---

## 0. 为什么这一轮

V197（§265）顺带撞出一条：**函数名写对、`return None` 的空实现，23 题全部通过交付闸**（三档 `verify_static` 都是）。
当时它是副产物，没有对照、没有在真实答案上验。

V194（§262）已判死一个免费闸 —— 但那是我**自己造的** `--verify-impl`（8 题装置面）。
本轮量的是**部署路径上真正在跑的那个闸**：`mw/core.py:2058 _gate_finish`，
判据 `vfy.derive(goal, verify_static=2, verify_exec=0)`，默认 5 条：
`nonempty / defines / fence_lang / compiles / undefined`。

> 问：这 5 条判据，在**真实作答**上，能把「做对的」与「做错的」分开吗？

⛔ 不是重修这个闸，不是加判据，不是接线。只量。

## 1. 样本与口径

**池**：`bench/evidence/l3_s282/answers_v194.jsonl` 的 33 条答案原文（`chars` 48~731、`truncated` 全 0、无空串）。
它们的分数来自 `readings_v194.json`（同一次真跑、同一打分器）。**33 格 = 33 条**（去重后仍 33，V194 已按键 `(suite, id)` 校过）。

| 子集 | 格数 | 用途 |
|---|---|---|
| `score == 1.0` | 10 | **正例对照**：闸若拦它，就是误杀 |
| `score < 1.0` | 23 | 主样本：闸能不能挑出这些 |
| 其中 `score == 0` | 待测（事后登记） | 最坏假阳性 |

**臂**：

| 臂 | 输入 | 期望 |
|---|---|---|
| **G1** | 33 条真实答案 × 真闸（static=2, exec=0） | 主读数 |
| **G2** | 10 条满分答案**人为破坏**（各删一个必填冒号 ⇒ 语法/结构错） | 闸必须拦 ⇒ 证明闸不瞎 |
| **G3** | V197 的空实现形态（`def <题面函数>(*a, **k): return None`）× 23 题 | 复现「23/23 过闸」 |

⚠️ **G3 的函数名必须取自题面**（V197 自踩第 1 条：stub 名字写错 ⇒ 测的是"名字错时说什么"）。
取法：从题面正则抽 `函数名必须是 X` / `def X(`；抽不到的题记 `NO_FN` 并**从分母剔除**（报两个分母）。

## 2. 押注（全部三值：成立 / 不成立 / UNKNOWN）

| 号 | 命题 | 押 |
|---|---|---|
| **P1** | G1 里闸 **pass** 的格数 ≥ 30/33 | 押**成立**（它们本来就是过闸交付的答案） |
| **P2** | 满分 10 格 pass = **10/10** | 押成立 |
| **P3** | G1 pass 组里 `score < 1` 的比例 **≥ 50%** | 押成立（假阳性过半） |
| **P4** | `mean(score | pass) − mean(score | fail) ≥ 0.10` | 押**不成立**；若 `fail` 组为 0 ⇒ 判 **UNKNOWN** 并报分母 |
| **P5** | G2 破坏后 fail = **10/10** | 押成立（正例对照：闸能看见结构错） |
| **P6** | G3 空实现 pass = **23/23** | 押成立（V197 复现，装置自检） |

**必绿自查**（写预注册时已知会成立，判别力有限，价值在钉住）：
- S1：`vfy.derive(goal, 2, 0)` 的 `Check.name` 集合 = 5 条格式判据，**无一条 `kind == "example"`**（`verify_exec=0`）。
- S2：G1 的答案里 `def <fn>` 出现率 = 33/33（否则 `defines` 判据本身就不可比）。

⛔ **不做的事**：不改 `verify_*` 任何默认值；不加判据；不重跑模型；不接任何线。
⛔ **越界即作废**：本轮结论只覆盖「这 5 条静态判据 × 这 33 条答案」，不外推到 `verify_exec=1` 或别的题池。

## 4. 判据极性（先写清，免得事后改口）

- P3 **成立** ⇒ 闸的假阳性过半 ⇒ 「不能当筛选器」在**部署闸**上复现，V194 的结论从「我造的闸不行」升级为「这一类免费闸都不行」。
- P3 **不成立**（pass 组里 score<1 的比例低）⇒ 说明真实答案里做错的大多已被拦下 ⇒ 闸比 V197 的 stub 读数有用，必须如实改判 V197 的推论强度。
- P4 **UNKNOWN**（fail=0）⇒ 判别力按 **0** 记，并明写「不是闸准，是没有可比的两组」。
