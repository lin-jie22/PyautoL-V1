# PREREG V209（§277）：同题自评的**定向效应** —— 把算力从「题」移到「断言」

日期：2026-11-19　｜　装置：`bench/evidence/l3_s297/`　｜　先写后跑

## 0. 为什么要这轮

V208 的判决是「通道通了、收益测不出（Δ=+0.074 < 臂内极差 0.139~0.222）」。
它留了两个候选：① 关外包（改产品行为，需拍板）② 压方差（不改代码）。

本轮做 ②，但不是「同一件事再跑几遍」——那只会放大盲目性。要做两件结构性的事：

1. **把分母从「6 题」缩到「2 题」**：`coding_small` 里有 4 题在 T=1.0 下恒定满分
   （t02/t03/t05/t06），它们对任何改进都是天花板，占掉 2/3 算力却贡献 0 信息。
2. **把读数从「题分」下沉到「断言」**：评审原文点名的是**具体输入与期望**
   （`assert merge_ranges([(1,3),(2,6),(8,10)]) == [(1,6),(8,10)] ⇒ TypeError: 'tuple'
   object does not support item assignment`）。若模型真读了它，被点名的那几条断言应当
   先变，而不是「整题偶然过」。

⭐ 这同时回答了 V208 没答的问题：**提升是「照着改」还是「这题变简单了」**。

## 3. 功效（⛔ 先报可检测下限，再报效应）

单格 n=20，p≈0.5 时 SE=0.11。目标格合并后每臂 **80 个样本**，SE(差)≈0.05。
⇒ **MDE(α=0.05, 80% 功效) ≈ 0.14**。低于 0.14 的差本轮判「测不出」，不判「没有」。

## 4. 判据（押）

| # | 命题 | 押 | 否证条件 |
|---|---|---|---|
| P1 | 装置正面路径：`prev-self` 下两题都拿到自己的失败断言，`prev` 下都拿不到 | 成立 | 重放里出现 `own=·` 或 `rejected.self=0` 于 prev 臂 |
| P2 | 目标格 T 的通过率：**B > A**，且差 ≥ **0.25**（≫ MDE 0.14） | 成立 | 差 < 0.15 |
| P3 | C 臂与 A 臂在目标格上差 **< 0.15**，且 \|B−A\| > \|C−A\| | 成立 | C 也涨 ≥0.15 |
| P4 | 天花板格 C 上 **B 不比 A 差**（不劣于 −0.10） | 成立 | B 在已通过的断言上掉 ≥0.10 |
| P5 | 题分（每题 20 次均值）B > A | 成立 | B ≤ A |

P2 若成立且 P3 成立 ⇒ 「提升来自**本题自己的失败断言**，不是块本身」。
P4 若成立 ⇒ 「不是整体变强/变弱，是照着点名的那几条改」。
P5 是**与 V208 对齐用的桥**：V208 用题分判 UNKNOWN，本轮在同装置上重做题分，看缩小分母后能不能判。

## 5. 预注册的否证与降级

- 若 B 在目标格涨了但 P4 也掉（天花板格下降）⇒ 只能判「换了一种错法」，不判提升。
- 若 B 与 C 都涨 ⇒ 判「块的存在本身有效」，V208 的 n3≡n1 被推翻，需另立一轮解释。
- 若 B 只在 t01 涨、t04 不涨 ⇒ 登记为「按错误类型分化」，不合并成「同题有效」。
- 子集 `suite_sha` 与全量不可比 ⇒ ⛔ 本轮任何数字不得写进全量尺子（`coding_small` 0.9722 等）。

## 6. 已预知的装置缺陷（跑前登记，跑后逐条对账）

1. `--critique-file` 同时是**载入路径和写回路径** ⇒ 跑完会覆盖输入。V208 的 `critique_n2in.jsonl`
   就是这样被自己的输出盖掉的（现在里面 t01=0.8333 是 n2 的结果，不是它读到的输入）。
   ⇒ 本轮先把先验固化成 `prior_sub2.jsonl` 并另存 `prior_src_snapshot.jsonl`，跑完对账。
2. 日志里 `投喂=N（M 次筛选）` 取真账本 ⇒ 恒 0（V208 §276.4）。本轮改用重放读 `stats()`，不看那行。
3. 子集的 `prev` 臂仍带 5 条别题评审，其中**含另一题的失败断言** ⇒ C 不是「空块对照」，
   是「别题失败断言对照」。这是有意的：它测「串题有没有用」。
