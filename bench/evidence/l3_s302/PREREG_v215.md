# 预注册 V215（§283）：把累积块交给「真正解题的那一端」—— 配对块

**写于跑之前**（2026-11-20 19:0x，`bench_out/runs.jsonl` 基线见 `start_runs.txt`）。

## 0. 为什么做这一轮

V214 的免费普查（`bench/evidence/l3_s302/`）量到一条结构事实：

> 默认配置下，3/3 次外包调用的 stdin **逐字等于题面**（172/112/172 字），
> 而同一时刻 state 里躺着 227 字的 `[外部评审]` 块。
> ⇒ 「学到的东西进不进求解路径」在**部署默认配置**下是假的。

V214 已经用**正例对照**证明修法接得上：`--external-handoff blocks` 时
2/2 次 stdin 变成 `题面 + 229 字`（`341 = 112+2+227`、`401 = 172+2+227`）。

本轮只问一件事：**这段附言到底改不改答案。**

⛔ 本轮**不改任何判据、不改落盘格式**；`--external-handoff` 默认 `off`，
   所以这一轮若失败，产品行为**一个字都不变**。

## 1. 装置：配对块（沿用 §280 的 `bench/interleave.py`）

| 项 | 值 |
|---|---|
| 臂 | `off`（state 里有评审、但不交给外部）vs `blocks`（同一份 state 的累积块一并交出） |
| ⛔ 两臂的共同条件 | **都** `--critique-scope prev-self --critique-why raw` ⇒ **state 逐字节同形**，唯一差别是 `handoff` |
| 外部能力 | **注册**（两臂都不加 `--no-external`）—— 这是本轮的自变量所在 |
| 块数 | **20 块 × 2 臂 = 40 次运行**，块内顺序按 `(i−k) % n` 轮转 |
| 每次运行 | 新进程、`--memory-dir` 全新空目录、评审输入从冻结快照 `prior_v214.jsonl` 重拷 |
| 题集 | `suite_sub2.jsonl`（2 题 × 6 断言，`suite_sha=e322e014…`） |
| 模型 | `qwen2.5:7b`，`T=1.0`，`--budget 1` |
| 预计 | 40 × ~110 s ≈ **75 分钟**（外部能力每题 40~60 s） |
| 记录 | `order.txt` / `schedule.tsv` / `state_*.jsonl` / `log_*.log` / `runs.jsonl` 新增 40 行 |

## 2. 判据（先写死）

| # | 命题 | 门槛 | 极性 |
|---|---|---|---|
| **P1a** | 装置：调度表 40 行逐行等于实跑顺序 | 非零退出 **0** 次 | 押成立 |

**判读规则（不许事后改）**：
- P2 成立 ⇒ 累积块在**部署默认路径**上有牙（这是十三轮里第一次在默认路径上量到）。
- P2 不成立但 P1c 成立 ⇒ 附言送到了、没改答案 ⇒ 下一刀是「附言写什么」，不是「送不送」。
- P1c 不成立（外包覆盖率太低）⇒ 本轮 **UNKNOWN**，先修覆盖 —— ⛔ 不许拿"分数没动"当结论。

⚠️ **MDE 自报**（纪律 105）：20 块、实测不一致率按 V212 的 `π_d≈0.15` 估，
McNemar 可检测 `δ≈0.30`。⇒ 本轮**只能**看见大效应；`< 0.25` 的差别一律报 UNKNOWN。
⚠️ **跨窗极差**（纪律 110）：`t04[0]` 的 `off` 臂在 V212/V213 上分别是 5/20、4/30，
本轮 `off` 掉到 0~1/20 或涨到 9/20 都**不算**干预效应，先按同一臂的极差解释。

## 3. 自踩预案

1. ⛔ **外包覆盖率是分母**：若某块里 planner 没选外部能力，该块对 P2 无信息
   ⇒ 必须**同时报**「40 次运行 / 其中 k 块两臂都外包」。不许只报 20。
2. ⛔ **两臂日志里的 `handoff=` 行必须核对**：`off` 臂印 `handoff=off`，
   `blocks` 臂印 `handoff=blocks` —— 参数没生效与效应为零在读数上同形。
3. ⚠️ 外部能力的 `k=2` 多角度生成本身就是随机的，且它自己会执行筛选
   ⇒ 同一段附言可能把 3 份候选都推向同一个形状，也可能一份都不碰。
