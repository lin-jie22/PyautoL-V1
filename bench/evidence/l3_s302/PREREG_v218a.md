# PREREG V218a —— 打开门 B 能不能把「走不走外部」固定住

**先写后跑。** 本轮不问块内容，只问**装置**：`V1_EXTERNAL_ANSWER_TOOL` 打开后，
`kernel_external.calls` 是不是每次都等于 2（两题各一次）。

## 0. 为什么问这个

§287（V217）判 UNKNOWN，真问题是「分数跟走不走外部一一对应」。免费普查
（`FREE_calls_v218.txt`）把它定位到两处：

| 读数 | 值 |
|---|---|
| 2 题子集 n=159 的 calls 分布 | **0: 74（46.5%）/ 1: 12 / 2: 73（45.9%）** 双峰 |
| `t04` 满分率 按 calls | calls=0 → **15/74 = 20.3%**；calls=2 → **73/73 = 100%** |
| `t01` 均值 按 calls | 3.43 / 3.75 / 3.62（**几乎不动**） |
| 门 B（`core.py:1386`） | 存在，写死第 0 位，条件 `it == 1` |
| 门 B 默认值 | `V1_EXTERNAL_ANSWER_TOOL=""` ⇒ **从未触发** |
| 主循环 | `spend_step()` 在 `it = steps_used` 之前 ⇒ **第一轮 it=1** |

⇒ 那 159 行的 calls 全部来自**门 A**（planner 自己挑），是抽样；
而 `t04` 的分数几乎是「外部有没有覆盖它」的函数。

## 1. 这一轮只做一件事

`export V1_EXTERNAL_ANSWER_TOOL=agent:code_agent`，跑 **3 次**（单臂 `off`，
`--critique-why shape`，`--budget 1`，同 2 题冻结题集）。

## 2. 判据（先写死）

| # | 门槛 | 判 |
|---|---|---|
| P1 | 3/3 次 `rc=0`，单次 ≤ 420 s | 否则整轮 INVALID（装置） |
