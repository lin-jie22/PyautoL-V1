## 0. 上一轮留下的唯一未决

§289.5：`B` 的块对 `1h30m` **一字未提**，却三块都恰好翻第 0 格（`1h30m`）。
⇒「附言给了知识」与「附言把生成推到另一个采样点」在 V219 的读数上**分不开**。

V219 的阶梯是 A(0 条) → B(2 条别题满分) → C(2 条别题满分 + 1 条本题失败) → D(同 C 但 why=raw)。

读完这三级能拆出两件事，但 V219 只跑了一件事的两种写法（C vs D 都带失败信息）：

| 从 → 到 | 多了什么 | V219 实得 |
|---|---|---|
| A → B | 两行满分（别题） | +1（3/3 块） |
| B → C | **一行本题失败** | 再 +1（3/3 块） |

缺的那一格是：**如果那一行本题记录写的是「1.00 — 通过 6/6」（零失败信息），还会不会 +2？**
这就是 `G` 臂。它与 `C` **只差那一行的内容**：位置、格式、条数、其余两行逐字节不变。

## 5. 押

**押 `n_G = 12`（每块 4/6，Δ=+1）。**

理由（写下来是为了跑完能审判自己，不是为了自洽）：
- A→B 的 +1 来自「两行满分」；B→C 的 +1 来自「一行本题失败」。
- 若那 +1 只来自「多一行」，G 该是 15（= C）。若来自「失败」二字，G 该回到 12。
- 我押**内容**：因为 V219 的 D（信息更多）反而更弱（+0.67），说明这条通道不是「文本越多越好」，
  而是「文本里有没有可用信号」。
