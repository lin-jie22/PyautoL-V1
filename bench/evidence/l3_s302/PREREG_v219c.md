# V219c 预注册（`§291`）—— 三条轴：别题失败→本题满分、满分→失败（同块长）、加回异常类名

## 0. 先更正上一轮（以及 V219）的一处读法错误

免费量查到：`scope=prev` 排除本题后，`block_for()` 走的是 `crit[-3:]`（**3 条**），不是「后两条」。
所以 V219 的 `B` 臂给 `t01` 的块是：

```
[外部评审] [coding_small/t04_merge_ranges] 0.33 — 通过 2/6；异常: TypeError, AssertionError
         ｜ [coding_small/t05_top_k] 1.00 — 通过 4/4
         ｜ [coding_small/t06_rle] 1.00 — 通过 5/5
```

⇒ **V219 §289.3 写的「A→B = 加两行满分」是错的**：B 相对 A 加的是
「**一条别题失败行** + 两行满分」。B→C 的 +1 因此不是「多一条本题行」，
而是「把**别题**的失败行换成**本题**的失败行」。
⚠️ 不改 V219 的落盘记录（历史不许改），在这里更正，并在 §291 里标出。

## 4. 判据

记 `n_X` = 3 块 `t01` 满分项数之和（每块 0~6，总 0~18）。
已知：`n_A = 9`、`n_G = 12`、`n_C = 15`（前两轮各 3 块；本轮同轮复测）。

> **P2（主判据，唯一一行）**
> 若 `n_C ≥ 14` 且 `n_G ∈ [11,13]`（正例闸：C、G 必须复现上轮的同向差）
> 则按 `n_H` 判：
> - `n_H ≥ 14` ⇒ **成立 A**：失败**计数**足够；异常类名零贡献
> - `n_H ∈ [11,13]` ⇒ **成立 B**：计数零贡献；牙在**异常类名**
> - `n_H ≤ 10` ⇒ **不成立**：「计数 + 类名」须同时在场（非加性）

> **P3（次判据，同轮补 V219b 的缺口）**
> `n_B'` 与 `n_G` 相等 ⇒ 「别题失败行」≡「本题满分行」（失败**位置**决定一切，内容无关）
> `n_B'` 比 `n_G` 低 2 以上 ⇒ 别题失败行也有正贡献（跨题累积第一次有读数）

## 5. 押

**押 `n_H = 12`（成立 B：计数零贡献，牙在 `ValueError`）。**

理由（写下来是为了跑完能审判自己）：
- `通过 1/6` 只说「几乎全错」，**不指向任何具体动作**；`ValueError` 是一个**词**，
  会激活「`int()` 解析失败 ⇒ 去写更稳的单位解析」这条具体修补。
- V219 的 `D`（信息更多：带断言原文）反而更弱（+0.67）⇒ 这条通道不是「文本越多越好」，
  而是「有没有可用信号」。计数是程度，类名是**指向**。

**同押 `n_B' = 12`（P3：别题失败行 ≡ 本题满分行）。**
理由：V219 的 `B`（别题失败）与 V219b 的 `G`（本题满分）各 3 块都是 4/6，
若本轮同轮复现相等，则「失败行只有在**本题**上才有牙」被确认。
