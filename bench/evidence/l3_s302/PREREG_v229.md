# PREREG v229：名字对/体不对 vs 名字错/体对 —— 照抄的闸是「名字」还是「体」

**写于跑之前。不许事后补判据。两臂一起押。**

## 1. 这一轮问的是哪一句话

V227 判 **CONTENT-AWARE**：投喂**别题**的码 ⇒ 不照抄（2/2），两题都掉。
但那个处理**同时**变了四样东西：函数名 / 函数体 / 语义 / 长度 ⇒ 「照抄取决于**是**本题的」这句话
没有指出**哪一样**在起作用。`external/code_agent.py:171` 把整段 stdin 当 `goal`，另写一句
`函数名必须是 {fn}`（`fn` 从题面正则抽）⇒ 最省事的解释是**名字匹配**，但从未取证。

**分道方法（仍然零产品代码改动）**：把「名字」与「体」拆开，各造一个块，做完整 2×2。

|  | 体对（本题的码） | 体不对（别题的码） |
|---|---|---|
| **名字对** | **V226b**（照抄，4/6 · 6/6） | **臂 B**（本轮，待跑） |
| **名字错** | **臂 C**（本轮，待跑） | **V227**（不抄，3/6 · 2/6） |

四角里两角已有读数，本轮补另外两角 ⇒ **一次能把「名字门 / 质量门」判到底**。

## 3. 判据（两个层次，缺一即不能判「抄没抄」）

臂 C 的照抄**可能带着改名**（模型被要求「函数名必须是 `{fn}`」），逐字节相等会把它判成「没抄」——
那是口径错误。所以每臂都记两级：

| 记号 | 定义 | 适用 |
|---|---|---|
| **EXACT** | `sha(输出) == sha(投喂块)` | 两臂 |
| **NAME-FIX** | 输出 == **把投喂块的名字改回本题名字**后的字节（即臂 C 的「体照抄、名改回」） | 臂 C（臂 B 的名字本来就对，此级退化为 EXACT） |

单元判定 **copied** = `EXACT or NAME-FIX`；**not-copied** 才需要另外解释。

## 4. 押（三值，逐格押、不许合并）

**「抄」的概率**（预注册，写死）：

| 格 | 名字 | 体 | 抄的概率 |
|---|---|---|---|
| B·`t01` | 对 | 不对 | **0.35** |
| B·`t04` | 对 | 不对 | **0.40** |
| C·`t01` | 错 | 对 | **0.55** |
| C·`t04` | 错 | 对 | **0.55** |

⇒ 主押 **BODY-GATE**（0.50）：体对上就抄（模型照抄后把名字改回）、体不对就不抄（名字救不了它）。
其余 **SHALLOW-MATCH**（名字或体任一对上就抄）0.25、**NAME-GATE**（只有名字算）0.20、

## 5. 判定规则（写死，跑完照判）

以**每道题各自**的 (B 抄?, C 抄?) 查表：

| 臂 B（名对体错） | 臂 C（名错体对） | 判定 | 含义 |
|---|---|---|---|
| 抄 | 抄 | **SHALLOW-MATCH** | 任一线索对上就抄 ⇒ 通道是**关键词触发**，不是累积 |
| 抄 | 不抄 | **NAME-GATE** | 名字是门、体不影响 ⇒ 「只改这一处」类指令有机会（要拍板） |
| 不抄 | 抄 | **BODY-GATE** | 体是门、名字不影响 ⇒ 通道真的在读内容是本题的码 |
| 不抄 | 不抄 | **BOTH-REQUIRED** | 必须认出「这就是本题的上一版」⇒ 通道最窄 |

- **两题判定不同** ⇒ **ONE-SIDED**：两格都报，⛔ 不归因到「题难易」、⛔ 不合并成一条。
- **P1 不成立**（块没进探针入参 / 前缀不一致）⇒ **UNKNOWN**，不许挑读数解释。
- **P6 失败**（`state_trimmed != 0`）⇒ 块被预算闸裁过 ⇒ 本轮作废。

⛔ 只判「这一对输入上成立」（`n_eff=1`。纪律 122/133）。⛔ 不判「机制」——四格里名字/体/长度仍非完全正交（见 §7）。

## 7. 已知会污染归因的四处（先写下来）

1. ⚠️ **块长不是完全不变**：改名让块 ±2 字节（502/675 对 500/677）。V227 已证长度两方向都不解释
   掉分，但本轮**只判「抄没抄」**（字节级），⛔ 不用长度解释分数。
2. ⚠️ **`pairs` / `s` 形参名没改**：臂 B 的 `def parse_duration(pairs)` 里形参仍叫 `pairs`，
   臂 C 的 `def merge_ranges(s)` 里仍叫 `s` ⇒ 名字改动**只到函数名**，形参是额外的可辨认线索。
   ⛔ 不许把「靠形参认出来」写成「靠名字」。
3. ⚠️ **臂 C 的 NAME-FIX 判据在语义上偏向「抄」**：模型只要照抄体、改个名就算抄。
   这是有意的（那正是「把块当源真值」的定义），但**必须同时报**它跟 `EXACT` 的差。
4. ⚠️ **两臂不是同一个块**：B·`t01` 与 C·`t04` 收到同一个块 X，B·`t04` 与 C·`t01` 收到同一个块 Y。
   ⇒ 判「名字/体哪个是门」时，比的**不是同一段字节**，而是同一段体配两个名字。
   长度/体的差异在两臂间被**配对抵消**，但⛔ 不能因此声称「只有名字变了」。
