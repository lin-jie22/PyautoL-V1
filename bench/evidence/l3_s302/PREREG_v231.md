# PREREG V231（§302）—— 补上 Reflector：`[自我修订]` 能不能让 `t01` **越过祖先**

## 0. 一句话

V230 证明通道的动作是「照抄体 + 就地修补」，**上限 = 祖先**（`t01` 4/6、`t04` 6/6 就是原版）。
那轮 `why` 逐字点名了 `assert parse_duration('1h30m') == 5400` 与 `assert parse_duration('10m') == 600`，
**一格没修**。本轮按 Reflexion 的三件套补上缺的那一件：**Reflector**。

## 1. 为什么缺的是它（外部依据 + 我们的读数）

Reflexion（Shinn et al. 2023）的消融：**只给失败轨迹（episodic memory）而不写反思 ⇒ 不提升**；
多出来的 8% 全部来自**写反思**那一步。三件套是 Actor / Evaluator / **Reflector**。

我们的装置此前有前两件：
- Actor = `code_agent`（求解）
- Evaluator = scorer（给 `score` + `why`，`why` 已进 `[外部评审]` 块）

**缺 Reflector** ⇒ 下一版拿到的是**症状**（`⇒ AssertionError`），不是**根因 + 动作**。
V230 的读数正是这个缺口的样子：给它两份带洞的码，它只修了「体里一眼看得出」的错。

## 4. 主判据（判据行唯一，纪律 59）

**P3（主）：R2 的 `t01` 分数 > 4/6。**

- 押「越过」**0.45** ｜「持平 4/6」**0.35** ｜「更差 <4/6」**0.20**
- 为什么不是更高：只有 2 格空间、7b 模型、且 V230 已证它**不按 `why` 改**。
  Reflexion 的 +11pp 是在 GPT-4 + HumanEval 上，不可直接搬（纪律 90：先问同域否）。
- ⛔ 若 `t01` 到 5/6 或 6/6 但 diff **指认不出**来自说明覆盖的那一处 ⇒ **降级**
  （纪律 149：分数新高不是通道有用的证据）。

## 6. 已知限定（先写，不许事后补）

1. **`[自我修订]` 的信息来源是 `why` 原文**，而 `why` 含 `assert ... == 5400`。
   ⇒ 本轮**不区分**「从失败里推理」与「照着测试改」。这是标准 Reflexion 形态（unit test 反馈给 reflector），
   但 ⛔ 不许据此说「它会诊断」。纯度问题留作后续（用 `shape_why` 再跑一臂）。
2. `t04` 满分 ⇒ 单题实验，`n_eff=1`。`t01` 的 4/6 是确定装置上的值（§294），单次即真值。
3. lesson 绑定 `based_on_sha`：只有与账本里那份代码逐字节一致才注入。
   `freeze_pass` 会把旧输入冻在账本里（§301.6）⇒ 这一条是**必须**的，否则说明会被贴到另一份代码上。
4. 只跑 2 轮、2 题 ⇒ 成本 ~5 min。

## 7. 本轮**不做**的事

- ⛔ 不改默认值（`--critique-reflect` 仍是 off）。
- ⛔ 不让 Reflector 产出代码（那会造出第二条求解路径，归因当场断掉）。
- ⛔ 不因为「分数更高」就宣布闭环 —— 只有 P3 + P4 同时成立才算「说明被用上了」。
- ⛔ 不跨题、不跨口径比较（`suite_sha` 不同即不可比）。
