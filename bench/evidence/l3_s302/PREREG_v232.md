# PREREG V232（§303）—— 把诊断粒度从「断言失败」升到「实得 X」

## 0. V231 留下的确切缺口

V231 把 Reflector 接上了，装置全通（说明进了 `state` 与探针入参、137 字、`t04` 内控无块），
但 **`t01` 仍 4/6 `011011`**，与 R1、与 V226b、与 V230 全同。逐字节比下来，故事是：

| 臂 | `t01` 输出 | 分数 |
|---|---|---|
| R1（无说明） | `24c322d5d9b6` 677 字 = **起点码（照抄）** | 4/6 `011011` |
| R2（有说明） | `1aa52c9066ec` 675 字 = **新码** | 4/6 `011011` |

R2 的 diff **只有一处**：把 `s.lower()` 提前赋值（`parts = s.lower().split('h')` → `s = s.lower(); parts = s.split('h')`）
—— **语义完全等价的重构**。也就是说：说明**改变了生成**（照抄 → 改写），但**没有改变行为**。

## 1. 根因：诊断错了，而模型忠实地执行了错误诊断

离线判分（零模型）量到真实失败机制：

```
'10m'  → split('h')=['10m'] (len=1) → split('m')=['10',''] (len=2) → else 分支
       → hours=int('10')=10; minutes=int(''.split('m')[0]) = int('') ⇒ ValueError
       → 被 except 吞掉 ⇒ return None（期望 600）
```

而 V231 里 Reflexion 写的说明是：「`10m` …程序**误认为它含有 'h' 分隔符**，导致解析出错」
—— **错的**。程序没有误认为含 h；它正确地进了 m 分支，然后把分钟当成了小时。

⇒ `why` 里只有 `⇒ AssertionError`，**没有实际返回值**。缺这一项时 7b 只能猜，猜错了。
这正是实验记录里纪律 135 的原话：**真实账本的诊断粒度决定自省上限**
（`AssertionError` 与 `ValueError` 指认的位置不同）。

**小样已先验**（30 秒、不改产品）：同一条 `why`、同一份代码，**只多给两行实测值**
（`1h30m 实得 3600`、`10m 实得 None`），Reflector 的诊断从「误认为含 h」变成
「`10m` 被错误地视为无效输入 ⇒ 应把 `if len(parts) == 1` 那个分支改成正确解析单一单位」
—— **指向了正确的分支**。

## 2. 本轮唯一变量

`mw/reflect.py` 新增 `failed_actuals(code, tests)`：对每条**失败**的断言，离线算出**实得什么**。
`build_prompt(..., actuals)` 多出一段 `【实测返回值】` + 一句「先判断这个返回值说明走到了哪条分支」。

⛔ 三条边界（自测 A1~A5 钉住）：
- 不编造值：断言不是 `==` 形状 ⇒ 退回异常名（`⇒ 抛 ValueError`），⛔ 不许凭空给一个数。
- 通过的断言不出现（没有诊断价值，还会撑长 prompt）。
- 只执行**已落盘的答案**与**该题自己声明的断言**；不产生分数、不改尺子
  ⇒ `scorer_sha` / `suite_sha` 一字未动。

与 V231 相比，**除了这四行输入，装置完全相同**（同起点 `crit_v226.jsonl`、同开关、同题面、同温度、同预算）。
两轮结构也不变：**R1 播种（块里无说明）/ R2 检验（块里有说明）**。

## 3. 主判据（判据行唯一）

**P3（主）：R2 的 `t01` 分数 > 4/6。**

- 押「越过」**0.50** ｜「持平 4/6」**0.35** ｜「更差」**0.15**
- 为什么比 V231（0.45）高：诊断已被小样证实变准了，而 V231 的失败被归因到「诊断错」。
  为什么不更高：7b 的诊断仍笼统（它说「应正确解析单一单位」，没说「`int('')` 会抛」），
  而「看对了地方但改不对」是本装置已见过的形态（V230 的 `t01` 就是 4/6 不动）。

## 4. 其余判据

| 编号 | 断言 | 类型 |
|---|---|---|
| **P1** | 两题入参前缀（`[上版代码]` 之前）与 V226b 逐字节相同 | 装置 |
| **P1b** | R1 无 `[自我修订]`；R2 有，且 `state` 与探针入参**两处都有** | 装置 |

| **P4** | 若 P3 成立：R2 的 diff 必须**改变语义**（不只是等价重构），且落在 `10m`/`1h30m` 那条解析链上 | 归因 |
| **P5** | R1 的 `t01` = 4/6（无说明时不会自己变好） | 反证 |
| **P6** | Reflector 仍不写代码（`越界=0`） | 边界 |

⚠️ **P4 是这轮的关键升级**：V231 的教训是「产出变了 ≠ 用上了说明」。
因此 P3 若成立，必须同时证明 diff **改了语义** —— 否则按 V231 的形态记「等价重构」，不算越过。

## 5. 已知限定

1. `[自我修订]` 的信息来源仍是 `why` + 实测值，实测值由 `assert ... == ...` 里求出来
   ⇒ 这条通道**仍属「照测试改」**（与 §285 的老问题同宗）。本轮不解决纯度，只解决「诊断对不对」。
2. 单题（`t04` 只做内控），`n_eff=1`；`t01` 的 4/6 是确定装置上的值（§294）。
3. 两轮 / 各 1 次 ⇒ 成本 ~4.5 min。

## 6. 本轮**不做**

- ⛔ 不改默认值（`--critique-reflect` 仍 off）。
- ⛔ 不让 Reflector 产出代码。
- ⛔ 不因为「小样诊断变准了」就推定分数会动 —— 那是把两次不同的量当同一次。
- ⛔ 若 P3 不成立，**不许**改判据为「诊断变准了也算成功」：诊断变准是**中间量**，
  累积的定义是「下一版更好」，不是「说得更像那么回事」。
