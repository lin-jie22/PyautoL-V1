# RESULTS v226 / v226b：投喂「上一版代码」⇒ 逐字照抄（COPY），闭环退化成恒等映射

**两轮实跑**：V226（run `43592`，101 s，判 UNKNOWN）｜ V226b（run `92355`，109 s，判 **COPY**）。
`scorer_sha=6062bd622c` 与 V224/V225 相同 ⇒ 分数可比。零新题、零新尺子。

## 0. 一句话

把**上一版代码**放进块里（而不是只放分数+失败断言），模型**没有修补、也没有换家族**，
而是**逐字照抄**（2/2 题，输出 sha == 投喂 sha）。于是账本那一行**跑前跑后逐字节相同**，
下一轮输入必然与这一轮相同 ⇒ 这是一个**已证明的不动点**，再跑多少次都不会变。

⇒ 「累积产物」这条路在当前形态下的上限 = **守住不再掉**，不可能**提升**。

### 2.3 决定性证据：账本行跑前跑后逐字节相同

```
crit_v226.jsonl  t01 行  ==  crit_v226b_after.jsonl  t01 行     （score/why/answer 三键全同）
```

## 3. 三种投喂内容，三种失败方式

| 块内容 | 模型行为 | 结果 |
|---|---|---|
| 只有分数（`1.00 — 通过 6/6`） | 换家族（B：坏 `1h30m`+`10m`） | 4/6 |
| 分数 + 失败断言（点名 `1h30m`/`10m`） | 换到另一个家族（A：坏 `45s`+`10m`） | 4/6 |
| **分数 + 失败断言 + 上一版代码** | **整段照抄** | 4/6（不变） |

⇒ 六轮净 0 至此有了完整解释：**给它判决，它换家族；给它产物，它照抄。**
两条路都不会"只改点名的那一处"。

`10m` 是全历史公共洞：主家族 A/B 都坏它，5/6 的高频变体（18 次）也只坏它；
而 `6/6` 在 237 个可配对观测里出现过 **4 次、4 份不同代码、各 n=1** —— 可达，但从未被复现。

## 6. 新增纪律

- **142.** ⛔⛔ 判「记忆有没有用」之前，先判**输出是不是输入的那一份**：
  投喂产物会让模型退化为**逐字照抄**，判据是 `sha(输出) == sha(投喂段)` ——
  它比分数早一步说话，且不受"分数是粗粒度读数"影响（§296.4）。
- **143.** ⭐ **闭环是否还在动，用账本行字节判**：跑前跑后**逐字节相同** ⇒ 下一轮输入相同
  ⇒ 不必再跑。这是"测不动"的最强证明，比多跑几次便宜一个量级。
- **144.** ⛔⛔ 新增一个块前缀 ⇒ **必须同时查两处**：进没进 `state`、进没进 `HANDOFF_BLOCKS`。
  V226 首跑：`state` 961 字有、入参 261 字没有、答案逐字节不变 ⇒ 白跑的 101 s。
