# RESULTS v229：名字门 还是 质量门 —— 完整 2×2

**预注册**：`PREREG_v229.md`（跑前写死，未改判据）。**零产品代码改动**，唯一变量是账本 `answer` 里的函数名。

## 0. 一句话

判 **BODY-GATE**（两题一致）：把**别题**的码投喂进去，只把 `def` 那一行的**函数名**改成本题要的名字，
模型**仍然不照抄**（2/2）；反过来把**本题**的码改名成别题的函数名，模型**照抄体、只把名字改回来**（2/2，
输出与本轮改名前的码**逐字节相同**）。⇒ 照抄的闸是**体**，不是名字。

## 4. 顺手量到的两件事（都不是本轮判据）

### 4.1 体相同时，改名对 `t04` **完全无影响**

V227 的 `t04` 块 = parse 体 + `def parse_duration`(677)；臂 B 的 `t04` 块 = **同一份 parse 体** +
`def merge_ranges`(675)。两轮的输出**同 sha**（`60dc1bbdb95e`，396 字）、同分（2/6 `011000`）。
⇒ 对 `t04`，块里那段**它用不上的体**是彻底惰性的，名字怎么改都一样。

### 4.2 体相同时，改名对 `t01` **改了生成**

V227 的 `t01` 块 = merge 体 + `def merge_ranges`(500) ⇒ 输出 `b8bf041e020f`(312)、3/6 `010011`；
臂 B 的 `t01` 块 = **同一份 merge 体** + `def parse_duration`(502) ⇒ 输出 `22d72be8f21e`(370)、
**5/6 `011111`**。⇒ 名字不是「无影响」，它把生成推到了另一处；但**没有**让它照抄。

⚠️ **5/6 是 `t01` 至今最高分**（此前：off 3/6、own-copy 4/6、cross 3/6）。它来自一份**函数体完全不对题**的块，
⛔ **不许**记成「累积有用」：体是 `merge_ranges` 的，产出的是一份全新的 `parse_duration`
（`units={'s':1,'m':60,'h':3600}` + 逐段解析），既没抄体也没借结构。这一格只说明**单次读数可以比历史最高还高**。

## 5. 判定与限定

- **BODY-GATE** 的含义有限但明确：照抄**由体驱动**——模型会读那段码、看它是否解这道题，名字只是被它**顺手改回**。
  ⇒ §297 的「逐字照抄」不是格式/槽位效应，也不是名字门（§298 的「最省事的解释是函数名匹配」**被否掉**）。
- ⛔ 不判「机制」：四格里**体与长度仍绑在一起**（体对时块 675/677 长，体不对时 500/502 短），
  本轮只把**名字**从四样东西里分了出来（函数名 / 函数体 / 语义 / 长度 → 去掉了函数名这一项）。
- ⚠️ 形参名没改（臂 B 的 `def parse_duration(pairs)`），它是**额外的可辨认线索**；但它只指向「体是别题的」，
  ⛔ 不能据此说「模型靠形参认题」。
- ⚠️ 两题 / 每臂 1 次；`n_eff=1`。
