## 2. R2 的 diff 只有一处，而它是**等价重构**

```diff
-        parts = s.lower().split('h')
+        s = s.lower()
+        parts = s.split('h')
         if len(parts) == 1:
-            parts = s.lower().split('m')
+            parts = s.split('m')
```

语义**完全不变**（`s.lower()` 提前赋值）。所以：**说明改变了生成，没有改变行为**。

## 3. 为什么——诊断本身是错的（离线判分证）

`10m` 的真实失败链：

```
split('h')=['10m'] len=1 → split('m')=['10',''] len=2 → else 分支
hours=int('10')=10 ; minutes=int(''.split('m')[0]) = int('') ⇒ ValueError
⇒ 被 except 吞掉 ⇒ return None（期望 600）
```

而 Reflector 写的是：「`10m` …程序**误认为它含有 'h' 分隔符**，导致解析出错」——**错的**。

⇒ **模型的执行是忠实的：它忠实地执行了一个错误的诊断。**
所以本轮不是「通道没用」，也不是「模型不听」，而是**上游那句话错**。

## 6. 新增纪律

- **153.** ⛔⛔ **「产出变了」不等于「用上了那段话」**：判断一段注入是否被采用，必须看 **diff 是否改变语义**。
  V231 的 R2 换了 675 字节、sha 变了、分数不变 —— 逐行看才发现是 `s.lower()` 提前的等价重构。
  ⛔ 只报「sha 不同」会把「它照着我说的改了」写成结论，而它只是**在提到的那一行附近动了动**。
- **154.** ⭐⭐ **自省的瓶颈常常在「被自省的那条信息」上，不在自省者**：`why` 只有 `⇒ AssertionError`、
  没有**实际返回值**时，诊断只能猜（纪律 135 的现场兑现）。修法是补信息，不是换更会说话的模型。
