## §0 起点与**先量**

### 0.1 上一轮押的那条形式

§240.7 写的最小形式是：

> `done_gids()` 改成「**最后一次**判定是 MET」而不是「曾经 MET 过」。

押：`STALE` 消失且 `DONE` 不提前。

### 0.2 读代码读出来的一个问题（**在跑之前**）

`propose()` 末尾是 `goals = [g for g in goals if g.gid not in done_set]`，
而 `record()` 只记 `propose()` 的输出。两句话合起来：

> **一个 gid 一旦进了 `done`，它再也不可能被 `propose()` 提出；既然提不出，
> 也就不会被执行、被记账 ⇒ 它在账本上不可能出现 MET 之后的行。**

⇒ 在**本循环能产生的任何账本**上，「最后一次判定是 MET」与「曾经 MET 过」是
**同一个集合**。所以 §240.7 押的那条最小形式，单独实施 **Δ = 0**。

这不是读数，是可达性结论（与 V168 的 STAGE0 同型）。但纪律 87 要求
「押『这一步走不通』前先把那一步跑一遍」，所以 §1 的 STAGE0 仍然真跑两条实现、
在真账本上逐元素比，不拿推理代替。

### 0.3 那真正该改的是什么

「MET」是对**当时那次测量**的断言，不是永久事实。真正该问的是：

> 这条 MET 判定，**按现在的读数**还算不算数？

所以形式改成：`done_gids(rows, obs)` = 「最后一次判定是 MET」**且**
「该行记下的 `criterion` 在当前读数上仍成立」。两者缺一：
- 只做「最后一次」⇒ 0.2 说的，Δ=0；
- 只做「读数为准」而保留「曾经 MET」⇒ 也能工作，但把「最近一次判成 NOT_MET」
  也当 done，语义上说不通（一条目标最近被判没做成，却记着说做完了）。

⛔ 行里没有 `criterion`（旧账本 / 手写的合成行）⇒ **不算 done**。
理由：多提一次会重判、会记账、会被看见；静默藏掉一条退步不会被看见。**宁可见，不可藏。**

## §1 STAGE0（**不改仓库代码**，只用本地复刻）

装置 `probe_stage0.py`。⚠️ 它 **import 的是改动前的 `mw.goals`**，
另在文件内用三个本地函数复刻三种 `done` 语义 —— 因为改动前仓库里只有第一种。
主实验（§2）会逐条核对「出厂函数 == 复刻」，⛔ 不复刻完就当出厂函数是那个意思（纪律 65）。

三份账本：

| 记号 | 怎么来 | 它要证的事 |
|---|---|---|
| `L_real` | 真 `run.py --goals --goals-act 1 --offline` 连跑 8 轮（单题套件 `t06_rle`） | 旧账本的**形状**：MET 之后有没有行 |
| `L_reg` | 用**真 API**（`propose→evaluate→record`）+ 脚本化观测量：先 3 次 1.0（RAISE 判 MET），再追加 2 次 0.0 | 退步账本上三种语义**分不分得开** |
| `L_ok` | 同上，但观测一直是 1.0，不回落 | 对照：没有退步时三种语义必须一致 |

STAGE0 判据（3 条，⛔ 不并入主判据）：

- **S1** `L_real` 与 `L_reg` 上，「MET 之后还有行」的 gid 数 = **0**；
  且 `done_hist(rows) == done_naive(rows)` 逐元素相同。
  ⇒ 原押的形式**单独实施无效**。（若 S1 不成立，我押错了，主实验照原押做。）
- **S2** `L_reg` 上 `done_read(rows, obs)` **少于** `done_hist(rows)`，差集恰是
  被回落的那个 RAISE gid；`propose()` 在 `done_read` 下重提它、在 `done_hist` 下 0 条。
- **S3** `L_ok` 上三种语义的 done 集合**完全相同**，`propose()` 条数相同。

## §2 主实验判据（7 条，全部预注册）

装置 `v173.py`，读数为准的实现取自**出厂** `mw.goals`。

| # | 命题 |
|---|---|
| **P1** | 原押单独实施 **Δ=0**：`L_real`/`L_reg` 上 `done_hist == done_naive`，且出厂 `done_gids(rows)` 在「无读数」时**不把任何一格当 done**（⛔ 不做静默回退到旧语义） |
| **P2** | 退步被看见：`L_reg` 上出厂 `done_gids(rows, obs)` 不含该 gid、`propose()` **重提**它、`regressions()` 点名 **1** 格，且**两个数都报**（`met_mean` 与 `now_mean`） |
| **P3** | 不回落时不动：`L_real`/`L_ok` 上出厂 `done` 与旧实现的 done **逐元素相同**、`propose()` 条数与旧实现**逐条相同**、`regressions()` **0** 条 |
| **P4** | 退步只发生在 `RAISE`：穷举 `n_obs ∈ 0..5` × `mean ∈ {0, 0.5, 1.0}`，**追加**观测时 `COVER`/`PROBE` 的 gid 永远留在 done（`n_obs` 单调）；`regressions()` 命中的 gid 全部是 `RAISE` |
| **P5** | `STALE` **结构性消失**：穷举状态空间（1~2 格 × `n_obs 0..4` × `mean ∈ {0,0.5,1.0}` × `esc ⊆ 格`，共 N 组）在读数为准的 done 下 `state()` 的值域 = `{WORK, EMPTY, IDLE, DONE}`、`STALE` **0 次**；**同一穷举器**在历史 done 下必须能找到 `STALE`（正例路径，纪律 62 —— 证明穷举器不哑火） |
| **P6** | 部署态两个数：真账本（24 格 / 36 行）上 `done=0`、`regressions=0`、`propose=40` 条且与改动前**逐条相同**；同时报「读数会回落」的部署证据：均分从 ≥1.0 落到 <1.0 的格数，与其中**达到过 `MIN_OBS`** 的格数（后者才是今天能触发的） |
| **P7** | 变异体有牙：`done_gids` 恒返回「所有 MET 的 gid」（不看读数）⇒ **P2 FAIL**；恒返回 `[]` ⇒ **P3 FAIL**。两个变异体都要报 FAIL，⛔ 不许只报一个 |

**判据的行与押同向**（纪律 76）：本节押的是「读数为准能消掉 STALE 且不乱动」，
P1 押「原押无效」——两条都写清「成立/不成立各意味着什么」。

## §3 边界（⛔ 不许放大）

1. **不提高任何分数**：本轮的产物是「一条退步会不会被看见」，不是「分数变好」。
2. ⛔ **不动 `MIN_OBS` / `TARGET` / `KINDS`**：改了就是换尺子。
3. ⛔ **不动 `ESCALATE` 的触发条件**（V171 判据 Q6 钉常量集合）。但必须报一个**交互读数**：
   退步的格若同时被转运维，`propose()` 仍会跳过它 ⇒ 退步**只在 `regressions()` 里可见**。
   这个数要报出来，不许含糊过去。
4. ⛔ **不说「L5 完成」**。`STALE` 消失是**消掉一个 bug**，不是新增一种能力。
5. ⛔ **不碰 V79**（自造判据 0/8）。

## §4 自证清单（跑之前先想好怎么被骗）

- 退步账本必须**真走过** `record()`，⛔ 不许手写一行 `{"verdict":"MET"}` 当证据。
- `L_ok` 是**对照臂**：如果 `L_ok` 上也有退步，说明装置在乱报，P3 立刻失败。
- 穷举器必须**先证明自己会触发**（P5 的第二个数）。
- 两个变异体都要跑（P7）；只跑一个等于没跑（纪律 5：红=无的三形态）。
- 报「改动没影响部署」时，必须同时报 `propose` 40 条**逐条相同**（纪律 82：说「纯省」要逐条 `hit`+`s1` 全同）。
