# PREREG v240（§312）—— 换路预算参数化（⛔ 本轮不跑模型）

## 0. 为什么新开一轮

V239 的下一刀之一：**4B 的截断率 50%**（6 次里 3 次被 900 token 砍断，3779/3679 字符正文），
而换路的 `max_tokens` 在 `run.py` 里**写死 900**。

⚠️ 改预算 = **改分母口径**：截断率变 ⇒ 「4B 落分的 3 次」这个分母本身变，
V238/V239 的读数不能与新预算下的读数直接比。所以按纪律先预注册。

## 1. 本轮做什么 / 不做什么

| | |
|---|---|
| **做** | ① `--goals-swap-max-tokens` 一等化（默认 900，逐字节保持历史口径）；② 非法值构造即抛；③ 生效值可见；④ 契约 5 条 + 撤回态；⑤ **全量撤回态跑完**（V239 只跑了定向 6 条） |
| **不做** | ⛔ 不跑任何模型。⛔ 不用新预算重跑 V238/V239 的格。⛔ 不改默认值。 |

⇒ 本轮**不产生新模型读数**。它只把「换一个预算」变成一件**可执行、可回滚、可判**的事。
真正「1600/2400 哪个好」的实验是**下一轮**，要单独拍板（分母会变）。

## 2. 口径（写死）

1. **默认不变**：不传 `--goals-swap-max-tokens` ⇒ 生效值 **900**，与 V235~V239 逐字节同行为。
   跨轮锚：默认档 prompt sha 仍为 `3b33bcb8b2276580`（`selftest_v239` T7 同一份）。
2. **显式才变**：`--goals-swap-max-tokens N` ⇒ 该值进 `_swap_candidates(max_tokens=N)`，
   且**只**影响换路那 k 次调用，⛔ 不影响 act、不影响 `limits.llm_max_tokens`。
3. **非法值构造即抛**：`<=0` 抛 `ValueError`，⛔ 不许静默回落到 900
   （「以为调大了，其实还是 900」是 V236 的 900/2400 全灭同型）。
4. **生效值可见**：`⚠️` 非默认时打印 `mt=N` 到 `换路` 行；默认档**不加字段**（日志逐字节不变）。
5. **范围**：只改 `run.py` 的 swap 路径。另一处写死 900（`critique-propose`，行 2691）
   ⛔ 本轮不动，如实登记为「同类问题未处理」。
