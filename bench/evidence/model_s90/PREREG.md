# §56 预注册 —— 第一个「同通道、换被测对象」实验（第九十轮）

⛔ **本文件在跑之前写定**。预测错了要原样登记，不许事后改。

## 56.0 为什么是这一轮做

§55 的判决是：`caliber_sig` 那笔账不成立，**真缺口是实验设计** ——
147 行历史记录里 `SUBJECT_ONLY`（只差被测对象）**0 对**。

本轮就把这一对造出来。造它的前提不是"再找一个模型"，是**让两个模型收到同一个协议**。

## 56.1 前置取证（跑之前已测，不是推断）

### ① 本机有两个生成模型，同端点

```
127.0.0.1:11434/v1/models →  nomic-embed-text:latest / Qwen3.5-4B:latest / qwen2.5:7b
```

### ② 但它们的**协议不同** —— 直接比就是混口径

同一句「返回这个 JSON」的冒烟测试：

| | 延迟 | completion_tokens | message 字段 |
|---|---|---|---|
| `qwen2.5:7b` | 4.03s | 12 | `{content, role}` |
| `Qwen3.5-4B` | 23.23s | **554** | `{content, reasoning, role}` |

⇒ 一个交 20 字符答案花 12 token，另一个花 **554** token（40 倍延迟）。
拿它们直接比"谁更强"，比的是 **模型 + 思考协议 + 速度** 三件事。

### ③ 关思考的唯一有效写法，以及三种**被静默忽略**的写法

| 写法 | completion_tokens | 结论 |
|---|---|---|
| 什么都不加 | 554 | 基线 |
| **`reasoning_effort: "none"`** | **12** | ✅ 有效（0.57s） |
| `chat_template_kwargs.enable_thinking=false` | 554 | ❌ 被忽略 |
| `think=false` | 554 | ❌ 被忽略 |
| `thinking: {"type":"disabled"}`（内核会发的形态） | 554 | ❌ 被忽略 |

⚠️ 端点对未知字段**静默忽略、不报 400** —— 与 §51 记的「官方端点收未知字段会 400」
相反。⇒ "端点是否宽容"是**通道属性**，不是协议属性；不能拿一家的行为推另一家。

⭐ 而 `reasoning_effort` **不在内核请求体里**，内核也发不出来（改 `mw/llm.py` ⇒ 断
`harness_sha` ⇒ 全量 166 条重跑 1h44m）。⇒ 走 `bench/llm_proxy.py --inject`
（测量装置，不进契约层），两臂收到**同一个** `reasoning_effort`，
于是「模型」成为唯一变量。

## 56.2 设计

| 项 | 值 |
|---|---|
| 题集 | `bench/specgen/tasks_v2.jsonl`，`suite_sha=d6b7ed14`，10 题 / 140 格 |
| solver | `llm`（完整内核，非直连） |
| 臂 A | `qwen2.5:7b` |
| 臂 B | `Qwen3.5-4B:latest` |
| 唯一变量 | `llm_cond.model` |
| 通道 | **两臂同一个端口** `127.0.0.1:8790` → `http://127.0.0.1:11434` |
| 注入 | 两臂都是 `{"reasoning_effort":"none"}` |
| 采样 | `temperature=0.0`，`--repeat 3`（每题 3 个样本） |
| 其余 | `--fresh --no-external --max-tokens 2048`，wall=120s / calls=24 / steps=12 / verify_static=2（默认） |

⛔ **端口必须同一个**：`llm_cond.endpoint` 是 `urlsplit(base_url).netloc`，
两臂给不同端口就会变成 `MIXED`（换模型 + 换路径），这一对白做。
⇒ 顺序跑，臂间 kill 代理再起。

## 56.3 预测（可被否证）

1. **方向**：`mean(B) ≤ mean(A)`。依据：参数量约一半、思考关掉后协议相同。
2. **量级**：`mean(A)` 落在 **6.5~7.5**（历史同尺子 `verify_static=2` 一次读数 7.1427）。
   `mean(B)` 落在 **4.5~6.5**。
3. **可分辨性**：`|mean(A) − mean(B)|` **大于** 臂内噪声极差。
4. **臂内噪声**：3 次 repeat 的极差 **≤ 4 格**（历史同口径两次差 4 格，
   且只落在 `sg02`/`sg05` 两题上）。
5. **反直觉风险**：若 `|Δ| ≤ 噪声`，则结论是**尺子分不开 7B 与 4B**，
   而不是"两者能力相同"。那会是一个关于尺子的 fail-closed 结论，我会照实登记。

⛔ 本轮**不主张**"哪个模型更强"作为普适结论：n=1 个端点、1 个题集、1 天。
它只回答一件事：**这把尺子能不能把两个真实模型分开，以及台账能不能表达这个比较。**

# 结果 vs 预测（跑完之后追加，⛔ 上面原文一字未改）

| # | 预测 | 实测 | 判决 |
|---|---|---|---|
| 1 | `mean(B) ≤ mean(A)` | `0.8286` vs `0.7024` ⇒ **B 高 17.7 格** | ❌ **反了** |
| 2 | `mean(A)` ∈ 6.5~7.5 | **7.02** | ✅ |
| 2 | `mean(B)` ∈ 4.5~6.5 | **8.29** | ❌ 高出一个整档 |
| 3 | `|Δ| > 臂内噪声` | 17.7 > 15.0（余量 **2.7 格**） | ✅ |
| 4 | 臂内极差 ≤ 4 格 | A = **15 格**；B = **0 格** | ❌ / ⚠️ |
| 5 | 若 `|Δ| ≤ 噪声` 则是尺子分不开 | 未触发 | — |

**四条里错三条。** 逐条说清楚错在哪：

- **①方向错了。** 我的依据是"参数量约一半"。这个依据本身就漏了一件事：
  `Qwen3.5-4B` 与 `qwen2.5:7b` **不是同一代**。代际差可以盖过参数量差 ——
  这是常识，但常识**不是读数**，而我当时把常识当成了预测的依据。
  ⛔ 更重要的教训：这个方向**不该被预测**，因为没有任何本机历史读数支持它；
  我当时是在"猜一个听起来合理的答案"，而不是"从一个读数外推"。
- **②B 的档位错。** 预测 4.5~6.5，实测 8.29。同源于 ①。
- **④噪声 ≤ 4 格的依据是错的。** 那个 4 格来自**两次单跑之差**（`5.7141` / `5.4284`）。
  两次样本给出的"极差"是**极差的下界**，不是估计值；三次样本立刻翻到 15 格。
  ⇒ 登记为一条方法学教训：**用 2 个样本报"噪声下限"，报出来的永远偏小**，
    而偏小的噪声会让下一轮把噪声读成改进。

## 15 格里发生了什么（这才是本轮真正的读数）

不是"模型抖动"。三轮 `sg10` 的**第一版答案都被自检打回**，
第二版被「⏭ 重复动作已跳过」跳过，墙钟转收尾，`_close_out` 又发了一次
专门索要答案的调用 —— 那一次交出的 419 字符版本少了 `import re`，**没有再过自检**。

```
ord1  430 字符  sha db82131d…  14/14
ord2  419 字符  sha 38f40729…   1/14   ← 少一行 `import re`
ord3  430 字符  sha db82131d…  14/14   ← 与 ord1 逐字节相同
```

⇒ 15 格 = 13（缺 import）+ 2（`sg01` 12→14）。
⇒ **所谓"噪声"，在这个尺子上是一条没有闸的补救通道。** 见 DESIGN §56.5。
