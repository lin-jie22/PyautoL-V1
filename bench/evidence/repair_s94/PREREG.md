## 0. ⛔ 先纠一个我自己的措辞错误：这不是「跨题族」

第九十三轮 §60.9 我写的下一步是「跨题族复现」。**查完题面后这个说法站不住**：

| | v2（`sg01`~`sg10`） | v3（`ex01`~`ex10`） |
|---|---|---|
| 形态 | 「按**下面列出的先后顺序**依次处理」+ 5 条编号规则 | 「按下面列出的规则实现」+ 3~4 条编号规则 |
| 错误形态 | 漏一条规则 / 顺序错 / 边界错 | 同左 |

两者是**同一形态**的两个实例集（不同生成器：`taskspec.py` / `ext_v3.py`，但题型同构）。
所以本轮能支持的最强结论只是：

> 「§60 的读数**不依赖 v3 那 10 个具体实例**」

**它不能**支持「§60 的读数不限于这一族题」。后者需要另造一个形态不同的题族 —— 本轮**不做**（见 §7）。
按纪律，本轮报告里一律写「同族换实例」，不许写「跨族」。

## 3. 预测（先写死，跑完逐条对）

依据：§56.4 记录过 v2 上 qwen2.5:7b 臂 A 的三轮 102/105/105 格（140 格，约 0.73~0.75）——
⚠️ 那是**另一个口径**（`verify_static` 已 promote、sig 不同），本轮**不许**把新读数与它并列，
只是拿它估「可失分余量」的量级：**≈ 31~42 格**。

| # | 预测 | 判据 |
|---|---|---|
| **P1** | 方向复现：`P 净增益 > 0` 且 `R − P < 0` | 两条同时成立才算复现 |
| **P2** | 量级缩小：`P 净增益` 落在 **+10 ~ +20 格**（v3 是 +31） | 落在区间外即预测错，照登 |
| **P3** | 归一化后接近：`P 净增益 / 可失分格数` 落在 **30%~55%**（v3 是 31/84 = 37%） | 同上 |
| **P4** | `R` 臂净增益落在 **−6 ~ +6**（v3 是 −2） | 同上 |
| **P5** | v2 上「满分题」（旧分 = 14/14）的题数 **≤ 2**（v3 是 3 题） | 同上 |

**我认为最可能错的是 P2/P3**（我没有 v2 在**本口径**下的旧分，只有跨口径的估计）。
如果 P 净增益撞到「可失分余量」的天花板（例如余量只有 31 格而 P 拿到 +28），
那 P2 就是**被天花板压出来的**，不是机制变了 —— 这种情况我会写成「不可分辨」，不写成「不如 v3」。

## 4. 判定规则（与 §60 §5 逐字相同）

```
gain = Σ max(0, 新 − 旧)      loss = Σ max(0, 旧 − 新)      net = gain − loss
noise = Σ_题 (该题各轮 new 的极差)
可分辨 ⇔ |R − P| > noise（取两臂逐轮 noise 的最大值）
```
