# §72 预注册：U2 —— `verify_static` 1（报名字）vs 2（盲报），在 `tasks_v4` 上

> 写于跑真模型**之前**（2026-10-27 23:5x）。理由同 §66/§70/§71：事后补判据 = 自带选择偏差。

## 一、只问一个问题

第八十轮在 `tasks_v1`（6 题 × 14 用例 = 84 格）上量到三臂：
`0` 关 0.5574 ｜ `1` 报名字 0.6190 ｜ `2` 盲报 **0.6905** ⇒ 默认值定在 `2`。
但那把尺子**不含**「忘 `import`」这类失效面最大的题（`sg01` 是唯一的例外，而它只有 14 格）。

`tasks_v4` 有：`at04` 三次全是同一份 440 字答案，用了 `os.makedirs` 却**没有 `import os`**（§71.4）。

**本轮问**：在**会咬合**的题上，「告诉模型缺哪个名字」是否优于「盲报一句话」？

⛔ 这不是「模型是否变强」，是**同一个内核的两个载荷**谁更有用。

## 二、两个假设（必须有一条能被自己的读数否证）

| # | 假设 | 若成立应看到 | 被否证的形态 |
|---|---|---|---|
| H1 | 盲报下模型定位不到缺哪个名字（§71 T1b：3 次机会，收尾改写 3 次全部仍缺 `import os`）⇒ 报名字使其补上 | A 臂（`=1`）的 **3 次机会全部**补上 `import os`；`at04` ≥ 0.75 | A 臂重写后**仍缺** `import os` |
| H0 | §80 的排序（2 > 1）是机制性的，不是 `tasks_v1` 的偶然 | A 臂总分 ≤ B 臂总分 | A 臂总分比 B 臂高 ≥ 3 格 |

⚠️ 两条互斥，跑完必须有且只有一条被否证。若落在中间（A > B 但 < 3 格，或 A 只补上 1/3 次机会）⇒ **UNKNOWN**，不许写成「略好」。

## 三、两个分母（§66 自踩的修法，必填）

| 分母 | 预注册值（来自 §71 T1b 实测） | 说明 |
|---|---|---|
| **机会数** | **3 次尝试 / 9 次闸跑**（每臂） | 静态判据在这把尺子上只有 `at04` 会失败 |
| **咬合数** | **0 / 9**（每臂，T1b） | 「触发后重写补上缺失名」的次数 |
| 格数 | 128 × 3 rep = **384** / 臂 | 每格一条独立断言 |
| 增补块机会数 | `at04` × 6 rep = **6 机会 / 臂**（见第六节） | 只用于**机制读数**，⛔ 不跨 `suite_sha` 比分数 |

⛔ **机会数只有 3 是本轮的结构性弱点**，写在跑之前 —— 不许事后说「样本足够」。
所以本轮的主读数不是总分，是**逐条机会的因果链**：闸报了什么 → 重写答案里那个名字补上没有 → 交付物过没过闸。

## 四、判负条件（任一成立 ⇒ 读数作废或降级）

| # | 判负 | 为什么 |
|---|---|---|
| N1 | `attempted != recorded` 或 `failed_scorer > 0` | 口径没接通 |
| N2 | 同 `v4` 题集上 `--solver oracle` 在**同一 env** 下不是 1.0000 | 尺子自身不可解 |
| N3 | 任一臂的**机会数 = 0** | 没有机会 ⇒ 只能报「未咬合」，⛔ 不许报「无效」 |
| N4 | 两臂机会数**不相等** | 设计上触发集相同（同一份代码、同一条件），不等即装置有问题 |
| N5 | `|Δ总分| ≤ 本 run 极差` | §71.5：极差本身不是常数，只能用本 run 的 |
| N6 | `0 < Δ < 3 格`（3 格 = 0.0234 的平均分） | 「有方向无规模」⇒ UNKNOWN，保留默认 `2` |
| N7 | 两臂耗时差 > 20% | §62：通道速度是混杂因子 ⇒ 分数 Δ 降级，只允许机制读数 |

## 五、口径（与 §71 T1b 逐项相同，只改一个 env）

model=`qwen2.5:7b`、`temperature=0`、`repeat=3`、`max_tokens=2048`、`--fresh --no-external`、
`V1_MAX_WALL_S=120`、`V1_MAX_LLM_CALLS=24`、`V1_MAX_STEPS=12`、`V1_CLOSE_RESERVE_S=45`、
`V1_CLOSE_RESERVE_STEPS=1`、`V1_CLOSE_OVERRUN_S=30`、inject=`{"reasoning_effort":"none"}`。

- **A 臂** `V1_VERIFY_STATIC=1`（报名字）
- **B 臂** `V1_VERIFY_STATIC=2`（盲报，**当前默认**）

两臂跑在**同一份逐字节相同的目录副本**（`/tmp/v1_s102_work`，rsync 自 `bc7bc62` 后的工作树，
`diff -rq` 只剩 `.DS_Store`）。唯一的自变量是那个 env。

⚠️ `verify_static` 进 `Limits` ⇒ 两臂 `caliber_sig` **必然不同**（这是设计，不是事故）。
可比性靠「代码逐字节相同 + 只改一个 env」，与 §66 同宗。
⭐ B 臂与 §71 T1b 的 `caliber_sig` **逐位相同** ⇒ B 臂同时是 T1b 的**同晚复现**，
可用于估「跨 run 噪声」（§71.5 只有单 run 极差，缺这一项）。

⚠️ **顺序偏差**：A 先、B 后（顺序写死，不随机）。若两臂耗时差 > 20% 按 N7 降级。
