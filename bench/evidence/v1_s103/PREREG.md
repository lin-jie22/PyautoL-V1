# §73 预注册：V1 —— `verify_static` **0（关自检）** vs **2（盲报，当前默认）**

> 写于跑真模型**之前**（2026-10-28 01:3x）。理由同 §66/§70/§71/§72：事后补判据 = 自带选择偏差。

## 一、只问一个问题

第 102 轮（§72）量到 `1`（报名字）比 `2`（盲报）在 `tasks_v4` 上 **+10 格**。
但它**只量了 `1 vs 2`** —— 缺底下那一档：`2` 相对 **`0`（完全关掉静态自检）** 又值多少？

```
0  ──?──▶  2  ──+10 格──▶  1
（关）      （盲报）        （报名字）
```

`2` 每触发一次要**多花 1~2 次生成**（打回后用满 `verify_retries`），
§72 里 B 臂比 A′ 臂多耗 3m15s 就是这笔账。**这笔账在 `tasks_v4` 上从没量过。**

⛔ 这不是「模型是否变强」，是**同一个内核多派一条判据值不值**。
⛔ 也不许跨轮拿 §72 的 B 臂（`=2`, 0.5469）当本轮对照 —— §62：跨时段不算数，必须同晚两臂。

## 二、两个假设（必须有一条能被自己的读数否证）

| # | 假设 | 若成立应看到 | 被否证的形态 |
|---|---|---|---|
| H1 | 盲报**值**那一次额外生成 | `=2` 总分 > `=0`，且 `Δ ≥ 3 格`（0.0234） | `Δ < 3 格` 或 `Δ < 0` |
| H0 | 盲报在这把尺子上是**纯开销**（载荷无信息 ⇒ 打回只是多烧一次生成，交付物没变好） | `=2` 总分 ≈ `=0`（`\|Δ\| < 3 格`），但 `=2` 的耗时/生成数**明显更高** | `=2` 比 `=0` 高 ≥ 3 格 |

⚠️ 两条互斥。若 `=0` **反而更高**（`Δ ≤ -3 格`）⇒ 第三类结论「闸在**制造**伤害」，
必须单列，⛔ 不许并进 H0 里说成「差不多」。

## 三、两个分母（本轮分母与 §72 结构不同，必须写死）

`=0` 臂**必然**触发 0 次 —— 那是设计，不是装置故障。所以 §72 的「机会数按尝试算」在这里会恒 0，
不能用。本轮改为**两个分母 + 一个离线复算**：

| 分母 | 定义 | 谁给 |
|---|---|---|
| **真机会** | `=2` 臂上闸实际触发（打回 / 收尾未过闸）的**尝试**数 | 跑批日志按 `▶ 任务开始` 切块 |
| **潜在机会** | `=0` 臂的**交付物**里，离线用 `mw.verify.undefined_names` 复算**会被拦**的份数 | 零模型复算（`analyze_v1.py` S3） |
| 格数 | 128 × 3 rep = **384** / 臂 | 每格一条独立断言 |

⭐ 潜在机会是本轮的核心装置：它让「闸关掉之后到底漏了什么」变成**可数的数**，
而不是「反正没触发」。⛔ 但潜在机会 **≠** 真机会：它只说「如果闸开着，这份交付物会被拦」，
说不出「打回之后会不会变好」—— 后者只能由 `=2` 臂的分数承担。

## 四、判负条件（任一成立 ⇒ 读数作废或降级）

| # | 判负 | 为什么 |
|---|---|---|
| N1 | `attempted != recorded` 或 `failed_scorer > 0` | 口径没接通 |
| N2 | 同 `v4` 题集上 `--solver oracle` 在同一 env 下不是 1.0000 | 尺子自身不可解 |
| N3 | `=2` 臂的**真机会数 = 0** | 治疗组没被治疗 ⇒ 只能报「未咬合」，⛔ 不许报「无效」 |
| N4 | `=0` 臂**仍出现**「自检未过」字样 | 关没关上（装置接线反证） |
| N5 | `\|Δ总分\| ≤ 本 run 极差`（两臂各自的 3 rep 极差） | §71.5：极差不是常数，只能用本 run 的 |
| N6 | `0 < Δ < 3 格` | 「有方向无规模」⇒ UNKNOWN |
| N7 | 两臂耗时差 > 20% **且** 分差方向对 `=0` 有利 | §62：通道是混杂因子 ⇒ 分数 Δ 降级为机制读数 |
| N8 | 离线复算器对 `=2` 臂「仍会被拦」的份数 ≠ 日志「收尾未过闸」数 | 复算器与内核判据不同源 ⇒ 潜在机会不可信 |

⚠️ N7 的写法与 §72 不同：本轮**预期** `=2` 更慢（它多打回），所以「更慢」本身不是判负，
只有「`=0` 更快且分数也更高」才需要怀疑通道/预算混杂。
