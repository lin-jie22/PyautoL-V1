但分数**还是 6/16** —— 因为失败形态从

```

```

变了。**闸消灭了它唯一看得见的缺陷，露出来的是它看不见的那一层。**

⇒ 这解释了 Δ=0 的机制：`at04` 的 10 个失分点不在「名字没绑」，而在**行为**（原子性/失败清理）。
闸能做的只是把「崩在 import」换成「跑起来但不对」，格数一模一样（6/16 → 6/16）。

⚠️ 与 §72 对照（跨轮，只作解释不作并列）：`=1`（报名字）在 `at04` 拿到 **1.0000**。
⇒ 同一个触发点，**载荷决定重写的方向**：盲报让模型猜（猜中 import 也只是换个错法），

## 五、两处自踩

### 5.1 ⛔ 判负条件的方向用错了 ⇒ 「无差异」这类结论永远判不出来

第一版 `S10` 把 `N5 |Δ| > 极差`、`N6 |Δ| > 3 格` 都放进 `need`，于是 Δ=0 时这两个必红 ⇒ 输出 `UNKNOWN`。
**这是实现错，不是判据松**：主张「有差异」要 \|Δ\| 大，主张「无差异」要 \|Δ\| 小，**同一组门槛不可能两用**。

修法：分成 `need_diff`（N5/N6）与 `need_eq`（逐题逐 rep 全等 / \|Δ\| < 3 格）两组，按主张选一组。

⭐ 记这一条的价值：这是**第二次**在判据方向上报错（§72.7 是「分母随结果动」）。
两次的共同形态是：**判据是为「有差异」写的，却被拿来判「没差异」**。

### 5.2 ⛔ 日志里的任务名是**函数名**，不是题号 ⇒ 「闸碰过的题」成了空集

`S11` 第一版拿日志里的 `write_or_fail` 去和题号 `at04` 比，永远匹配不上 ⇒ `touched` 为空集，
而**空集与「没碰过」输出同形**（§70.4 ③ 的老病，第三次犯）。

修法：从 `tasks_v4.jsonl` 的 `prompt` 抽 `def (\w+)` 建 `函数名 → 题号` 映射。

## 六、局限（写在结论旁边，不许只写在附录）

1. **这是等效性结论，不是「证明相等」**：本 run 极差 = 0.0000 只说明「本时段抖动为 0」，
   不等于「任何 Δ 都可分辨」（§63：`T=0` 不是逐字确定）。旁证：`at05` 两臂都出现 2 种 sha
   （`5512482d` / `1500eca8`），说明**同 prompt 同晚确实会给出不同答案**，只是分数没动。
2. **机会面只有一个题**：`at04` 是 `tasks_v4` 上唯一会触发静态判据的题（3 次尝试）。
   「Δ=0」只说这把尺子上这一处；⛔ 不许外推成「静态自检一般没用」。
3. **`=1` 与 `=0` 的交互没测**：本轮只测 `0 vs 2`。`1` 在 `at04` 是 1.0000（§72），
   但那是**另一个自变量**，不能拿来补这轮的结论。
4. **成本差是同载荷内的**：`+14` 次生成里，有一部分是「打回后必须重写」，不是「模型自己想多写」。
