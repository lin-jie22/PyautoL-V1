## 5. 演练③：分支表（空串 / 0 ⇒ 跳过 B 臂；≥1 / unknown ⇒ 跑）

```
  D0_NI=[]         ⇒ 跳过 B 臂（D0′）
  D0_NI=[0]        ⇒ 跳过 B 臂（D0′）
  D0_NI=[1]        ⇒ 跑 B 臂
  D0_NI=[2]        ⇒ 跑 B 臂
  D0_NI=[unknown]  ⇒ 跑 B 臂
```

空串必须走"跳过"分支：§77 那次 `grep -E '^D0_NI='` 取到空串，
被判成"ni 组 0 机会"从而**错误地跳过 B 臂**——这次反过来了：
空串意味着**提取失败**，按 §78.6 的处理应该登记"探针故障"并照跑（`unknown`），
所以脚本里 `D0_RC != 0 ⇒ D0_NI=unknown`。⚠️ 遗留风险已登记：
**探针本身返回 0 却印不出 `D0_NI`** 这种情况，脚本会读成空串 ⇒ 跳过 B 臂。
本轮演练②证明"印不出来"只可能来自探针异常输出，而探针的任何异常都会让 `print_report()` 抛错（rc≠0）。
