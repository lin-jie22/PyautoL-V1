## §4 机制：为什么升不起来 —— 检索是**反信息**的

这是本轮真正的产出。三条证据，全部可离线复算。

### 4.1 配对题的特征集**完全相同**

`tasks_v8` 的 6 题两两 Jaccard：

| 对 | Jaccard |
|---|---|
| `e1wi` vs `e1ni` | **1.0000** |
| `e2wi` vs `e2ni` | **1.0000** |
| `e3wi` vs `e3ni` | **1.0000** |
| 其余 12 对 | 0.7500 ~ 0.8750 |

阈值 `REWARD_MIN_SIM = 0.30`（`mw/worldmodel.py`）。**15 对全部远超阈值，3 对精确等于 1.00。**

⇒ 检索**没有任何区分力**：任何一道题，`reward_guidance` 都会返回「最相似的 3 条」，
而那 3 条**必然**是它的孪生题（sim 恰好 1.00，排在最前）。

### 4.2 复算「第 2 轮起跑时每题实际吃到的提示」

用只含第 1 轮记录（`id ≤ 92`）的库快照重放 `reward_guidance`：

| 题 | 检索到的 3 条来自 | passed 序列 |
|---|---|---|
| `e1wi` | `e1ni` × 3 | T, T, T |
| `e1ni` | `e1wi` × 3 | **F, T, T** |
| `e2wi` | `e2ni` × 3 | F, F, F |
| `e2ni` | `e2wi` × 3 | T, T, T |
| `e3wi` | `e3ni` × 3 | F, F, F |
| `e3ni` | `e3wi` × 3 | T, T, T |

**每一道题收到的，都是「与它仅差一行 import 的那道题」的成绩。**
`e2ni` / `e3ni` 的提示原文是：

```
历史同类题的外部得分：
- 同类题（结构重合 1.00）：历史通过，得分 1.00 ⇒ 无记录的失败模式
- 同类题（结构重合 1.00）：历史通过，得分 1.00 ⇒ 无记录的失败模式
- 同类题（结构重合 1.00）：历史通过，得分 1.00 ⇒ 无记录的失败模式
```

⭐ **这三行是本题最坏的信息。** 孪生题之所以过，**正是因为**它骨架里有那行 import；
而本题缺的**正是**那行。于是「它过了、没有失败模式」被读成「不需要补」——
**结构相似度最高的地方，恰好是两道题唯一有差别的地方。**

### 4.3 三条边界条件的实际表现

| 设计边界 | 设计意图 | 实测 |
|---|---|---|
| ① 来源必须外部（`REWARD_SOURCE`） | 防自评 | ✅ `拒=0+0`，54 条全收 |
| ② 整轮跑完才写 | 防轮内开卷 | ✅ 第 1 轮 `奖励[...]` 段为空（`读=None`），18 条在轮末写入 |
| ③ 检索排除同题号 | 防开卷考同一题 | ⚠️ **执行正确，但无效** —— 排除自己之后，剩下的最相似者是孪生题 |

⭐⭐ **③ 是实现正确、目标落空的典型**：它挡住了「考同一道题」，却挡不住
「考一道只差一行、且那一行正是考点」的题。**判据（task_id 不等）与实际语义（题目不同）之间有缝。**

## §5 两处逐字节证据

### 5.1 `e1ni` 掉分的真身：**整整两行被删**

`A 臂（16/16）` vs `B 臂第 2 轮（0/16）`，`e1ni` 的答案 diff **只有两行**：

```diff
 ```python

-

     return re.sub(r"@[A-Za-z0-9]+", "", text)
```

而 `_strip_tags` 里用了 `re.sub` ⇒ `NameError: name 're' is not defined` ⇒ 0/16。

3 rep 一致性（这是关键，说明不是抖动）：

| 轮 | `e1ni` 三次尝试是否含 `import re` |
|---|---|

| `b_r3` | `[False, False, True]` |

⭐ 这是 §78 `p1ni` 的**同一形态再次出现**：`ni` 版骨架缺 import，
模型要么自己补上（过），要么不补（不过）。**这一次，记忆让它选择了「不补」。**

### 5.2 `e1wi` 的翻转：**一处真 bug 被修掉**（且不是奖励通道的功劳）

`b_r1` 的 rep1 → rep2：

```diff
-    kept = set()
+    kept = []
+    seen = set()
     for item in items:
         stripped = _strip_tags(item).strip(" \t")
-        if stripped:
-            if stripped not in kept:
-                kept.add(stripped)
-                kept.append(stripped)

⇒ 它**不能**算在「跨轮累积」头上，只能算在「轮内共享内核」头上。

### 5.3 归因的唯一性论证

r2 相对 r1，**唯一新增的机制**是什么？查 facts 表：

| fact | source | 创建时刻 | 落在哪轮 |
|---|---|---|---|
| `动作 [finish] 存在乐观偏差…` | worldmodel | **18:16:05** | `b_r1` 内 |

⇒ **`e1ni` 的 −10.7 格可归因于奖励通道，不是世界模型。**

## §6 一个必须单独登记的背离：**精度升，分数降**

| 轮 | 预演 | 命中率 | 混淆（ok_ok/ok_fail/fail_ok/fail_fail） | 分数 |
|---|---|---|---|---|
| `b_r1` | 315 | 0.610 | 192 / 75 / 48 / **0** | 58.7 |
| `b_r2` | 348 | **0.836** | 225 / 21 / 36 / **66** | 48.0 |
| `b_r3` | 343 | 0.819 | 225 / 21 / 41 / 56 | 53.3 |

世界模型从「**从不预演失败**」（`fail_fail=0`）变成「能预演失败」（66 次），命中率 0.61 → 0.84，
**而分数同时下降。**

⚠️ 两条都不许夸大：
- 命中率上升**部分**是算术效应：6 题里 3 题恒失败，学会说「会失败」自动抬高准确率。
- 但 `fail_fail` 从 **0 → 66** 是结构性变化，不是算术。
- 正确表述只有一句：**「预测得更准」没有转成「做得更对」** ——
  这正是 Hassabis 缺失清单第 4 条（内省与自我纠正）的形状：能识别这一步差，但找不到更好的，于是照旧。

## §7 本实验**不能**回答什么（预注册 §9 原样保留）

1. ❌ 不能回答「跨族迁移」—— 6 题全 level0、全 `op_cond`+`op_parse`，且**特征集 3 对完全相同**。

   **写分数这件事是人做的**（`run.py:1258` 由 CLI 开关决定）。
4. ❌ 不能回答「γ 轮之后会不会继续升」—— 只跑 3 轮。
5. ⭐ 新增边界：**本轮的负结果不能外推成「记忆无用」**。
   本轮实际测到的是「**在特征不可区分的题集上**，结构检索会返回孪生题的成绩」。
   那是一个**装置属性**（题集把考点做成了特征不变量），不是「记忆这个东西不行」。
