## 0 为什么是这个问题（这一轮唯一的主线问句）

MEMORY §零 定的唯一目标：让**累积 → 预测 → 自省**三个循环闭合。
V19/V21/V22/V23 四连判负，**全部在 `--fresh`（`run.py:1103-1105` 跑完即删）下测的** ⇒
测到的都是冷启动。V24 又发现那四条判负里含一个**交互项**（投喂 × 盲报）。

⇒ 到今天为止，**「跨轮累积」这件事本身从未被量过**。
`--memory-dir` 存在（`run.py:869-880` 设 `V1_STATE_DIR`，`args.fresh=False`），
但 §71~§79 八轮没一臂用过它跑跨轮序列。**机制存在 ≠ 机制通电**（纪律 14）。

**本轮必答**：让 `--memory-dir` 固定、连续 N 轮不重置，分数会不会变？变了多少？在哪一题上变？

| 臂 | `V1_VERIFY_STATIC` | `V1_REWARD_ECHO` | 库 | 轮数 | 作用 |
|---|---|---|---|---|---|
| `c2`  | 2 盲报（**现状默认**） | 1 真回显 | **累积**（目录不重置） | 4 | 主臂 |
| `c2z` | 2 盲报 | **0 不回显但照记** | **累积** | 3 | 等长安慰剂：库在续跑，投喂被关掉 |

## 2 主判据（判决表，**按顺序取第一条命中**）

记 `mean_k(arm)` = 第 k 轮 6 题得分之和（6 题 × 16 格，满分 96；可达上限 64，见 §5）。
`noise_floor = max(f2 两轮) − min(f2 两轮)`。

| # | 条件 | 判决 |
|---|---|---|
| 1 | `noise_floor ≠ 0` | **J4 装置不稳** ⇒ 本轮不出判据，只登记「同 prompt 重复跑拿不到同一答案」 |
| 2 | `c2` 的 `e2ni` 或 `e3ni` 在轮 2/3/4 任一 > 0 | **J1 累积通电（正）** |
| 3 | `mean(c2, 轮 2..4)` < `mean(c2, 轮 1)` − `noise_floor` | **J2 累积有害** |
| 4 | 以上都不中 | **J3 累积无效** |

- 条件 2 优先于 3：`e2ni`/`e3ni` 是 V19~V24 五轮里**任何机制都没拉起过**的两道题
  （V24 逐题矩阵：四臂全 0，交付件逐字节相同）。它们是「变强」唯一的**未饱和窗口**。
  正净值只可能出现在这里；出现在别处不可能（其余 4 题已满分）。
- 条件 3 用 `mean` 而非单题：单题（`e1ni`）已在 V24 被证明会因载荷塌成 0，
  但那**不是累积**的功劳（V24 一轮内就塌）。这里要的是**跨轮**的净值。

### 2.1 形状判据（不管落哪一格都要报）

`shape = c2 的轮 3 / 轮 4 是否与轮 2 逐格相同`。
- 全同 ⇒ **「一次跳变 + 平台」**：累积只发生一步，之后不再变。
- 仍变 ⇒ **多步累积**（这才叫「会自己变强」）。

### 2.2 载荷贡献判据

`Δ_payload = mean(c2, 轮 2..4) − mean(c2z, 轮 2..3)`
- `|Δ_payload| ≤ noise_floor` ⇒ 投喂的那两行字**内容值 0**（在累积条件下复现 V23 的结论）
- 否则记方向。⚠️ 两臂轮数不同（4 vs 3），只比**共同轮**（轮 2、轮 3）。

⛔ `c2z − f2` 的差**不许**归因给 reward 载荷：那条路上库也在续跑，
`facts` / `outcome` / `mismatch` 通道同时在工作。这条只登记，不下结论。

## 3 预注册先验（押错就认，不许事后补解释）

**押 J2（累积有害）**，且形状为「一次跳变 + 平台」。理由三条，全部来自既有落盘：

1. `c2` 轮 1 用空库 ⇒ 载荷为空 ⇒ 预期 64（复现 V24 `a0p2` = 64.0，3 轮极差 0）。
2. 轮 2 起载荷非空，而 V24 的 `a1p2`（有条目 + 盲报）实测 **48.0**，`e1ni` 被打回 2 次、
   两次重写**逐字节相同**（`4157b661`）⇒ `cascade` 熔断 ⇒ 0。
   `c2` 的轮 2 与 `a1p2` 的差别只有「库里的行是这一轮自己写的」⇒ 预期同落 48。
3. 形状为平台：零模型探针（§7.1）实测轮 2 起载荷**内容恒定**，只有计数在涨
   （`NameError 出现过 4 次 / 6 次`），4/6 题归一化后逐字相同 ⇒ 没有新信息进入 prompt。

**明知不利也要写下的一条**：如果 Δ 精确等于 −16.0 且只落在 `e1ni` 一格，
那本轮**不能**声称「累积有害」——那是 V24 的交互项被第二次测到，与本轮问句无关。
本轮若只拿到这个，判决按 §2 落 J2，但结论必须写明「**这是重复，不是新发现**」。

## 4 预注册的取证方式（先确认它在装置里存在）

- 逐题得分与交付件 sha：从每轮 `bench_<tag>/runs.jsonl` 读（`analyze_v25.py`）。
  ⚠️ `answers.jsonl` 只存最终交付、行序 = 尝试序、`rep` 恒 1（MEMORY §五.6）。
- `static` 位真生效的正控：日志里 `判据=5项(...)` 的括号内容，`c1` 必须是「未定义名」，
  `c2`/`c2z`/`f2` 必须是「结构检查」。⛔ 这个正控在 V24 用过（`run_v24.sh:107-115`），
  但当时的失败文件 `p0e_fail.txt` **只在失败时创建** ⇒ v24 结尾那句
  `wc -l < p0e_fail.txt` 印 0 与「零失败」同形（纪律 8「缺席冒充零」）。
  本轮改为：**每轮都往 `p0e.txt` 追加一行**（`tag crit ok`），计数来自恒存在的产物。
- `echo` 位真生效的正控：`c2z` 的日志里 `外部奖励 写入 N 条` 必须照常出现（写不受回显影响），
  且 `c2` 与 `c2z` 的 `e1wi` 交付件**允许**不同（载荷进了 prompt）。
  ⛔ 若 `c2` 与 `c2z` 六题交付件**逐字节全同** ⇒ 回显位没生效，判 **J4**（不是 J3）。

## 5 已知的判决空间上限（先写死，防止把天花板读成结论）

`tasks_v8` 在 `T=0` + 当前预算下，四臂实测的最佳逐题矩阵是
`e1wi 16 / e1ni 16 / e2wi 16 / e2ni 0 / e3wi 16 / e3ni 0 = 64`
（V24 §2，四臂中最高）。

⇒ **可达上限 = 64，不是 96。** `e2ni` / `e3ni` 占 32 格，在 V19~V24 的 30+ 次运行里
**从未被任何机制拉起过一格**。所以：
- 指望 `mean` 从 64 涨上去 = 指望那两道题 ⇒ §2 条件 2 单独立了一条。
- `mean` 的下降侧有空间（→ 48），上升侧没有。
