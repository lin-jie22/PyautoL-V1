## 0 为什么必须先做这一轮（而不是直接做 V25 收尾时计划的「灌无关文字」臂）

V25 的判决书 §89.4 写了一句归因：**「通路是 `facts`，不是 `reward`」**。
收尾之后我把这句话拿去验，**没验住**，而且否证来自三条互相独立的读数：

1. `MemoryStore.recall(e1wi 题面)` 在 `/tmp/v25/mem_c2z/memory.db` 上返回 **0 条**
   （题面 1182 字，FTS 查询 24 个 token，`facts` 只有 2 行，两行都讲「动作 [finish] 预演偏差」）。
2. 用真实库构造 `Core` 复算 `_state(e1wi 题面, history=[], it=1)`：
   块只有 `['[目标]', '[第']`，**没有 `[语义记忆]` 块**。`e1ni` / `e3ni` 同（1192 / 1709 字）。
3. 日志里那句 `语义记忆=2` **不是送达条数**：`core.py:1964` 打印的是
   `stats['memory']['facts']` = `memory.stats()` 里的**表行数**（`memory.py:398`）。

⇒ 第 3 条尤其要紧：我上一轮把它当成了「载荷送达」的证据。
这是纪律 14「机制存在 ≠ 机制通电」的第二次同形复发，只是这次是我自己误读自己的台账。

**所以 V26 的问句不是「累积有没有用」（V25 已回答：分数会变），而是：**

> 轮 2 起跑时，**哪一段文字**真的变了？它从哪条路进到 prompt 里？

⛔ 在通路没定位之前，任何「灌等长无关文字」的臂都可能打在一个**根本没接线**的开关上
（§88.3 的 `keep_ratio` 闸就是这么白造的：边际拦截 0，读数上却长得像「加了一道保护」）。

## 1 装置（两臂四轮，全部开 `--state-dump`）

同一 `bench/specgen/tasks_v8.jsonl`（6 题 / 96 格，`suite_sha` = `519dad774a366461`），
同一 `T=0`、同一端口 8815、同一预算、同一 `--use-reward`。
起点库一律**全空**（新建目录，⛔ 不用 V25 的库）。

| 臂 | 库 | `V1_REWARD_ECHO` | `V1_VERIFY_STATIC` | 轮数 | 作用 |
|---|---|---|---|---|---|
| `d2` | **累积**（目录不动） | 0 不回显 | 2 盲报 | 2 | 主臂：V25 里 +16 全出在这一档 |
| `f2` | **每轮重置为空** | 1 真回显 | 2 盲报 | 2 | 正控：同起点 ⇒ 同步 state 必须逐字节相同 |

- `echo=0` 是刻意的：reward 段完全不进 prompt（`worldmodel.py:662` 直接 `return ""`），
  所以 `d2` 的 prompt 差异**只可能**来自记忆通道，不可能是投喂措辞。
- `f2` 是本轮**唯一**能让「state 差异 = 累积」这句话成立的东西。没有它，
  「两轮 state 不同」也可能只是装置自己不稳。
- 轮内交错（R1: `d2` `f2`；R2: `f2` `d2`），⛔ 累积臂不跨轮乱序。
- 四轮**同一时段连续跑完**。跨时段会改变同一个 prompt 的答案（V22 §86 已证）。

### 1.1 「state」到底指什么（写死，防止事后偷换）

`--state-dump` 落的是 `Core.state_log` 的原文（`run.py:230-249`）：
每次 `_state()` 一份，含 `[目标]` / `[工作记忆]` / `[语义记忆]` / `[外部评审]` / `[轨迹]` / `[第 k/N 步]`。
**它不含 `guidance`**（那走 `planner.propose(guidance=...)`，是另一个参数）。
⇒ 判「prompt 同不同」时，state 之外还要单独算 `wm.guidance(...)`（`echo=0` 下必须为空串，
可离线复算，见 `analyze_v26.py` 的 §3）。

## 2 判据（按顺序取第一条命中；冻结后不改）

先记 `S[arm][round][task][it]` = 该步 state 原文；`score[arm][round][task]` = 该题得分（×16 格）。

| # | 条件 | 判决 | 含义 |
|---|---|---|---|
| 1 | `f2` 两轮的 `S` 里，同一 `(task, it)` 存在逐字节不同 | **J0 装置不可重复** | 本轮不出归因；且 V25 的 `noise_floor=0` 一并作废 |
| 2 | `f2` 两轮全同 **且** `d2` 两轮**没有任何题**分数变化 | **J3 未复现** | 本时段不走那两个吸引子 ⇒ 归因问题**顺延**，⛔ 不许拿旧读数硬套 |
| 3 | `d2` 有题分数变化，且该题存在某步 `S` 不同 | **J1 定位成功** | 报出：首个变化的步号、变化所在的块名（`[工作记忆]`/`[语义记忆]`/`[轨迹]`）、首差异行 200 字 |
| 4 | `d2` 有题分数变化，但六题**所有步** `S` 逐字节全同 | **J2 反证** | 同 state ⇒ 同 prompt ⇒ 同答案（`T=0`）却被打破 ⇒ **采样不是确定性的**，V25 的确定性结论全部要重写 |

- 条件 4 必须单列成判决而不是「异常」：它一旦成立，比任何归因都值钱。
- 条件 3 命中后**只报事实**：块名 + 首差异行。⛔ 本轮不许写「所以内核学会了 X」。
- ⛔ 不许把「`d2` 与 `f2` 的差」直接叫记忆的价值：两臂 `echo` 位也不同（0 vs 1），
  这是装置限制，已登记为已知混杂，本轮**不**用这个差下结论。

### 2.1 必须一起报的读数（不进判决，防「归因给不存在的通路」）

1. 每题每轮的 **`recall` 工具调用次数**（日志 `↳ recall` 行计数）——
   这是**唯一**还剩的候选通路：模型自己调 `recall(query)`（`tools.py:136`）→
   命中结果进工作记忆 → 下一步的 `[工作记忆]` 块。它与 `_state` 的自动检索是**两条路**。
2. 每题每轮的 **`guidance` 长度**（离线用 `wm.guidance()` 复算库快照）——
   `echo=0` 下必须恒为 0 字。若不为 0 ⇒ `V1_REWARD_ECHO` 没生效，判 J0。
3. 每题每轮的**块清单**（state 每行行首的 `[...]`），按步列出。

## 3 预注册先验（押错就认）

**押 J1，且差异块是 `[工作记忆]`。** 理由三条，全部可离线验：

1. `_state` 的自动检索（`core.py:1420` `recall(goal)`）在真实库上实测 **0 条** ⇒ 排除 `[语义记忆]`。
2. `guidance` 在 `echo=0` 下实测 **空串**（本轮离线复算：空库 0 字 / 真实库 0 字）⇒ 排除「易错点」段。
3. `[外部评审]` 需要 `--use-critique`（`run.py:995` 默认 None），V25/V26 都没开 ⇒ 排除。
   剩下 `[工作记忆]`：模型每轮都调了 `recall` 工具（V25 日志 `c2z_r1` 4 次 / `c2z_r2` 4 次），
   而轮 1 起跑库里有 0 条 facts、轮 2 起跑有 2 条 ⇒ 同样的 query 在两轮拿到的**内容不同**。

**明知不利也要写下的一条**：如果 J1 命中但差异块是 `[轨迹]`（即步数/历史不同），
那说明**差异是动词不是名词**——两轮跑的步数不一样，模型自己走岔了，
此时「通路」这个词就不该用，只能记「同一装置在两轮里走出不同轨迹，起点差异未定位」。
