## 0. 这一轮为什么非做不可（对齐 §零 主线）

§90 的判决是：V25 那 +16 的载体是 `blobs` 表的**全局自增行号**（`b#1` → `b#12`，+1 字符）。

这带来一个测量学后果，比「记忆有没有用」更前置：

> **只要库会变大，prompt 就会变。** 而库一定变大（每轮写 6 条 reward + 若干 blob）。
> ⇒ 在现在的装置上，**任何跨轮实验的对照组里都混着一条与语义无关的因果边**，
> 且它的效应量（16 格）**等于或大于**我们想测的任何东西。

⇒ V28 不是「再找一个效应」，是**把尺子的零点校准**：把那条边拆掉，
让「零信息」在读数上真的表现为**零差异**。

**每轮必答**：这一轮有没有让「累积循环」离可测更近一步？
答：有 —— 只有它把「库变大」从混淆变量变成不变量，之后任何跨轮 Δ 才可归因于**内容**。

## 1. 唯一变量（改什么、为什么是这个改法）

### 1.1 改动

`mw/memory.py`：

| 位置 | 现在 | 改成 |
|---|---|---|
| `__init__` | 无 | `self._blobs_base = SELECT COALESCE(MAX(id),0) FROM blobs` |
| `capture()` | `ref=f"b#{lastrowid}"` | `ref=f"b#{lastrowid - self._blobs_base}"`（**本会话内序**） |
| `expand()` | `WHERE id=?`（ref 当全局 id） | `WHERE id=?`（ref + base 反算） |

⇒ 句柄仍然是「短、稳定、可打印」的 `b#1`、`b#2`……，**长度与现状完全一致**
（1~2 位十进制），只是分母从「库的全局行号」换成「本会话第几次捕获」。

### 1.2 ⛔ 为什么**不**用内容寻址（sha 前 8 位）

上一轮我说的方案 A 是「`b#` 用 `sha[:8]`」。**放弃它**，理由是它一改就带进第二个变量：

- `sha[:8]` ⇒ ref 从 `b#1`（3 字符）变 `b#34ea10cc`（11 字符）；
- `core.py:1110` 的索引行是 `[{ref} {chars}字 sha={sha}] `，而 `WORKING_CHAR_CAP=300` 是**硬上限**；
- ⇒ 正文可见宽度会从 ~285 字掉到 ~277 字（**−8 字**），且 `sha` 在同一行里出现两次（冗余）。

同一轮里同时改「编号来源」与「正文可见宽度」，两个变量无法分离。
本会话内序**零长度变化**，是这一轮能保持单变量的唯一改法。

⚠️ 已知取舍（写在这里，不许事后补）：内序 ref **不能跨进程解析**（重启后 base 变）。
本系统里 ref 从不落盘 —— 它只存在于 `working`（进程级 deque）与 `state` 快照里，
`expand()` 总与 `capture()` 同进程。⇒ 这个取舍在本装置里无成本；换装置时必须重审。

**第一组：反证组（治污有没有生效）** — `s12` 臂 = 空库 + 预置 11 条 dummy blob，两次独立冷启动

| 记号 | 条件 | 判决 |

| **J4** | `s12` 的 state 里**不出现** `b#1` 或**出现** `b#12` | **装置没生效**（先验正控失败）⇒ 本轮作废，不许读成 J1/J2 |
| **JB** | `s12` 两轮均 Σ=48、`e1wi`=0、首句柄 `b#1` | **治污成立**：那条边被拆掉了 |
| **JC** | `s12` 的 state 首句柄是 `b#1`，但 Σ **仍 64**（`e1wi`=16） | **+16 不只来自编号** ⇒ §90 的 J1 收窄，`b#12` 只是必要不充分 |
| **J0** | `s12_r1` 与 `s12_r2` 的 17 个 state 快照不全同 | **装置不可重复** ⇒ 本轮作废 |

（而不是「这一轮压根没 dump」）。所以 `J4` 排在 `JB` 之前。

**第二组：校准组（零信息时的跨轮净效应）** — `d2` 累积 2 轮（echo=0, static=2）+ `f2` 重置 2 轮（对照）

| 记号 | 条件 | 判决 |
|---|---|---|
| **JD** | `d2` 两轮 17 个 state **逐字节相同** 且 Σ 相同 | **累积循环在零信息下净效应 = 0** ⇒ 基线校准成功，此后任何跨轮 Δ 都可归因于内容 |
| **JE** | `d2` 两轮 state 逐字节相同，但 Σ **不同** | 违反 `T=0` 确定性 ⇒ 确定性结论要**重写**（与 V26 的 J2 同形） |
| **JF** | `d2` 两轮 state **不同** | 归因未完成：必须逐行 diff，指出**还有哪条边**在泄漏（`b#` 之外的） |

### 2.2 分母（三选一，必须现在写死）

**按题算**（6 题 × 16 格 = 96 格，可达上限 64）。理由：
本轮所有判据都是「某几格的交付件是否逐字节相同」，题是天然的独立单位；
`repeat=1`、每臂每轮只跑一次 ⇒ 不存在 rep 内部重复，按题算不会虚增样本量（纪律 11）。

### 2.3 我的预期（可被自己读数否证）

押 **JB + JD**：

- `s12` 两次都 **48**（`e1wi`=0，`4e9be367`，首句柄 `b#1`）；
- `d2` 两轮 state **逐字节相同**、Σ 都是 **48**。

⇒ 若 `s12` 是 64，我押错（JC），且说明 §90 的因果链缺一环；
若 `d2` 两轮 state 不同（JF），说明还有别的泄漏边，`b#` 不是唯一的一条。
