## 1 载荷为什么「必然够用」（这是本轮唯一的新东西）

逐字核对 V30 `o4_r2` 的交付件，三题恒 0 的失败**不是题难**，是同一个形状：

| 题 | 骨架里**没给**的东西 | 模型实际交了什么 | 报错 |
|---|---|---|---|
| `e1ni` | 顶部 `import re` | 整个函数，**没有** import | `NameError: name 're' is not defined` |
| `e2ni` | 顶部 `import json` + 三个辅助函数 `_dump/_split/_add` | **只有** `def group_names` 那一段 | `NameError: name '_split' is not defined` |
| `e3ni` | 顶部 `import datetime` + `_split/_read_day/_monday_of/_add` | **只有** `def week_of` 往后 | 同上 |

而题面的「编辑约定」**已经写了**这两个要求（补 TODO 之间、顶部可加 import、其余逐字保留）。
⇒ 模型不是「不知道」，是**在同一份长 prompt 里没执行**。
V30 `p4` 甚至把它自己的报错原文（`name '_split' is not [defined]`）送到了 `e2ni` 面前，
那一格仍然是 0 —— **只给诊断不够，得给动作。**

载荷 P（74 字，落盘在 `make_seed.py`）：

```
骨架要整份原样输出（含 _split 等辅助函数），只在 BEGIN/END TODO 之间填代码，其余逐字保留；顶部补上本题用到的 import。
```

它的可视性已被探针量过：`as_line()` = `[tasks_v8/e3wi] 1.00 — ` + `why[:120]`，
`core.py:1443` 再切 `[:140]` ⇒ 23 + 74 = **97 ≤ 140**，P **逐字完整可见**（`p0_reach.txt` Q1b）。

## 2 单变量是怎么做出来的：把「同一段字」放进账本的不同条目

`core.py:1443` 是 `crit[-3:]`，`critique.py:126` 按 `task_id` 字典序排 ⇒ **每题的送达窗口固定**：

| 当前题 | 送达的三条 |
|---|---|
| `e1wi` / `e1ni` / `e2ni` | `e2wi`, `e3ni`, `e3wi` |
| `e2wi` | `e2ni`, `e3ni`, `e3wi` |
| `e3wi` | `e2ni`, `e2wi`, `e3ni` |
| `e3ni` | `e2ni`, `e2wi`, `e3wi` |

⇒ **`e1ni` / `e1wi` 两条永不送达任何人**；**`e3wi` / `e2wi` 出现在除自己以外全部 5 个窗口**。

于是「P 放 `e1ni`」= 账本里有这段字、**零送达**；「P 放 `e3wi`」= 同样一段字、**送达 5 题**（含三个 `ni` 目标）。
账本条数、其它五条内容、总字数**全部不变** ⇒ 这才是单变量。

### 判决表（按顺序执行，先命中先判）

1. **`J0` 装置失效** —— `P0-g` 或 `P0-h` 不过。⇒ 不出判据，修装置。
2. **`J_NOROOM` 装置无分辨率** —— `s4` 与 `s1` **逐格完全相同**（Σ 同，且 6 格一一相同）。
   ⇒ **V19~V30 十二轮零读数全部改标为「未测到」**；「把材料送进 prompt」这条路在本装置上
   **不可判**，后续不许再用同一装置做「有没有用」的实验。
3. **`J_INVERT`** —— `s4` 有格下降 ≥16 且**无格上升**。⇒ 载荷有害（与 §89 `e1ni` −16 同形）。
4. **`J_DICE` 置换** —— `ΔΣ(s4−s1) = 0` 但存在格间反向移动；**或** `s3` 也发生了 ≥16 的格移动。
   ⇒ 那 74 字仍是扰动骰子（相消第四次），**分辨率仍未证**，且必须登记 `s3` 的具体格子。
5. **`J_RESOLVED` 有分辨率** —— 同时满足：
   - `ΔΣ(s4 − s1) ≥ +16`；
   - 至少一格 `s1=0 → s4=16`；
   - **该格的交付件里出现 P 要求的结构**（顶部 `import` 与骨架原有函数在）；
     ⛔ 只看分数不算 —— 分数涨了但答案里没有那个结构 ⇒ **记为 `J_DICE`**（修复不是来自 P）；
   - `ΔΣ(s3 − s1) ≤ 0`（安慰剂不涨）。
