## 九、补记（同日收尾）：那 2220 字节找到了，而且**推翻了本文第二节的 D1 结论**

> 证据：`p4_tail.txt`（`probe_v36_tail.py`，零模型、零网络、只读 `/tmp/v36` 冻结产物）

### 9.1 先认错

本文开头那句「**累积的记忆一个字节都没进 prompt**」是**错的**。
D1 只比了 `_state()` 的 6 个块，而 `_state()` 是 `--state-dump` **唯一**落盘的东西。
**差额落在另一条渲染路径上，D1 结构上就看不见。**

正确表述：
**累积经 `recall(动作)` → 世界模型事实 → 预演 prompt，进去了 268~488 字节；
但它一个决策也没有改变**（21 个 state 逐字节相同、96 格分数一格未动）。
"没进 prompt" 与 "进了但没用" 是两件完全不同的事，本轮之前我把它们混成了一件。

### 9.2 那 5 条差异是谁（三步钉死）

| 步 | 证据 | 结论 |
|---|---|---|
| ① 分类 | 每轮 34 条 = **24 条 `max_tokens=1024`（规划/收尾）+ 10 条 `200`（预演）** | `200` 只来自 `WorldModel.predict`（`worldmodel.py:398` 写死） |
| ② 定位 | 5 条差异 `[3,6,11,24,30]` 的 `max_tokens` 取值集合 = **{200}** | **全部是预演调用**，规划调用 24/24 逐字节相同 |
| ③ 算账 | `known=1条 ⇒ 268 字节`、`known=2条 ⇒ 488 字节`；实测 Δ 取值 = `[268, 488]` | **逐字节命中** |

`known` 的渲染规则（`worldmodel.py:686`）：

```
"已知易错点：\n" + "\n".join(f"- {f.text}" for f in wm)
  36 + 2 + (2+228)        = 268     ← 只有事实 A
  36 + 2 + (2+228) + (2+216) = 488  ← 事实 A + 事实 B
```

两臂的库（`/tmp/v36/mem_cum` 180KB / `mem_rst` 114KB）：

| | facts | worldmodel | episodes |
|---|---:|---:|---:|
| cum | 2 | 2 | 56 |
| rst | 1 | 1 | 27 |

cum 多出的 id=2 就是那 216 字节。**不是"大约 488"，是 268 与 488 两个数都被算干净。**

### 9.3 通路（每一行都可复核）

```
core.py:1036        pred = self.wm.predict(state=state, action=cand.as_line())
worldmodel.py:391   known = self.guidance(action=action, k=3)
worldmodel.py:683   facts = self.memory.recall(action, k=k)      ← 同一条 recall
worldmodel.py:684   wm = [f for f in facts if f.source == "worldmodel"]
```

⭐ **这同时回答了 V37 的第 3 条**：`recall` 没有坏。
`recall(goal)`（1700 字的长题面）0 命中 —— 那是 V35 测的 626 次 0 差异；
`recall(action)`（`finish({...}) — 意图` 这种短动作行）**有命中**。
⇒ 「语义记忆是死的」要改成「**长检索词在 FTS 上打不中，短检索词能打中**」。

### 9.4 ⛔ 为什么 2220 字节没换来一格分数

`grep pred mw/core.py` 一共 **6 处**，全部在这里：

```
1034  pred = None
1036  pred = self.wm.predict(...)
1037  if not pred.trustworthy:      ← 只决定"记不记这条读数"
1039      self.log(...)
1099  if pred is not None and pred.trustworthy:
1100      mm = self.wm.observe(pred, ..., ok=result.ok)   ← 只用于事后学习
```

候选是在 **1036 行之前**就定好的（`cand` 来自 `plan.steps[:n]`）。
预演**不选动作、不否决、不重排** ⇒ **它是纯观测，不是决策输入。**

于是这条环是：

> 预演 → 执行（不受影响）→ 事后比对 → 沉淀成事实 → 下一次预演的 `known` 变长
> → 预演更「有依据」→ **仍然不影响执行**

**它是一个闭合的学习环，但和"行为"之间没有边。** 这正是 §99 那条
「机制存在 ≠ 机制通电」的第三种形态：**通电了，但输出端接在记录仪上，不接在执行器上。**
