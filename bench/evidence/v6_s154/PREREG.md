## 2 本轮改的是什么

```diff
 _ANSWER_SYS = (
-    "只输出最终答案本身：不要 JSON、不要解释、不要道歉、不要代码块围栏。"
-    "如果是代码，直接输出代码原文。"
+    "直接输出最终答案：代码就给代码原文，文字就给正文。"
 )
```

选 v4 而不是 v3（"如果是代码，直接输出代码原文。"）的理由：
`_ANSWER_SYS` 也服务**文本题**（如 AZ117 的"用一段话说明快排"），v3 对文本题**没有任何指令**。

契约侧同步：4 处 fixture 原本按字面量 `"只输出最终答案本身"` 分派答案调用，
改成 `from mw.planner import _ANSWER_SYS`（变量比较）—— 否则改一次提示词就把 fixture 打红，
而那红的**原因不是行为变了**（纪律 1 的"红=无"第三种形态的近亲）。
