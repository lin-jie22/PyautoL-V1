# V73 预注册 —— 打回后的重写**不带状态**：把「逐字重提」这条死边剖开

> ⛔ 与脚本不一致时只认本文件。
> ⛔ 本轮**只改一处输入构造**（`_carry` 分支的 `state`），不改任何提示词文本。

## 0. 先写三条对本轮不利的事实

1. **对照是历史跑批，不是同轮并行两臂**。基线取 V67 的 8 跑（`bench/evidence/v6_s156/`），
   它们与本次用**同一脚本、同一常量**，唯一差别是 `V1_REJECT_CARRY=1`。这不是严格的
   同时对照；缓解手段只有一条：基线 8 跑的 `kernel_rework` **逐格相同**
   （`carried=1 / redelivered=2 / same=2 / diff=0 / dup_skipped=2 / passed_after=0`），
   说明这个格子在 T=0 下是确定的。
2. **`state` 的含义与 V65 那一刀不是同一个调用点**。V65 第四刀测的是**收尾交付**
   （`planner.answer`）的 state；本轮改的是**打回后的重规划**（`planner.replan`）。
   所以本轮是**外推**，不是复现。押注按外推登记（见 §4，不押"升"）。
3. **本轮不以 `mean` 为判决依据**。理由：单题动满 1.0 只值 `1/6 = 0.111`，
   低于形状噪声 **0.1290**（V65 §3）⇒ 用 `mean` 判"变强"必然分辨不出。

## 1. 要回答的问题（接 V71 / V72 / V65）

V71：`redelivered=19 / same=18 / diff=1` ⇒ 打回之后，模型**逐字重交**。
V72：`example_runs` 在 V68~V70 全 0。**本轮更正**：那三轮的题集（`g7e` / `struct_convert`）
本身没有 `example` 判据 ⇒ 0 是**题集的性质**，不是内核的性质。`coding_small` 上
`example_runs=5 / example_failed=2`，**每跑都是**（V67 八跑逐格相同）—— 传感器一直在跑。

⇒ 传感器通、反例通（`--state-dump` 原文里既有 `TypeError` 也有模型自己那份代码）、
写端通（`rewards_recorded` 不计但库内 `kind=reward` 有 20 条）。
**唯一不动的是"重写出来的还是同一份"**。

V65 第四刀给了一条线索：同 system / 同题面下，state 从 2329 字改成 107 字的
`[工作记忆]` 仍是 2/6，改成**空**才 6/6 ⇒ 那一块**在不在**比它写什么更能改输出。

本轮的刀就切这里：**打回后的重写不给状态块，只给目标 + 轨迹 + 报错原文。**

## 3. 判据（字段名带分母，全部三值）

| # | 判据 | 基线（V67 八跑） | 押 |
|---|---|---|---|
| P1 | `diff / redelivered`（次 / 次） | `0 / 16`（每跑 0/2） | **升**（出现 ≥1 次真改版） |
| P2 | `t04_merge_ranges` 分数 | `0.3333`（每跑逐格相同） | **升** |
| P3 | `example_failed`（次 / 跑） | `2`（每跑） | **降** |
| P4 | 题级 `mean` | `0.8611` | 三值，**不作判决**（见 §0.3） |

押 P1「升」的机制：`diff` 现在恒 0，而 `dup_skipped=2` 说明两次重交都被判成"同一动作"；
若状态块是决定输出的那一项（V65 第四刀的结论），去掉它就该至少出现**一次**不同实现。

## 4. 分母口径（写进字段名）

- `redelivered` = **次**（打回之后又交了一次），不是题、不是跑 ⇒ `diff/redelivered`。
- `example_failed` = **次 / 跑**（`kernel_verify.example_failed` 每跑一个）。
- 题级 `mean` = 6 题平均分（`report.per_task.score`），**不是**断言级。

## 5. 通电自检（先于任何解释）

若 P1 与基线逐格相同（`diff=0`、`same=2`），**先别下"没效果"的结论**，按顺序查：

1. `logs/core.log` 里有没有 `↻ 打回重写：不带状态（REJECT_CARRY=2）` —— 没有 ⇒ 记 **UNKNOWN**（开关没走到）。
2. `--state-dump` 里那一轮的 `state` 是否真的变短 —— 没变 ⇒ 记 **UNKNOWN**（构造没生效）。
3. 两者都在、`diff` 仍 0 ⇒ 才可以记「**状态块的缺席不足以改变重写**」，并把 V65 第四刀的结论
   **限定在收尾调用**上（这是本轮能给出的最有价值的负结果）。
