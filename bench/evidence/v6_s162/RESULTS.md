# V73 结果 —— 打回后的重写**不带状态**：三种判据全部落在「平」，且不是没通电

> 一句话：**把状态块整个拿掉，重写出来的还是逐字同一份。**
> `redelivered=16 / same=16 / diff=0`（基线 `14/14/0`）⇒ 「逐字重提」不是提示词**输入构造**的问题。

## 0. 先纠三处我自己的错（⛔ 不许藏）

1. **预注册里写「基线 V67 八跑」是错的**：`bench/evidence/v6_s156/` 里只有 **7 份**
   `runs_v67_*.jsonl`（`r1~r5` + `c1_empty` + `c2_dump`）。本轮实际基线 = **7 跑**。
   判据的分母随之改为 `diff/redelivered = 0/14`（不是 0/16）。
2. **V72 的一句话要更正**：V72 写「`example_runs` 在 V68/V69/V70 全部 0」，据此推出
   「同轮无传感器」。本轮实测 `coding_small` 每跑都是 `example_runs=5 / example_failed=2`
   —— **0 是那三轮题集（`g7e` / `struct_convert`）的属性，不是内核的属性**。
   传感器在 `coding_small` 上一直通着。
3. **`V1_REJECT_CARRY=2` 是既有字段的新取值**，没加 `Limits` 新键 ⇒ 契约 629/0、
   锚层 97/0 与改动前逐格相同（`/tmp/v73_gate.txt`，`EXIT=0`，3m08s）。

## 4. 结论（本轮唯一正读数）

**「重写还是同一份」的最后一个输入构造解释被排除。**

链条现在是闭合的（每一环都有原文/计数）：

| 环 | 读数 | 出处 |
|---|---|---|
| 传感器在 | `example_runs=5 / example_failed=2`，每跑 | 本轮 8 跑 + V67 7 跑 |
| 报错到得了模型 | `自检未通过：… TypeError: 'tuple' object does not support item assignment` 在 `[工作记忆]` | `state_dump_v67_c2.jsonl` it=3 原文 |
| 模型自己的代码也在 | `[轨迹] [step 2] finish({'answer': '… merged[-1][1] = max(...)'})` | 同上 |
| 打回会发生 | `carried=8`、`rejected` 每跑 1 | `kernel_rework` |
| 重写**不换路** | `same/redelivered = 16/16`，`diff=0` | 本轮 |
| 去掉状态也**不换路** | 同一格，且开关 8/8 通电 | 本轮 |
| 分数不动 | `t04=0.3333` ×15 跑、`mean=0.8611` ×15 跑 | 两臂 |

⚠️ 边界（⛔ 不许越读）：

- **不**能说"模型不会做这道题"：V65 探针里同一模型单轮 `t04 = 6/6`（`state=""` + 纯正向 system）。
- **不**能说"状态块无害"：V65 第四刀证明它**存在与否**能翻输出；本轮只证明**在 `replan` 这条路上**
  拿掉它不足够。
- **不**能与 `0.8611` 做相减式判决：本轮 `mean` 一格没动，本就不该拿它当证据。
