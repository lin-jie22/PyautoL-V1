# V80 预注册：差分自检的**前置量测**（分歧率在错题上是否高于对题）

> 本轮**不跑批、不改内核**。只回答一个问题：
> 「同一题独立采两份实现，行为分歧这件事，在**错**的实现对上是不是比在**对**的实现对上更常见？」
> 若答案为否（对题也大量分歧）⇒ §148.5 的 C 方案（差分自检）**不能开一整轮**。

## 0. 为什么必须先量这一步

纪律第 3 条：押「A 能让 B 发生」前，先量 B 在 A 之前**存在过没有**。

C 方案的全部假设是「分歧 ⇒ 至少有一份错」。这个假设**从未被量过**。
如果两份**都过测**的实现也经常在同一输入上给出不同结果，那么「分歧处打回」会在
61 道没有期望值的题上**大量误伤**，等于把 V77 修好的边变成随机扰动。

## 1. 装置（全部现成件，不新建判据）

| 环节 | 用什么 | 为什么不新造 |
|---|---|---|
| 题 | `bench/heldout/{struct_convert,g7j_n4,numeric_logic}_heldout.jsonl`，共 **11 题** | 现成题集，V78 已量过基线 |
| 采样通道 | `Planner.answer(goal, clean=True)`（`V1_REJECT_CARRY=5` 的交付协议） | 就是 V77 通电的那条边 |
| 采样数 | 每题 **4 份**，`T=0.8` | 4 份 ⇒ 6 对/题 ⇒ 66 对分母 |
| 判定「过没过测」 | `mw/verify.py: run_example(code, tests)` | 单一时真源，与评分器同一把尺 |
| 输入电池 | 题面 `tests` 里的**调用表达式**（用 `ast` 抽出，**丢掉期望值**） | 不手写输入 ⇒ 不引入我的偏好 |
| 分歧判定 | 两份实现在**同一输入**上的返回值（或异常类型）不相等 | 行为比较，不用文本 diff（文本必然不同） |

### 1.1 ⚠️ 输入电池的口径边界（先写下来）

这一版输入来自**题集自带的判分用例**。内核在部署时**看不见**这些用例
（`derive()` 只吃题面，§147.3）。所以：

- 本轮读数只回答「**行为分歧里有没有信号**」；
- **不**回答「不借助判分输入能不能拿到信号」（那需要模型自拟输入，属另一轮）。

⛔ 不许把本轮的「有信号」写成「差分自检可部署」。

## 2. 分母（三选一 + 理由）

**主分母 = 实现对（pair）的个数**。理由：判据「这两份会不会在同一输入上分歧」
天然是**对**级的；按题压成 1 会丢掉「同题 6 对里只分歧 1 对」这种结构。
**次读数**按题（11）与按输入点（每对 5 点）各报一次。

## 3. 分组（label 来自 `run_example`，不是我看代码猜的）

| 组 | 定义 | 含义 |
|---|---|---|
| `PP` | 一对两份**都过测** | 分歧 = **假警报**（评分器认为两份都对） |
| `FF` | 一对两份**都不过测** | 分歧 = 真信号（至少两份都是错的） |
| `MIX` | 一份过、一份不过 | **构造自检组**（见 §4） |

## 4. 构造自检（⛔ 这不是预测，是检测器有效性）

`MIX` 对**必然**在某个判分输入上分歧 —— 因为 `tests` 正是判定它们一过一不过的依据。
⇒ `MIX` 组的分歧率**必须 = 1.0**。若 < 1.0，说明我的抽取器/比较器有 bug，
**本轮全部读数作废**（不是"发现新现象"）。

同理，另两条检测器有效性检查：
- `text_unique`：每题 4 份样例的**代码文本去重数**。若某题 = 1（四份逐字相同），
  则该题的行为分歧率 0 **不能**读成「模型很确定」，只能读成「T=0.8 没起作用」。
- `parse_ok`：抽出可执行代码的比例。若过低，样本池不代表真实交付。

## 5. 预测（押三值）

| # | 内容 | 押 |
|---|---|---|
| P1 | `R_FF − R_PP ≥ 0.30`（错对更爱分歧，绝对差） | **升** |
| P2 | `R_PP ≤ 0.20`（对题上的假警报率低） | **降**（押它足够低） |
| P3 | `R_FF` 在**至少 2 个套件**里非空（≥1 对分歧） | **升** |

## 6. 开 C 方案的闸（全部满足才开）

```
MIX == 1.0（构造自检过）
且 text_unique 中位数 ≥ 2（采样真的有变化）
且 R_FF ≥ 0.40
且 R_PP ≤ 0.20
且 P3 成立（≥2 套件）
```

任一条不满足 ⇒ C **不开**，改走 §148.5 的 D（换 14b）或 E（承认入口只有 4 题）。

## 7. 已知会让本轮读成 UNKNOWN 的情形（先写下来，事后不许改口径）

1. 采样池里 `PP` 对少于 **10** 对 ⇒ PP 组分母不足，`R_PP` 只报区间不报判决。
2. 多数题 `text_unique=1` ⇒ 采样通道没通电，本轮作废。
3. 电池故障（`EXEC_FAULT`）占比 > 10% ⇒ 比较器不可信。
