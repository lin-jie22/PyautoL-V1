# V83 预注册 —— 语义记忆的**送达率**：读端入口标定（零 LLM）

> 写于实跑之前。⛔ 判据与分母口径在此定死，跑完不许改。

## 0. 为什么是这一轮

V82 判决：`distill()` 在 `run.py` 有 **0** 个调用点，`recall()` 只读 `facts`，
生产路径上"把昨天的正确交付变成今天的经验"这**条边根本不存在**。

但在修这条边之前必须先回答一个更前置的问题（纪律 3：押「A 能让 B 发生」前先量 B 存在过没有）：

> **就算我把一条完美的人写经验塞进 `facts`，它到底能不能到达模型眼前？**

如果连这一步都是 0，那 V82 之后要修的是**读端入口**，不是蒸馏器；
而且过去几十轮"累积 Δ=0"的归因也要重写 —— 不是"记忆无用"，是"载荷从没到过"。

### 本轮已有的先验证据（不是新读数，但指方向）

| 证据 | 读数 |
|---|---|
| `bench/evidence/{v6_s154,v6_s156,v6_s157,v6_s158,v6_s159}/state_dump*.jsonl` | 51 行 state **全部**不含 `[语义记忆]`（⚠️ 预注册初稿写 47，是我数错；跑后按文件重算见 `archived_state_scan.out`，判据方向不变：0/51） |
| `bench/evidence/knowledge_s47/state_dump.jsonl` | 6/6 行**含** `[语义记忆]`，4 条 `ZK1..ZK4` 惯例全在 |

两者的差别不是"有没有 facts"（A5 臂库里有 3 条），而是 **knowledge_s47 的题面与 fact 共享一个字面 token `ZK1`**。

⇒ 待验假设 **H1**：`recall(goal)` 只在**字面 token 完全相等**时命中；
中文经验与中文题面之间没有这种相等 ⇒ 送达率 = 0。

⛔ 不许把 `kernel_worldmodel.layer_recalled = 0` 当证据：那个计数只在
`memory_mode == ABSTRACT_MODE` 时累加（`core.py:2242`），非 abstract 臂上它**恒为 0**，
是"缺席冒充零"的教科书形态。

### 4 条人写经验（写在这里，⛔ 跑完不许改字）

| 题 | 经验原文 |
|---|---|
| k01 | 递归比较两份嵌套结构时，先把差异路径按层级用点号连接，再让某一侧缺失的值留空 |
| k02 | 拼接键值对之前，先确认多个项之间用分号紧跟一个空格连接，值里的特殊符号要逐字符转义 |
| k03 | 把带下标的扁平键还原成列表时，先取出现过的最大下标加一定长度，空位留空值而不是跳过 |
| k04 | 生成分节文本时，先确认每行末尾都要带换行，包括最后一行；空结构返回空串 |

（这 4 条必须通过 `looks_like_code()` 与 `_IDENTIFIER` 两道过滤 —— 它们是"蒸馏器理想输出"的形态。）

## 2. 三种候选读法（单变量 = 查询/索引策略）

| 代号 | 做法 | 改动面 |

## 3. 判据（分母写进字段名）

- `hit4_sN` = 4 题中，"本题对应的那条经验出现在 `recall(goal, k=6)` 前 6 名"的题数
- `distract_top6_sN` = 前 6 名里无关事实的条数（精度）
- `self_hit4` = 用经验原文当 query 时的自命中题数（**证明 FTS 本身没坏**的对照）

### 押什么（三值，⛔ 不许事后改）

| 判据 | 押 | 理由 |
|---|---|---|
| `self_hit4` | **4/4** | 原文自匹配必然命中；若不是 0 ⇒ 装置坏了，整轮作废 |
| `hit4_s0`（现状） | **0/4** | `_TOKEN` 把连续中文当一个 token，题面与经验的中文 run 不可能逐字相等 |
| `hit4_s1` | **4/4**，`distract_top6_s1` **≥3** | 2 字链能召回，但常见字对会误招 |
| `hit4_s2` | **4/4**，`distract_top6_s2` **≤1** | 短语查询能同时保召回与精度 |

## 4. 判决分支（预先定死，不许跑完再商量）

- **若 `hit4_s0 == 0`**：**臂不开**。这不是"记忆无用"的判负，是"载荷从未送达"的机制判决。
  下一刀 V84 = 换读端入口，判据就是 `hit4` 从 0 到 4（外部可核，不依赖系统自评）。
- 若 `0 < hit4_s0 < 4`：记录哪几题命中、共享的是哪个字面 token（H1 的部分验证）。
- 若 `hit4_s0 == 4`：H1 被否证 ⇒ 我上面的先验证据解读错了，回头查 `state_dump` 那 47 行为何没有块
  （那时候才轮到怀疑 `state_chars` 挤压，而不是检索）。

⛔ 无论哪个分支，**本轮不跑模型臂**：`hit4` 是必要条件的读数，不是效果的读数。
