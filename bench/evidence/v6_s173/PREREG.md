# V84 预注册 —— 语义记忆**读端**：把 2 字链检索接成「零命中后的第二级」

> 落盘时间：跑任何测量**之前**。⛔ 跑完只许追加「实测」段，不许改判据。

## 0. 问句

V83 已量出：把一条**人写的完美经验**写进 `facts` 之后，`recall(goal)` 一题也取不回来
（`hit4=0/4`，题面 token 与本题经验的**精确交集 = 0/4**），而同一份经验拿原文当 query
自命中 4/4 ⇒ FTS 没坏，坏在「题面 → 经验」这一跳。

本轮问句只有一个：

> **把这一跳修好之后，「累积的知识」是否第一次真的进了模型眼前？**

这条不是「让分数变高」，是让 V82 卡住的 E（零记忆 vs 累积记忆）**变成可测**。
⛔ 若本轮只把分数动了、送达仍为 0，则按上轮口径记为「修的仍是别的东西」。

## 1. 变量（单变量）

`MemoryStore.recall` 的**零命中出口**：现状 `return []` ⇒ 改为「先试字级 2 字链检索，
有命中就返回，无命中才 `[]`」。

**为什么只能做第二级，不能替换第一级**（这一条是读代码得到的**先验事实**，不是本轮测量）：

`tests/contract_test.py:7024` **AZ26** 把 `recall` 的命中**条数**钉死成三个字面量：

| 题面 | 期望条数 |
|---|---|
| `g7j_n0`（提 1 把钥匙） | `[1, 1, 1, 1]` |
| `g7j_n4`（提 4 把） | `[4, 4, 4, 4]` |
| 原题面（不提钥匙） | `[0, 0, 1, 1]` |

字级 2 字链在自然中文上召回远高于现状（V83 实测 S2 在同一池子上 `hit4=4/4`），
**替换**第一级必然让 n0 的条数 >1、原题面从 0 变非 0 ⇒ AZ26 红。⇒ 只能**追加**。

连带结论（结构性的，不是测出来的）：凡是第一级已经非空的题，新读端走的路**一个字节都没变**
⇒ 注入条数与字符数**逐题恒等**。所以 §152.6 的 G3 与 G1 不再互斥。

## 2. 内部矛盾修正（在测量之前改，必须显式记）

§152.6 原文的 **G3「注入条数与字符数逐题与旧读端完全相等」与 G1「hit4=4/4」互斥**
—— struct 4 题的旧读端是 0 条，要 4/4 就必须变。这是 V81 犯过的同一类错
（判据之间自相矛盾 ⇒ 怎么跑都能挑一半）。

**改法**：G3 的作用域收窄到「旧读端已送达的题」，struct 4 题上 `0 → N` 是**处理本身**，
不是要控制的混杂。⛔ 这不是放宽，是把「邻域恒定」用到它真正该管的那一半。

## 3. 判据（四条，形态写死，全过才开臂）

| 闸 | 线 | 形态（怎么数） |

分母口径（写进字段名，⛔ 不写「大概」）：
