## 2. 判决

1. **主押命中（升）**：`B > C`。C 与 B **同为 4 条送达、字数差 2.5%**，
   唯一差别是**内容** ⇒ 抬分的是**知识内容**，不是「多了一个块」。
2. **「有块」的白送效应存在但产不出满分**：C 把 `g7d2` 从 0.2 抬到 **0.6**（安慰剂里
   「按原样比较、保留最后一次」恰好贴近题面默认读法），其余三题**一格不动** ⇒ C 满分率 **0/8**。
3. **`g7d3` 是「知道 ≠ 照做」**：B 臂交付的代码是 `"{:,.2f}".format(x)` + 括号包负数
   ⇒ 只照做了 ZK2 的**负号那半条**，千分位仍用逗号 ⇒ 2/5。⛔ 不是没送到（211 块在），
   是**照做了一半**。
4. ⛔ 不外推：4 题、n=2、T=0、知识是**人写**的。本轮证明的是**上限**，不是「系统自己会变强」。

## 3. 意外发现（本轮第二读数，不进主判据但更重要）：**写端有活的通道**

C 臂两跑里各有 **1 次** `note ok=True`（A/B 各 0 次）。跑完库里多出第 5 条：

```
source=惯例记忆 | fmt_amount(x): 根据ZK2惯例，千分位用逗号分隔，保留两位小数，负数在数字前面直接加一个负号。
```

- 这是**模型自己**调 `note` 工具写进去的（`mw/tools.py:202-215`，`allow_note` 默认 **True**，
  `mw/config.py:434`），内容是它**这一次自己的实现**所依据的惯例 —— 而那条是**错的**。
- 于是 C 的 `g7e1`/`g7e2` 两题看到的是 **5 条**（273 字），不再是等长安慰剂。
- B 臂**一次也没写**（有正确知识就不写）⇒ 写端是**条件触发**的：缺知识时写、有知识时不写。
- ⛔ **更正 V82**：V82 的「桥在生产路径上不存在」只对 `abstractor.distill`（0 调用点）成立。
  写端其实有**两条活着的通道**：`note`（模型主动）与 `worldmodel.learn()`（失配沉淀，
  `allow_learn` 同样默认 True）。正确表述是：
  **写端有路，但没有一条经过验证 —— 失败路径会写，写的是自己的猜测。**
- 这就是「自我强化错误」的现场形态：0.2 分的交付，照样把它的错误惯例沉淀进库。

## 4. 押错与自踩（都登记，不改判）

1. **预注册押的正是 `B > C`** ⇒ 命中。但**没预见 C 会自写事实** ⇒ 「等长安慰剂」
   在第三/第四题上**不再等长**（273 vs 211）。方向对 B 不利（C 更大），故不推翻 B>C。
2. **§153.7 的 k04 前置被撤回**（前提为假）：失败用例 `{'s': {}, 't': {'b': 2}}` 对应的
   「每个 section 输出 `[section]` 一行」**题面里已写死** ⇒ 改写经验只能复述题面，
   不构成「积累来的知识」。与 V81「F 只覆盖题面写全的题」同型。理由写在 `PREREG.md` §0。
3. **差点把 `g7d3` 读成「知识没送到」**：state 块实测在（211 字），失败原因是照做了一半。
   ⛔ 教训：分数不满分时，先看**块在不在**，再看**块里的内容够不够**，最后才是「照不照做」。
4. **C 臂的块字数 216≠211** 不是异常：安慰剂四条总长 207 + 3 个分隔符 = 216，B 是 202+9=211。
