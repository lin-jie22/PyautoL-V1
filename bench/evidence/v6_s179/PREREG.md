## 2. 分组规则（按**内容**分，不按标号）

⛔ 这是本轮最关键的口径：V85 的 C 臂是**同标号安慰剂**（块里写着「（ZK1）…」但内容是常识默认）。
按标号分组会把安慰剂算成「有知识」⇒ 必须按**原文判别子串**判定。

| 键 | 子串（逐字取自 ZK 原文） | 安慰剂里的对应写法（应当判 0） |
|---|---|---|
| ZK1 | `转小写` | `不改变大小写` |
| ZK2 | `千分位用空格分隔` | `千分位用逗号分隔` |
| ZK3 | `这类历史脏值` | `都算真` |
| ZK4 | `U+2026` | `三个英文句点` |

每题所需的 ZK（与 `make_seed_v85.py` / `make_seed_v87.py` 的构造一致）：
`g7d2_dedupe_keep→ZK1`、`g7d3_fmt_amount→ZK2`、`g7e1_parse_flag→ZK3`、`g7e2_truncate_tail→ZK4`。

每格打三个特征：
- `own` ∈ {0,1}：块内含**该题所需 ZK 的原文**（判别子串在）。
- `label` ∈ {0,1}：块内含该题所需 ZK 的**标号**（`（ZKk）`）。
- `n`：块内 ZK 标号个数；`full` = `n==4`（四条都在）。

## 3. 判据（押三值；每条写死聚合口径）

| 判据 | 口径 | 押 |
|---|---|---|
| **P1 地板** | g7j 格中 `own=0`（含空块、含安慰剂）的全部格，`max(score)` | **= 0.2**（不允许出现 >0.2） |
| **P2 天花板兑现率** | g7j 格中 `own=1 且 full=1` 的格，`score==1.0` 的比例 | **0.75**（±1 格） |
| **P3 总体兑现率** | g7j 格中 `own=1` 的全部格，`score==1.0` 的比例 | **∈[0.45,0.75]** |
| **P4 低于地板** | g7j 格中 `own=1 且 score<0.2` 的格数 | **≥1** |
| **P5 安慰剂** | V85 C 的 8 格：满分格数 / `max` | **0 / ≤0.4** |
| **P6 两族不重叠** | struct 16 格（全部 `own=0`）的 `min` 与 `mean` | **min≥0.2 且 mean≥0.5**（与 P1 的 0.2 上限并存 ⇒ 两个题族同一条件、分布不重叠） |

补充登记（不判命中，只报数）：
- 位序 `pos`（own 的 1-based 名次，缺席=0）与分数的关系；
- 兑现率的 **Wilson 95% 区间**（n=24 时 18/24 的区间）；
- `label=1 但 own=0` 的格数（安慰剂陷阱的规模）。

## 4. 三种可能的结局与各自含义（先写死，避免事后叙事）

1. **P1 命中、P3 不命中**（兑现率显著低于 1）⇒「知识必要但不充分」被量化：
   累积能给的是**上限**，不是**保证**；且因为噪声地板 = 0（V88 P5 三次确认），
   **同一提示重试不可能提升兑现率** ⇒ 下一刀必须动「重试时块变不变」。
2. **P1 不命中**（出现 >0.2 的无知识格）⇒ 「0.2 地板」是我读表读出来的假象，
   §157.2 的边际曲线（借 0.20 当零点）要作废。
3. **P6 不命中**（struct 也被打到 0.2）⇒ 「规格只在记忆里的题」与「模型本来就会的题」
   没有分界，V85 的安慰剂设计失去解释力。
