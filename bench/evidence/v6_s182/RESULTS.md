## 3. 机制：逐字节，三臂在 g7d3 上的实现

| 臂 | 实现 | 分 |
|---|---|---|
| R1 规则 | `fmt_str = "{:,.2f}".format(x)` → `return fmt_str` | 0.4 |
| R2 示例·正确 | `"{:,.2f}".format(x)` → `.replace(',', ' ')` | **1.0** |
| R3 示例·错误 | `'{:,.2f}'.format(x).replace(',', '，')` | 0.2 |

⇒ **形式决定「是否执行转换」，内容决定「转到哪」**：

- 规则说「千分位用空格」⇒ 模型用默认的 `"{:,.2f}"`，**没有执行**换空格这个动作。
- 示例说 `1234.5 → '1 234.50'`（输出里**看得见空格**）⇒ 模型**必须**想办法产生空格 ⇒ `replace(',', ' ')`。
- 安慰剂示例的输出里是逗号 ⇒ 同一个 `replace` 动作，目标变成 `'，'` ⇒ 0.2。

⇒ 这是 V85「知道 ≠ 照做」的**解法**：**给结果，不要给意图。**

## 4. 为什么只有 g7d3 有效 —— 规则与示例分工不同

g7d2（去重 + 归一化）的实现：

| 臂 | 实现 | 分 |
|---|---|---|
| R1 规则 | `x_normalized = x.strip().lower()` | **1.0** |
| R2 示例 | `norm_x = x.lower()` —— **漏了 `.strip()`** | 0.6 |
| R3 安慰剂 | `norm_x = x.lower()` | 0.6 |

⇒ **g7d2 上 R2 = R3 = 0.6，示例内容一点没起作用**（`0.6` 是「只看大小写、不去空白」的固定结果）。

⭐ 两题合起来给出分工：

| | 规则擅长 | 示例擅长 |
|---|---|---|
| 传达的是 | **操作序列**（strip 再 lower） | **输出形态**（空格不是逗号） |
| 失败方式 | 认同但不执行（g7d3 0.4） | 只见树木（g7d2 0.6） |

⇒ **规则与示例是互补的，不是替代的。**
