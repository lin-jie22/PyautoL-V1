## 3. 三个新读数

### 3.1 ⭐⭐⭐ U2 反转：一句括号，胜者变输家

| | P0 | P1 | P2 |
|---|---|---|---|
| A1 − A0 | **+0.15** | **−0.05** | **−0.05** |

⇒ **V100 那个 1.00 的「优点」，连一句语义等价的括号改写都扛不住，而且反过来变成比基线更差。**
⇒ 任何形如「闭环把系统变强了 0.15」的说法，**在同一批题的另一份措辞下就会变成 −0.05**。
这不再是「泛化差」的问题，是**符号不稳定**的问题 —— 而符号是判据的最低要求。

⚠️ 诚实边界：反转**只在 g7d3 一题**上发生（A1 的 g7d3 1.0→0.4；A0 的 0.4→0.6）。
均值上的反号是**单题效应被 4 除**的结果，⛔ 不许写成「四题整体变差」。

### 3.2 ⭐⭐⭐ 「连带损伤」不是修改的属性，是 **(修改 × 题面)** 的属性

同一处编辑 `ZK2#34 、→,`，在三份题面下伤的东西**完全不同**：

| 份 | g7d3 | 受伤的题 |
|---|---|---|
| P0 | **1.0**（`8089eee6`） | **无**（四题全 1.0） |
| P1 | 0.4（`075b4099`，**退回到基线那个盆**） | **它自己** |
| P2 | **1.0**（`309f1027`，一个**新的满分盆**） | **g7e1**（1.0→0.4） |

⇒ V96 那条 `r(g7d3,g7e1)=−0.875` 的「拆东墙补西墙」，**换一份措辞就换一组墙**。
P1 里它修好的那题自己塌了；P2 里它修好的题保住了、却把另一题打坏。
**「这个修改好不好」这句话，在不知道题面的情况下没有真值。**

### 3.3 ⭐⭐ 两句话改法完全不同，给出**同一个实现**：效应来自「扰动」，不来自「意思」

P1（`（惯例不在题面里）`→`（这几条惯例没有写在题面上）`，字数 +5）与
P2（`惯例处理`→`惯例来做`，字数不变）是**两句意思与字数都不同**的话。结果：

- A0 在 P1 与 P2 上**都**得到 g7d3 = 0.6，盆**都是 `5755e033`**（同一个实现）；
- A3 在 P1 与 P2 上也是这个盆。

⇒ **起作用的是「这句话不再是原来那句」，不是它的内容**。
若内容在场，两句不同的话不该收敛到同一个字节。

⭐ 这同时排除了「字数」这个解释：P1 加 5 字、P2 一字不加，结果**逐字节相同**
⇒ 与 V95「长度不是因果量」**独立复现**一次（不同位置、不同句子）。

## 4. 混淆与瑕疵

1. **只有 3 臂 / 3 份题面 / 1 跑**。⛔ 结论只说「这两句话在这个位置上」。
2. **U4 只能证「有送达」，不能证「送了几条」**；P1/P2 上**只有 A1 分叉**（A3 与 A0 同盆
   `5755e033`）⇒ **哪个字符有影响，也随题面变**。这条比 V101 更狠：连「敏感字符」都不稳定。
3. **A2 未跑**：它在 P0 上与 A1 逐字节同（同一个实现 `8089eee6`，V101 §169.6）⇒ 加它是加重复。
4. **派生题面**：`bench/evidence/v6_s191/suites/` 里的 P0/P1/P2 **不进 `bench/heldout/`**
   ⇒ `check_counts` 的 67 题口径不变。`tests`/`oracle`/`partial`/`null`/`meta` 由脚本逐字段断言不变。
5. **p̂ 不可用**：这不是随机采样，是 3 个定值。

## 5. 对主线的意义

- **V100 的 1.00 是伪的**，这一点现在有三条独立证据：V101（换套件后一格不剩）、
  V102（同一套件换一句话后反号）、V100 自己（11 步里 9 步无效、无梯度）。
- **「改一句话就能改分」+「改什么不重要」** ⇒ 分数不是知识的函数，是**题面字节的距离**的函数。
  这解释了为什么 V93~V99 里所有「属性」（位序/长度/措辞/形态）都保持不住符号：
  **它们从来不是自变量，只是扰动量的不同取法。**
- **对 B 路线**：异源判据不能是「同一批题的另一种说法」（V101 已排除换套件），
  也不能是「同一批题换一句措辞」（V102 排除）。
  ⇒ 它必须是**能独立于题面字面存在**的东西：**程序行为的可判定性质**（性质测试、等价类、不变量），
  而不是「一串输入跑出来的分数」。这是 V103 要试的。

## 6. 下一刀 V103：把「扰动」钉死

问题：§3.3 说效应来自「不再是原来那句」。要判定这一点，需要一份**纯格式、零语义**的扰动。

装置：P3 = 把 P0 句末的**全角括号**换成 ASCII 括号（`（惯例不在题面里）`→`(惯例不在题面里)`），
意思与字数**完全不变**，只变一个字符的码位。P4 = 在句末加**一个空格**。

判据（只押结构）：
① 若 P3/P4 也让 g7d3 落到 `5755e033` ⇒ **效应 = 扰动，与语义无关**（决定性）；
② 若 P3/P4 不动 ⇒ 效应需要「词变了」，不是纯格式；
③ **同盆必同分**跨 5 份题面仍成立。
⛔ 不押分数值、不押哪份会动。
