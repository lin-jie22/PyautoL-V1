⇒ V106 的「块级有梯度」要降级：**那个梯度不可跨题，本质是抄同一题的更好实现。**

- 轮次：V107（`bench/evidence/v6_s196`）

## 二、⛔ 顺带查出 V106 的一个错：「2 个命中」其实是 **1 个**

V106 写的是「`075b4099` 76 组合 ⇒ **2 个到 1.0**（`L4 ← 8089eee6:L4`、`L4 ← 309f1027:L4`）」。
这一轮把计数拆开之后：

```
同题**组合** 24 个　**互异候选** 18 个　命中组合 2 个、命中互异候选 1 个
  命中行 "    return fmt_str.replace(',', ' ')" ← ['L4<-8089eee6:L4', 'L4<-309f1027:L4']
```

两个满分实现的 `L4` **逐字相同**（`8089eee6` 与 `309f1027` 只差引号风格，最后一行一样）。
⇒ **「2 个命中」是 2 个标签指向同一个候选。**

⭐ 这个更正的后果不是细节，是**结论要变硬**：
块级上升路径不是「有几个入口」，而是**恰好一个修复点** —— 那行 `return fmt_str.replace(',', ' ')`。
⇒ 「块级有梯度」这个说法**夸大了**。准确说法是：**有一个且只有一个已知的修补动作**。

## 四、为什么必须打坏（机制，不是巧合）

修好这道题需要的那一行是：

```python
    return fmt_str.replace(',', ' ')
```

`fmt_str` 是 **`g7d3_fmt_amount` 这道题的局部变量名**。别的题里没有这个变量：
- `g7d2_dedupe_keep` 用的是 `seen`/`key`，
- `g7e1_parse_flag` 用的是 `flag`/`tok`，
- `g7e2_truncate_tail` 用的是 `s`/`cut`。

⇒ 跨题的行里**引用的名字在这题里要么不存在（NameError→0.0），要么指向别的东西（0.2）**。
这不是「运气不好」，是**整行作为迁移单位时，必然带着题目私有的名字**。

## 五、对主线的意义（这一轮最要紧的一句）

> **累积的产物在跨题方向上没有价值 —— 至少以「整行」为单位时是这样。**
> 库里有 1.0 的实现，只能修**同一道题**的另一份实现。对新题，一行也搬不过去。

这把「累积 → 变强」的链条卡在了具体位置：
- V105：候选空间太小（42 格只 9 个实现）；
- V106：唯一的上坡路径是搬语句；
- **V107：搬语句只对同题有效，且只有 1 个已知修补点**
⇒ **「积累更多实现」不会自动变成「会做新题」**，因为可迁移的单位比「行」更小。

⭐ 这也解释了 V82~V87 那一片负结果为什么怎么调都不动：
那些轮次试图让系统把「惯例」写成自然语言再读回来，而**真正可迁移的东西**（`.replace(A, B)` 这种惯用法）
恰恰是**去掉题目私有名字之后**才剩下来的那部分 —— 而现在的管线里没有任何一步做这件事。

## 六、自踩与限制

1. ⛔ **V106 的「2 个命中」已更正为「1 个互异候选」**（见 §二）。原因是我在 V106 里按**组合**计数，
   没有按**候选**去重。这一条要回写进 `DESIGN.md` §174.4 与 `RESULTS.md`。
2. ⚠️ 跨题池只有 **3 道题 / 17 个实现**（档案里就这些）。⇒ 「跨题不可迁移」只在这 3 道题上成立，
   **不许推广成「跨题永远不行」**。
3. ⚠️ 迁移单位是**整行**（含缩进与变量名）。⛔ 不许把这一轮的负结果读成「迁移不可能」：
   单位越小越可能迁移，这一轮**只否掉了整行**。
4. ⚠️ `compile()` 过滤把 225 砍到 56（75% 丢掉）。V106 抽 20 个验证过按 0.0 计，本轮沿用同一做法，
   **没有再抽样验证**（同一算子、同一判据，风险低，但如实登记）。

## 七、下一轮（V108）的方向：把迁移单位降到「去掉私有名字之后剩下的那部分」

- **做法**：把捐赠行里的标识符统一**改名**到目标的变量名（`x`/`fmt_str`），再做整行替换。
  这样测的是「**结构**能否迁移」，而不是「名字是否碰巧一样」。
- **判据**：改名后跨题命中数是否 > 0。
  - \>0 ⇒ 可迁移的是**结构**（这条能进 L4）；
  - =0 ⇒ 连结构都不行，那才轮到「必须重新发明」。
- ⛔ 预告陷阱：改名会**人为制造**「看起来像」的行（例如把 `s.replace(a, b)` 改成 `fmt_str.replace(x, y)`），
  可能撞出**语义错但编译过**的候选。必须逐条报分数，不许只报命中数。
