## 2. ⛔ 本轮最重要的一件事：我的口径错了（升纪律 48）

脚本算的是 **`Δ = s(删后) − s(基线)`**；而**惯用法的因果效应 = `−Δ`**。
`delete_idiom.py` §4 拿 `Δ` 直接与 V109 的 uplift 比「同号」，**方向反了**。

| 口径 | 同号 | 异号 | ZERO | 判 |
|---|---|---|---|---|
| ⛔ 错误（用 `Δ`） | 1 | 16 | 5 | 「押中」 |
| ✅ 正确（用 `−Δ`） | 16 | 1 | 5 | **押错** |

按（题, 惯用法）聚合（组级，去掉格数加权）：

| 组 | V109 | 效应（−Δ 均值） | 关系 |
|---|---|---|---|
| g7d2 `.lower()` | +0.700 | **+0.700**（4 格） | 同号 |
| g7d2 `.strip()` | +0.600 | **+0.400**（3 格） | 同号 |
| g7d3 `.format(x)` | +0.540 | +0.700（4 格） | 同号 |
| g7d3 `.replace(',', ' ')` | +0.450 | +0.533（3 格） | 同号 |
| g7d2 `.add(norm_x)` / `.add(x_normalized)` | +0.300 | +0.800 | 同号 |
| g7d2 `.add(normalized_x)` | **−0.200** | **+0.400** | ⛔ 异号 |
| g7d2 `.add(x)` | −0.700 | 0 | ZERO |
| g7e2 `.strip()` / `.lower()` | **−0.800** | **0** | ZERO |

> **⇒ W2 押错：V109 的组间相关，在同题内大体被因果证实（6/10 同号，1 异号）。**

⛔ **纪律 48**：判据里出现「同号/异号」时**必须写出公式**（`效应 = s(删后) − s(基线)` 的负号）。
只写「与 Δ 同号」会让一个符号错误变成「押中」。（与纪律 46「分母不同不许比」同一族：
**方向不写清就不许判符号**。）

## 4. ⭐ 判决：V109 的两条负迁移**全部判死**（可证明）

### ① g7d3 `.strip() = −0.450` —— 唯一证据格**根本没进入执行**

g7d3 的 9 个实现里只有 `36317a87` 含 `.strip()`。它的原代码**编译不过**：

```
def fmt_amount(x):
    return f" {(x:.2f):,}".replace(',', ' ').strip() if x >= 0 else ...
SyntaxError: f-string: expecting a valid expression after '{'   @line 2
```

⇒ 它的 0.0 是**语法错**，与 `.strip()` 无关；其余 8 个实现都不含 `.strip()`（删无可删）。
⇒ **−0.450 是纯混杂，且原因不是统计，是「那格从来没跑起来」。**

⭐ 顺带一个对盆模型的修正：26 个实现里**只有这 1 个**语法不合法。
V105 H2 说「0.0 挤 3 个」—— 那 3 个是 `0a6acc93` / `17747356` / `36317a87`，
其中 **1 个没跑起来、2 个跑了但算错**（`$1,234.50` / 用逗号不用空格）。
⇒ **0.0 不是一种盆。**

### ② g7e2 `.strip()` / `.lower() = −0.800` —— 效应**全 0**

| 实现 | 惯用法 | 基线 | 删后 | 效应 | 位图 |
|---|---|---|---|---|---|
| `8184ec4d` | `.strip()` | 0.2 | 0.2 | 0 | 不变 |
| `8184ec4d` | `.lower()` | 0.2 | 0.2 | 0 | 不变 |
| `bc8c4b09` | `.strip()` | 0.2 | 0.2 | 0 | 不变 |
| `bc8c4b09` | `.lower()` | 0.2 | 0.2 | 0 | 不变 |

那个 0.2 来自 `s[-(n-3):]` 的**下标错**，与归一化毫无关系。
⇒ **−0.800 判死**：四格效应全 0，`strip`/`lower` 在这道题上纯属搭车。

## 5. ⭐ V109 的盲区：空组剔除丢掉的是**一整片因果**

V109 报告「两组之一为空的（题, 惯用法）组合 = **28**」。g7e1 的 8 个实现**每个都含** `.strip()` 与 `.lower()`
⇒ 「不含组」为空 ⇒ **这 16 格整组被剔除**。

本轮用实现内对照把它们捞回来：

| 惯用法 | 8 格效应 | 判 |
|---|---|---|
| `.lower()` | `0,0,0,+0.2,0,+0.2,+0.2,0` | **3 个实现因删除掉 0.2** ⇒ 有真因果 |
| `.strip()` | 全 0 | 无效应 |

> ⭐ **「组间比较」在空组时不是丢掉一个数，是丢掉一整片因果。**
> 这与 V104「9 条性质只有 1 条有牙」是同一种病：**覆盖面看起来很大，实际有效样本为零。**

  干净的读数是：**跨题注入一个语法/类型都兼容的修饰性惯用法，效应 = 0。**

## 7. 净收益（一句话）

> **惯用法是它自己那道题的必需品（13 个修饰性格子作证），但不是任何别的题的必需品（跨题注入 0 效应）。**

这句比 V109 的「符号由题目决定」更准，而且方向相反：
- V109 暗示符号是**任意的**（所以累积无望）；
- V110 说明符号是**稳定、可测的**，只是**作用域恰好等于它出现的那道题**。

⇒ 「累积→迁移」关闭的理由要改写：
**不是「攒的东西是假的」，是「攒的东西是真的，但它的正确性条件就是它自己那道题」。**
