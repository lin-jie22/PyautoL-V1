## 0. 承 V106 + V111

- **V106**：`075b4099`（0.4）的 **596 个**合法 1-编辑邻居，分数 `0.4×57 / 0.2×204 / 0.0×335`，
  **最高 0.4、上升 0 个** ⇒ 结论「字符级是单向棘轮」。
- **V111**：代码多样性 ≫ 行为多样性（g7e1 的 8 个代码只有 3 种行为）。

⇒ 必须排除的解释：**这 596 个邻居里有相当一部分在行为上与原实现等价**（改引号风格、改空白），
它们根本不是新候选。若如此，「无梯度」就不是地形性质，而是**邻域在行为上退化**。

## 1. 装置

- 算子：与 V106 **同一份** `char_mutants`（`bench/evidence/v6_s195/landscape.py`，含按字节去重）。
- 合法性：`compile()` 通过（与 V106 同）。
- 行为指纹：`assert EXPR == EXPECT` → `print(repr(EXPR)`（与 V111 同一套，含 `is True/None` 分支）。
- **分数由指纹重算**（V111 已验证与 `code_exec` 0 不一致），省掉 596 次判分。

## 2. 判据（三值，跑前写死）

| 编号 | 命题 | 押 | 理由 / 判负后果 |
|---|---|---|---|
| **Y1** | 596 个邻居中「行为与原实现**完全等价**」的比例 | **≤ 20%** | 机制：单字符编辑几乎都会改某个输出。若 **> 50%** ⇒ V106 的「单向棘轮」降级为「邻域退化」，「596 个邻居」这个数字要作废 |
| **Y2** | 分数 = 0.4 的那 57 个邻居里，**互异行为**的个数 | **≥ 20** | 若只有少数几种行为 ⇒ 「0.4 是一个点」；若 ≥20 ⇒ 「0.4 是一片宽台地，只是分数看不见」 |
| **Y3** | 存在**行为等价**的邻居（数量 ≥ 4） | **有** | 机制写死：`075b4099` 里有 **4 个 `"`**，改成 `'` 一个字符都不改语义 ⇒ 至少 4 个等价邻居。若 0 个 ⇒ 我的机制推断错了，须查为什么 |

⛔ **不写**「行为等价 ⇒ 同分」这条：它是恒真（`tests` 只吃行为，V105 H1）。

## 3. 分母口径

- Y1 分母 = **596**（V106 的合法邻居数，必须复现；若对不上，先停下查口径）。
- Y2 分母 = 0.4 档的邻居数（V106 说 57，必须复现）。
- ⛔ 每题/每档**分开报**，不合并。
- ⛔ 报「互异行为数」时同时报**分布**（哪个行为有几个人），不许只报总数。

## 4. 已知陷阱

1. **指纹只覆盖 5 个输入** ⇒ 「行为等价」只在这 5 个点上成立，不许说「语义等价」。
2. 单字符编辑可能造成**超时**（8s）⇒ 记 `ERROR:Timeout`，单列，不丢。
3. 打印 `repr(EXPR)` 与 `assert EXPR == EXPECT` 不严格同构（V111 §0 已处理）⇒
   必须交叉校验：**分数分布必须复现 V106 的 `0.4×57 / 0.2×204 / 0.0×335`**，
   对不上就判装置失效。
4. 语料仍是 1 个起点 ⇒ 不许推广到 `8089eee6` 或别的题。
