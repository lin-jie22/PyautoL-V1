# V139 预注册：后果侧的观测从哪来

> §205.7 的下一刀。写于跑任何代码之前。
> 零模型、零网络；**不新跑判据、不重跑轨迹**，只对 V138 已落盘的 89 站真值做分析。

## 0. 问题

V138 把「盲区」拆成三片：**真盲区 15/89（判据绿、下游真变）**、死旋钮 3、死代码 54。
那 15 个的共同形状是：`memory.py:321/367` 改两处 ⇒ 207 个函数跟着变、判据 631/0。

于是问题不是「判据覆盖多少」，而是：

> **当一条改动有下游后果、却没有断言盯着它时，「后果」这一侧的观测从哪来？**

V138 的回答是「跑一遍轨迹」。但那要 48 秒，和判据本身一个价。
这一轮问的是**更便宜的那一档**：在**不重跑任何东西**的条件下，能不能只靠

- **静态结构**（源码里的调用关系），
- **基线轨迹**（跑之前就有的、与本次改动无关的调用计数），

拿到「这次改动会不会有后果」「后果落在谁身上」。

## 1. 装置

- 真值：`bench/evidence/v6_s227/analysis.json` 的 89 条 `diff`（已剔除 16 个剔除集函数）
- 站点的被改函数：`v6_s227/taxonomy.py::owner_map()` 同一实现（模块.类.方法 命名，与轨迹同名）
- 基线调用数：`v6_s227/baseline.json` 的 `base_per_fn[*].n`
- 分层（V138 已定，不重判）：SPILL 32 / SELF_ONLY 3 / NOOP 54

**Part A（谁变了）**：对 32 个 SPILL 站
- `pred_t` = 被改函数 f 的**传递调用者集**（含 f 自己，静态图反向可达）

**静态图两档（写在跑之前，避免事后挑好看的那档）**：
源码里大量方法是经实例调用（`self.store.recall()`），没有类型信息就解析不出接收者。
所以图分两档，**两档都打印**：
- `strict`：只连能**精确解析**的边（同模块函数、`from .x import y` 进来的符号、`self.m/Class.m`）。
  解析不出的调用**不连边**（会低估召回）。
- `loose`：解析不出的 `<任意>.attr(...)` 连到**全库所有同名函数**（过度近似，会拉低精度）。
- **主读数用 `loose`**（它是「静态结构能给上界保证」的那一档）；`strict` 并列打印。
- `pred_d` = f 的**直接调用者集**（含 f）
- `truth` = 该站 `diff`
- 随机零分布：把 `truth` 的**函数标签随机置换**（1000 次，种子 20261115），
  零假设均值 = 随机挑同样大小的集合能撞上多少 ⇒ 纪律 49（零假设必须由重排造）

**Part B（会不会变）**：把 89 站二分类为 SPILL(32) vs NOOP(54)（SELF_ONLY 3 个排除）
- 免费特征：① 被改函数是否在基线轨迹里出现过（`owner ∈ base_per_fn`）；② 基线调用数；③ 静态入度
- 判据：AUC + 置换检验

## 2. 押注（只押结构，不押幅度）

| # | 命题 | 押 |
|---|---|---|
| W1 | **传播不总沿调用边**：至少存在一个 SPILL 站，`truth ⊄ pred_t`（召回 < 1） | 成立 |
| W2 | **静态可达是过近似**：至少存在一个 SPILL 站，`truth ⊊ pred_t`（精度 < 1） | 成立 |
| W3 | **越远越不准**：直接调用者精度 > 传递可达精度的站点占多数（≥ 2/3） | 成立 |
| W4 | **静态信号强于随机**：合并计（Σ命中/Σ预测）的富集倍数 ≥ 3× | 成立 |
| W5 | **死代码免费可判**：`owner ∉ base_per_fn` 的站点**全部**是 NOOP | 成立 |
| W6 | **免费信号有牙但不齐**：用免费特征区分 SPILL/NOOP，AUC > 0.5（置换 p < 0.05）**且** AUC < 0.9 | 成立 |

## 3. 判破怎么办

- 任何一条押破，照实登记，**不许事后改判据、不许挑站点**。
- W1 若押破（召回恒为 1）⇒ 「传播完全沿调用边」成立，静态图就是真相的超集且不遗漏，
  那 Part A 的价值从「预测谁变了」降级为「**缩小必须观测的范围**」。
- W6 若 AUC ≥ 0.9 ⇒ 免费信号足够，**后果侧的观测可以零成本**，这是更强的结论，不算失败，但要改口。
- W6 若 AUC ≤ 0.5 ⇒ 免费信号无用，观测必须重跑，登记为负结果。

## 4. 口径（纪律 46）

所有比例必须**先打印分母**：`|truth|`、`|pred|`、`|universe|`（= 331 个被调用函数）。
富集倍数 = 观测精度 / 零分布精度均值；零分布精度 = 随机集合命中数 / 集合大小。
⛔ 不许把「pred 里那些从没被调用过的函数」悄悄剔掉来抬精度——**主读数用全量 pred**，
`pred ∩ universe` 只作为附加口径并列打印。
