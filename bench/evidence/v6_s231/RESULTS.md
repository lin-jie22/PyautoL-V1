## 3. 读数里的两个「不是我以为的」

### 3.1 预注册押「145/145 UNKNOWN」，实得 62/145

145 行里 **83 行没有 `run_id`** —— 那些记录连「查某一次运行」的入口都没有。
`ledger_verdict` 按身份查，查不到就是 `UNKNOWN`（不是绿），结构命题成立；
但**字面分母押破了**：我押的 145 是可查的行数，实际可查 62。

⇒ 这条登记为**押破**，不改成「其实也对」。它反而暴露了一个真事实：
**V72 之前的账本记录没有身份证**，任何按 `run_id` 的读取对它们都无从下手。

### 3.2 `--compare` 从来没能比过（预注册外的发现）

W6 第一次跑出来是：`⛔ 口径不一致（差异字段 ['memory_seed']）⇒ 拒绝比较`，
而**同一份口径的签名一字不差**（`sig=71f8b695ae4aa7e1`）。

根因：`Caliber.diff()` 用 Python 值比较，`Caliber.signature()` 走 `_canon`（JSON）。
进程里 `memory_seed` 是 `(0, 0)`（tuple），落盘再读回是 `[0, 0]`（list）
⇒ **两个判据对同一件事给出相反答案**，而口径闸用的是 `diff`。
⇒ 自 `f9fed87`（`memory_seed` 进入口径）起，**任何写盘基线都拒绝比较**。
一个 fail-closed 的闸把自己关死了：它从不出错，因为它从不出结论。

复现（`READINGS_deadlock.txt`，`git archive f9fed87` 原地跑）：

```
sig 相同 : True
same_as : False | diff: ['memory_seed']
```

修法（唯一一处）：`diff()` 也走 `_canon` ——「同口径」只留**一个**定义。
契约 `AZ128h` 钉住这一点（签名相同 ⇒ diff 必空），撤回态是把这个 bug 原形写回去。

## 5. ⛔ 自踩登记（三处，其中两处打在**计数器**上）

1. **AST 计数器数成 0**：`AZ128g` 第一版只认 `ast.Name == "store"`，而外壳写的是
   `gate.store.save(...)`（`Attribute`）⇒ 全文件/外壳/函数体三处全 0，断言当场红。
   修：接收者认 `Name("store")` 或 `Attribute("store")`。
   ⇒ **计数器的形状要跟着被数的东西长**（第 137 轮 `owner_map` 那次同型）。
2. **W3 的第一次读数是假绿**：RED 那一跑放进空目录，「没写基线」是因为**没有旧文件**，
   不是因为拒绝了（纪律 5 第二形态：变异没生效）。改成先复制一份基线再跑，
   判据是 **sha 逐字节不变**。
3. **AZ126a 的撤回只能改材料**：它断言的是「旧口径在那份真实崩溃日志上读到 7/0」，
   实现侧没有可撤的东西 ⇒ 撤的是**输入**（7→8）。登记为「材料型撤回」，
   它证明的是这条断言不是恒真，不证明任何实现。

## 6. 边界

1. ⛔ 没让系统多做对一道题；三个「外面」一个没打开（问题 / 判据 / 目标）。
2. ⛔ 它只回答「这次量到没有、能不能当标准」，**不回答「改动对不对」**（V134 已判死）。
3. ⚠️ `--suite-dir` 仍不产生判据行 ⇒ 那条路径**也禁止写基线**（`gate=None` 直接拒绝）。
4. ⚠️ `stamp_verdict` 整体重写账本（145 行 482KB）；**两个 bench 进程并发会互相覆盖** ——
   当前无并发入口，登记为缺口。
5. ⚠️ 总账仍 **89 站、一个库**；V79（自造判据判别力 0/8）一个字没碰。

## 7. 下一刀

否则登记「分层无后果」。
