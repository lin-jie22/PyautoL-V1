# V143 预注册（§210）：账本才是权威 —— 基线的可信度必须由账本复核

写这份文件时**没有任何读数**。下面每一条押注都在跑之前定死，跑完只许照抄结果。

## 0. 靶子

V142 让结论有了去处（`runs.jsonl` 每行带 `verdict`，基线带 `verdict`）。但它留下了一个
结构性问题：**基线的结论是「自述」**。`bench_baseline.json` 里那句 `"verdict": "GREEN"`
是这次运行**自己**写下的，写在它自己声称的那个东西旁边 —— 换句话说：

| 谁在说话 | 说什么 | 谁能反驳 |
|---|---|---|
| 基线文件 | 「我是 GREEN 运行写的」 | **没有人** |
| 账本 `runs.jsonl` | 「GREEN/RED/CRASH/不知道」 | 没有人去问 |

于是「可信度」仍然只是**一个字段**，不是**一份可核对的记录**。真正的可信度必须能被
第三方复算 —— 在本项目里，第三方就是账本：同一次运行在账本里有自己的一行，结论应当
在**两处**都成立；不成立时，**保守的那个赢**。

## 1. 改什么（两个文件，不新造量表）

### `mw/bench.py`

| 新增 | 作用 |
|---|---|
| `record_verdict(rec)` | 「这一行的结论是什么」的**唯一**定义；缺席/`PENDING`/非法 ⇒ `UNKNOWN` |
| `ledger_strata(path)` | 账本**分层普查**：`rows` / `no_run_id` / GREEN / RED / CRASH / UNKNOWN |
| `baseline_provenance_gate(...)` | 基线**复核闸**：自称 + 身份证 + 账本三处对齐才放行 |
| `BaselineStore.save(..., run_id=)` | 基线里多存一格**身份证**（写它的那次运行的 `run_id`） |
| `BaselineStore.load_run_id()` | 无键 ⇒ `""`（**不是**「随便一行」） |

`baseline_verdict_gate` 保留，并成为复核闸的**第一层**（同一个判断只有一处定义）。

复核闸的规则（顺序即语义）：

1. 基线自称不是 `GREEN` ⇒ 拒（V142 已有）
2. 基线没有身份证 ⇒ 拒 ——「自述无法复核」
3. 账本里查不到这个 `run_id` ⇒ 拒 ——「自说自话」
4. 账本对这一行的结论不是 `GREEN` ⇒ 拒 ——「两处打架，保守的赢」
5. 其余 ⇒ 放行

### `run.py`

- 写基线时把 `gate.run_id` 一起写进去；
- `--compare` 先走复核闸，并把**账本怎么说的**念出来（不是只念基线自述）。

## 2. 押注（先写死，跑完照抄）

| # | 押注 | 判据 |
|---|---|---|
| **W1** | 账本分层普查是**自洽**的 | 对真实 `bench_out/runs.jsonl`：`no_run_id + GREEN + RED + CRASH + UNKNOWN == rows`，且 `UNKNOWN == 有 run_id 的行数`。⛔ 不押具体条数（纪律 40：押个数就是押幅度） |
| **W2** | 同一份读数，**只因账本查得到就换结论** | 一份 V142 形态基线（`verdict=GREEN`、**无** `run_id`，其余逐字节相同）⇒ 拒，理由出现「身份证」；把它补上 `run_id`（账本里 GREEN）⇒ 放行，且出现「判定」行 |
| **W3** | 账本**能推翻**基线的自述 | 先真跑一次 `--solver null`（天然 RED）⇒ 账本里出现一行 `verdict=RED`；伪造一份自称 `GREEN` 的基线、`run_id` 指向那一行 ⇒ **拒**，理由点名账本说的是 RED |
| **W4** | **正例路径存在**（纪律 62） | oracle 离线 GREEN ⇒ `--save-baseline` 写盘；再跑 `--compare` ⇒ 出现「判定」行（不是拒绝句） |
| **W5** | 账本没有这一行 ⇒ 拒 | 基线 `run_id` 改成账本里不存在的值 ⇒ 拒，理由点名「查不到」 |
| **W6** | 无回归 | 门禁 `EXIT=0`；契约 `N/0`（N = 650 + 本轮新增）；锚层 97/0；撤回态同步；文档 0 漂移 |

押「拒绝」的三格（W2 前半/W3/W5）额外押**零次**「判定」行 —— 拒绝就必须真的不出结论，
不是念一句「拒绝」再把数字算完。
