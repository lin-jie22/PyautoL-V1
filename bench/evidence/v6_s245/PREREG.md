# PREREG — V156（§223）：自省能不能定价

> 写于任何分数被计算之前。跑前结构见 `L3_QUESTIONS.md` §二（S1~S4，零分数）。
> ⛔ 不新造分数（只用 `v119.ev >= 1.0` 与既有 `p`/`s0`/`n`）；⛔ 不改 `gen`/`abstract`/记忆；⛔ 不碰 V79。

## 1 问法

「判到第一条 1.0 要花几次判分」= 该键的实例序列里第一条 `ev>=1.0` 的**位置**（1 起，只数这条键的判分）。
预测器给一个价格 `price`。问：**价格校准吗**（中位倍数误差 ≤2×）、**能排序吗**（Spearman）。

两个分辨率分开答（S2 已证明两者动态范围差一个量级）：

| 臂 | 序列 | 位置范围 | 可部署 |
|---|---|---|---|
| `A` 部署（k=2, R6） | 该键在 A_DEPLOY 事件里的实例，按首次出现去重 | **1~8** | ✅ |
| `C` 满闭包（d=2） | 该键的 C 实例，按 `sorted(src)` | 1~`n_c`（中位 12、最大 233） | ❌ 只作模型校准与排序检验 |

## 2 预测器（全部实现级留一 LOIO：留出一整个实现）

| 代号 | 输入 | 判分成本 | 价格公式 |
|---|---|---|---|
| `P0` | 训练集的**实测位置中位数**（同题内其他实现） | 0（历史） | 常数 |
| `P1` | 训练集里 `s0` 最近邻那一格的 `p` | **1** | 几何中位 `ceil(log .5 / log(1-p))` |
| `P2` | `P1` 的 `p`，用 `1/p`（均值口径） | 1 | `1/p` |
| `P3` | **本题本格**的 `p`（= 用 C 的全部实例，🚐 不可部署） | `n_c` | 几何中位 |

`P3` 不是候选方案，它是**几何模型的自检**：若连 `P3` 都不准，说明「实例独立同 p」这个前提本身
不成立（顺序有偏 / 相关性），此时 `P1` 的任何误差都不能归给预测器。

## 3 判据（预注册，三值：成立/押破/UNKNOWN）

| # | 判据 | 押 |
|---|---|---|
| **W1** | 装置自校验：A 的 `n_eval=2710`、到 1.0 `=21/25`、基线 `=10/25`、真实格 `=35` | ✅ 复现 |
| **W2** | 删失面：有 1.0 的格 `=28`、无 1.0 的格 `=5`（这 5 格位置 = ∞，价格不可定义） | 28 / 5 |
| **W3** | 部署层位置的中位数 | **1**（S2：13 格 `n_a=1`） |
| **W4** | **几何模型**校准（`P3`，C 臂）：中位倍数误差 | **≤2×**（模型成立） |
| **W5** | **部署层可定价**（`P1`，A 臂）：中位倍数误差 | **>2×**（不成立） |
| **W6** | `P1` 在 C 臂上能给格**排序**：Spearman(price, 实测位置) | **≥0.5** |
| **W7** | 绝对成本：部署层「价格 − 实测」的中位绝对误差 | **≤1 次判分** |

⭐ **W5 与 W7 一起读才是结论**：倍数误差大但绝对误差 ≤1 ⇒ 定价「不准但无害」（因为总成本上限只有 8）；
倍数与绝对误差都大 ⇒ 定价真的不可用。

## 4 口径与已知陷阱

1. **位置只在「这条键自己的判分」上数**，不数别的键。分母写进字段名（`pos_a_of_key`）。
2. **删失必须单列**：`pos=∞` 的格不许从分母里悄悄剔掉（纪律 64），要报「28 可定价 / 5 删失 / 33」。
3. **`n_a=1` 的格恒有 `pos=1`**（若命中）⇒ 这些格对「倍数误差」贡献 1/price，会把中位数整体拉低，
   必须同时报「只含有动态范围的格（`n_i>=2`）」的子集读数。
4. **顺序不是随机的**：A 臂按 `0 if key in mine else 1` 排序、同键内按 gen 顺序；C 臂按源码字典序。
   ⛔ 不许把 C 的字典序位置读成「搜索会花这么多次」。
5. `p` 的估计与 `pos` 的实测**来自同一批实例**时（`P3`），这是自检不是预测，必须标注。
6. 复现 A 臂是**重放**（确定性），不是新增判分；`ev` 结果走进程内 CACHE。
