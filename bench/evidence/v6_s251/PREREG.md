## 0. 问题

V162 把判分从 588 剪到 **179**，但命中仍是 **21/25**；缺的 **4 个全在 `g7d3`**。
再剪只省时间、补不上命中。⇒ 换方向：**覆盖**。

问：**这 4 个缺口在「全枚举」下可达吗？**

- 能到 ⇒ 是**搜索策略**问题（贪心/早停/剪枝挡住了通路），可以改搜索；
- 到不了 ⇒ 是**动作空间**不足（候选生成器缺算子），这是 V105「候选空间是瓶颈」的第一份**直接**证据。

## 1. 装置（口径逐字固定）

- 状态 = 源码串；生成 = `X.gen(tid, code, Sx, ch, ex)`，`Sx/ch/ex` 固定为**原实现**的上下文
  （与 `v162.replay` 完全一致）。
- 全枚举 = 从原码 BFS 到深度 `D`，**不剪枝**（不跳 `T1/T3/T4`、不跳 `ubiq`、不跳 `dup`）、
  **不早停**、**不按分数筛 frontier**（所有新状态都展开）、只按源码去重。
- 判分 = `V.ev(tid, src)`，分数格 5 格。
- 主臂 `E3`：`D=3`。扩展臂 `E4`：`D=4`（仅当 `E3` 后仍有缺口时跑，判据同形）。
- 归因：对每个缺口，取**最短**命中路径 `p0→p1→…→pk`（`s(pk)=1.0`），把贪心 `U` 臂
  **逐步重放**（同 `KEEP=2`、同 6 轮、同剪枝），找**第一处断裂**，按 `replay` 的**逐行判定顺序**归类：
  - ①**下坡**：`sc <= 父 s` ⇒ 不进 `pool`（`pool` 只收严格改进）；
  - ②**被剪**：`kind ∈ {T1,T3,T4}`，或 `kind==B` 且 `n_prov==n_sib`；
  - ③**宽度截断**：进了 `pool` 但该轮排名 >2，被 `frontier = pool[:2]` 丢掉；
  - ④**其他**：以上都不是 ⇒ **装置/口径不自洽**（必须如实报，不许归到前三类里凑）。
  ⚠️ `U` 臂 `skip_dup=False` ⇒ `T2` 的等价重写**不在本轮归因范围**内（它不剪）。

## 2. 判据（押三值；作用域 = `g7d3` 的 6 个非饱和实现、`D≤3`）

| id | 命题 | 押 |
|---|---|---|
| A1 | 至少 **1** 个缺口在 `E3` 下存在 `s=1.0` 的状态（存在性，不是幅度） | True |
| A2 | 可达缺口的最短命中深度 **≥2**（不存在「d=1 就命中却被 `U` 臂漏掉」） | True |
| A3 | 至少 **1** 个缺口的第一处断裂是①**下坡**（贪心结构上到不了该通路） | True |
| A4 | 至少 **1** 个缺口的第一处断裂是②**被剪**（剪枝挡的）或③**宽度截断**（`KEEP=2` 挡的） | True |
| A5 | 归因④（其他/不自洽）条数 == 0 | True |
| A6 | `E3` 命中集 **⊇** `U` 臂命中集（逐实现不比 `U` 差） | True（自校验，恒等式；失败=装置坏） |

⛔ A6 是恒等式（全枚举包含 `U` 走过的路径），**不计入「判据中几条」的结论**，只作装置自检。
