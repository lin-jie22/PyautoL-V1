## §0.1 跑前修正（相对 §232.8 的文字，两处，都写在跑之前）

1. **§232.8 说「把负数分支的输出包进一对括号」。实测（`probe_t6.py`）发现：**
   - `8c8ac7f0` 的 `U5` 终点是 `f'{x:,.2f}'.replace(',', ' ')` ⇒ 负数渲染成 `-1 234.50`，
     需要 `startswith('-') ⇒ '(' + s[1:] + ')'`（前缀 `-`）；
   - `17747356` 的 `U5` 终点是 `...replace('-', '(-')...replace(',', ' ')` ⇒ 负数渲染成 `(-1 234.50`，
     **不以 `-` 开头**，需要 `startswith('(-') ⇒ '(' + s[2:] + ')'`（前缀 `(-`）。
   ⇒ **「同一个模板」是错的，必须先拆成两个 marker 各自一个候选。** 这不是跑后修正。
2. **不实现 §232.8 的字面意思「包住负数分支」**（那要识别 `x >= 0` 分支并重写两支），
   改为**对返回值做前缀归一**：站点是「函数体顶层唯一 `return`」，不依赖有没有 `if` 分支。
   理由：`8c8ac7f0` 根本没有负数分支，按字面会**结构性漏掉**它。

## §1 算子定义

```python
def candidates_T6(code):
    # 站点：函数体顶层**恰好一个** `return`，且它是最后一句；函数内无 `_t6` 同名变量
    # 每个 marker m ∈ ("-", "(-") 一个候选，k = len(m)：
    #
    #   _t6 = <return 表达式>
    #   if _t6.startswith(m): _t6 = '(' + _t6[k:] + ')'
    #   return _t6
    # 标签：T6:r{i}:{m}
```

**marker 来源（必须写清，防「按题面硬编码」）**：三个前缀形式全部来自**本语料兄弟实现自己的语句**——
`-` 是符号本身；`(` 来自 `5755e033` 的 `'( '` 与 `0a6acc93` 的 `f"({abs(x)...})"`；
`(-` 来自 `17747356` 自己的字面量 `'(-'`。**一个测试用例都没读**（测试串只用于 `ev` 判分）。

**不可用站点必须计数并报出**（不许静默吞）：多 `return` / `return` 不在末尾 / 已有 `_t6`。
