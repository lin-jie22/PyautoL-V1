一个可测量的 agent 内核

七段认知循环全部可跑，预算可以逐笔对账，记忆去重由数据库保证， 而「它变好了」这句话有外部依据 —— 不是自己的感觉。 零第三方运行依赖（dependencies = [] 由契约钉死）。

先读这一条：V1 不是 AGI。

它也不声称「无限接近」AGI。它只声称一件事，而且这件事可以被别人在五分钟内证伪： 它是一个能被完整验证的 agent 内核。 下面的数字全部零模型、零网络、零密钥可复现；不能复现的部分，我们标出来说不能。

契约 587/0每条断言都配一条撤回态
锚层 97 条外部判定，含五把假尺子的反证组
172 条撤回态逐条精确转红，无多红、无异常
CI 三档3.11 / 3.12 / 3.13，读数行逐字相同

口径：契约条数 = check() 的调用次数；「撤回态」= 把实现改坏后， 对应断言必须恰好变红 —— 它证明断言不是恒真的。数字的唯一来源是 一次真实运行的日志，任何文档副本都被脚本核对，手抄不算数。

七段循环

perceive组装状态：目标 + 工作记忆 + 检索到的语义记忆 + 上一步观测
think判复杂度 → 快通道（1 候选）/ 深通道（≤N 候选）
plan失败必带错误原文重规划，绝不原地重试
gate四道运行时守卫：目标劫持 / 工具滥用 / 记忆投毒 / 级联熔断
foresee动作后果预演；低置信预测不进决策链
act分派永不抛异常 —— 失败变成一个可记账的结果对象
observe失配沉淀为情景案例 + 语义启发式，而不是被静默吞掉
persist工作 / 情景 / 语义三层记忆各自落位

内核做什么 / 不做什么

内核做（这是它的全部）内核不做（一律外部）
预算分配与对账写代码、改仓库
三层记忆读写与去重查资料、爬网页
动作预演与失配沉淀调用别的 agent / skill / MCP
规划、重规划、候选生成任何领域知识
四道运行时守卫任何具体业务逻辑
能力注册与分派——
交付前自检（判据只从题面派生）——
测量与判定——

外部能力通过 agents.json 接入；文件不存在时内核照常运行（外部能力数 = 0）。 这是刻意的：内核的可验证性不依赖任何外部系统、网络或密钥。

还有一条刻意的分裂：内核里的测量模块只做统计，判定留给外部锚层 —— 因为只有外部拿得到真值。内核不许给自己发分数，这正是上一代系统栽掉的地方。

没做到的事（记录在案）

  1. 没有持续学习。参数冻结；所谓「学习」全部发生在记忆层（改上下文，不改权重） —— 它只能把已有能力用得更准，不能产生新能力。
  2. 没有真正的世界模型。只有文本层面的动作后果预演，不是物理或因果模型。
  3. 外部判定的适用范围很窄。只覆盖 4 个领域、共 21 道纯函数题，全都是 「写一个 Python 函数、结果可被确定性 assert 判定」。多轮交互、有状态环境、 需要人类判断、开放式任务 —— 一个都没测。说它是「通用 Agent」就是越界。
  4. 相近分数不可分。已证明的只是「好 / 中 / 坏」三档有序； 0.60 与 0.65 这种差距是否可分，未证明，且这一点写在证据结构里，不靠声明兜着。
  5. 预算还不等于能力。4 倍预算下逐题分数与 1 倍一字不差 —— 预算目前是上限而不是资源。
  6. 没有概念层。记忆指纹是规范化文本的哈希 ⇒ 同一意思、不同说法会被算成两条。
  7. 在小规模题集上，真模型仍有天花板。我们自己那套 4 道难题上， 最好的臂稳定在 0.70，四轮负结果之后我们停止在那套题上继续加提示词 / 检索臂 —— 因为找不到一个不靠自评的选择器，再多候选也挑不出来。

这个仓库凭什么可信

许撤不许藏

每条断言都要配一条「撤回态」：把实现改坏，它必须恰好变红。 172 条撤回态逐条跑过，全部精确转红、无多红、无异常，改回来仍是全绿。 一条不能变红的断言只是装饰。

负结果也入库

连续多轮实验没有拿到更好读数的，就直接写「本轮作废 / 不认领」，并留下证据目录 （探针脚本 + 原始日志 + 指纹清单）。被否证的假设留在文档里，不删。

数字只有一处来源

文档里的每个总数都由脚本拿本次运行的日志核对；对不上就让整条流水线变红。 这类声明曾经漂过三处 —— 手抄失败是结构性的，不是记性问题。

绿勾不是读数

CI 的「通过」只说明没崩。三档解释器的读数行必须逐字相同才算数 —— 我们曾差点把「日志字符数相同」当成证据，而它随环境元数据在变（实测差 1 个字符）。
